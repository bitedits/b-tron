1.10 Системне управління (System Management)

Функції системного управління забезпечують:

  • Обробку виняткових ситуацій (Exceptions)
  • Отримання інформації про версію ОС та апаратну платформу
  • Зчитування параметрів конфігурації системи

1.10.1 Структури даних та константи

□ Інформація про версію ОС (T_VER)

typedef struct {
    UH  maker;      /* Виробник (Maker Code) */
    UH  id;         /* ID моделі/формату */
    UH  spver;      /* Версія специфікації BTRON (наприклад, 0x0300 для BTRON3) */
    UH  prver;      /* Версія комерційного продукту */
    UH  prno[4];    /* Серійний/керуючий номер продукту */
    UH  cpu;        /* Архітектура процесора (CPU) */
    UH  var;        /* Варіативний дескриптор */
} T_VER;

1.10.2 Системні виклики

def_exc
Define Exception Handler
Визначення обробника виняткових ситуацій для поточної задачі

【Синтаксис / Прототип】

ERR def_exc(W exckind, FP exchdr)

【Параметри】

W   exckind Тип винятку (залежить від платформи/архітектури)
FP  exchdr  Адреса процедури обробника (NULL = скасувати реєстрацію)

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (ER_ADR, ER_CTX, ER_PAR)
ret_exc
Return from Exception Handler
Завершення обробника винятку

【Синтаксис / Прототип】

void ret_exc(W ret)

【Параметри】

W   ret     Режим повернення:
              = 0 : відновити виконання з місця виникнення винятку (не повертається)
             != 0 : продовжити виконання коду обробника (наприклад, для longjmp)
get_ver
Get OS Version
Отримання версії ОС та процесора

【Синтаксис / Прототип】

ERR get_ver(T_VER *version)

【Параметри】

T_VER *version  Буфер для збереження версії

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (ER_ADR)
get_cnf
Get System Configuration Information
Отримання параметрів конфігурації системи за назвою

【Синтаксис / Прототип】

WERR get_cnf(TC *name, VP value, W len)

【Параметри】

TC *name    Назва параметра конфігурації
VP  value   Буфер для значення
W   len     Розмір буфера у байтах

【Значення, що повертається】

= 0     Успіх (числове значення типу W)
> 0     Успіх (довжина отриманого рядка TC у символах)
< 0     Помилка (ER_ADR, ER_NOEXS, ER_PAR)
