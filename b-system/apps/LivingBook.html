Living Book

双方向書籍
Interactive Hypermedia TAD Experience (TAD API)
← Back to B-System Applications
"From static manual to interactive laboratory – every page becomes a live, multimedia-rich sandbox powered by the TAD API."

Overview

Transforms static TAD documents — including the four standard BTRON system books — into a fully interactive hypermedia experience via the TAD browser engine (src/apps/tad_browser.c) and TAD API (tad_browser.h). Expands static diagrams into live media, executes embedded code examples live inside document segments, and attaches synchronized multimedia annotations that stay pinned to text blocks as the reader navigates.

リビングブック： TADブラウザー表示エンジン（src/apps/tad_browser.c）およびTAD API（tad_browser.h）の拡張機能により、4大システム解説書をはじめとするあらゆるTAD文書を動的で双方向な体験へと進化。静止図版を動画メディアセグメントへ展開し、掲載コードを紙面上で直接実行。文書の文脈に連動して移動する音声・ビデオ注釈を添付可能。

Key Features & Implementation

  • 実体コード実装：src/apps/tad_browser.c（ハイパーメディア文書ビューア・ページネーション）
  • テスト検証基盤：src/apps/test_tad_browser.c（TADセグメント解釈・描画テストスイート）
  • BTRON 4大システム書の完全インタラクティブ化（TAD API動的解釈）
  • 紙面コードのインライン・ライブ実行環境（その場で出力セグメントを生成）
  • TADドキュメントに密着して移動するマルチメディア注釈（音声・動画）
  • 静止図版のクリックによるスクラブ可能な動的仮想オブジェクト展開
  • 充実した注釈付きドキュメントを永続的なTAD実身としてキャビネットに保存
  • 注釈・実行結果をTADバイナリ形式で完全保持（外部個別ノート不要）

Why the Market Needs It

  • BTRON system books were historically distributed as static documents; developers could not run example code or see live demos while reading.
  • Learning material is isolated from interactive workflows when annotating a static document does not produce a linked Real Body.
  • Brings the full power of the TAD hypermedia model: Virtual Body links, executable segments, and interactive figures beyond static reflowable text.

Replaces / Normalises

Classic BTRON ProductB-System AdvantageTarget Users
Classic B-TRON "System Books" (static PDFs of the four system manuals) Code runs live in-page; illustrations become scrubbable video; annotations travel with the text Educators, trainees, developers learning the BTRON stack, documentation authors
Conventional e-book readers Full TAD hypermedia model: Virtual Body embedding, executable code, not just reflowable text

Typical Workflow

  1. Open a System Book or any TAD document in Living Book via the TAD API.
  2. Click a diagram → it expands to a scrubbable media Virtual Body inline.
  3. Click a code block → run it in place; output appears as a linked Real Body below the snippet.
  4. Record a voice note at a heading → it attaches to the paragraph and moves with it on navigation.
  5. Export the enriched page as a TAD Real Body into the Cabinet or open it in a Clarity reading session.
