1.10 Загальне системне управління (System Management)

1.10.1 Огляд загальносистемних викликів (Overview)

Розділ загального системного управління містить системні виклики для отримання версії ядра ОС Sakamura BTRON3, перевірки системної конфігурації та примусового перезавантаження чи зупинки системи.

1.10.2 Системні виклики загального управління (System Calls)

get_ver
 
Отримання версії та специфікації ядра (Get System Version)

【Синтаксис / Прототип】

WERR    get_ver(UH *ver, UH *subver)

【Параметри】

UH  *ver    Змінна для збереження мажорного номера версії ядра BTRON3 (Вихід)
UH  *subver Змінна для збереження мінорного номера версії (Вихід)

【Значення, що повертається】

= 0      Успішне виконання (Номери версій записано у ver та subver)
< 0      Помилка (Код помилки)

【Детальний опис】

Повертає точні номери специфікації та релізу ядра BTRON3.

【Коди помилок】

ER_ADR     : Неприпустима адреса вказівника ver або subver.
