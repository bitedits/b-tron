Overview & Architecture

The B-System Language and Character Subsystem represents the pinnacle of multi-lingual OS typography and input method design. Complying with the BTRON3 SPEC 3.20 standards, the subsystem unifies real-time keyboard transliteration, dictionary-based kana-kanji morphological synthesis, comprehensive character plane switching, and authentic Asian script encoding.

言語・文字コード設定（Language & TRON Code）： BTRON 3.20規格に基づく超多言語・高精度文字入出力基盤。純国産かな漢字変換エンジン「TIP Mozc」（src/tip/mozc_kkc.c, tip_ife.c, tip_task.c）、18万字超を収容するTRON文字コード第1面〜第16面、および純C99ポーティングされた「チベット語Extended Wylie（EWTS）変換器」（src/kernel/tip/wylie.c）を統合管理します。

1. TRON Input Processor (TIP) & Mozc Kana-Kanji Engine

The TRON Input Processor (TIP) serves as the system-wide Input Method Framework. Realized via a micro-kernel event server architecture, TIP exposes standard system call ports (iopn_tip, ichg_mod, iput_key, icls_tip) ensuring universal input support across all GUI widgets, editors, and terminal consoles.

Component / APISource FileTechnical Description
TIP IFE (Input Front End) src/tip/tip_ife.c Romaji-to-Hiragana finite state machine, pre-edit buffer composition (TIP_CNV), caret tracking (TIP_CAR), and output commit dispatch (TIP_OUT).

Transliteration & Functional Key Rules (ファンクションキー変換機能)

  • [F6] 平仮名変換 (Hiragana): 即座に未確定文字列を全角ひらがなへ転換（例: ナカノデス → なかのです）。
  • [F7] 全角片仮名変換 (Fullwidth Katakana): 未確定文字列を全角カタカナへ転換（例: なかのです → ナカノデス）。
  • [F8] 半角片仮名変換 (Halfwidth Katakana): 濁点・半濁点・促音を結合したJIS半角カナへ転換（例: がっこう → ｶﾞｯｺｳ）。
  • [F9] 全角英数変換 (Fullwidth Alphanumeric): 英数字・記号をJIS全角コードへ転換（例: BTRON 3.20 → ＢＴＲＯＮ　３．２０）。
  • [F10] 半角英数変換 / 変換確定: 英数小文字・大文字トグルおよびダイレクト確定。

2. TRON Code Multilingual Character Planes (TRON文字コード体系)

B-System implements the entire 16-plane TRON Multilingual Character Architecture, accommodating over 180,000 distinct kanji, classical glyphs, and international scripts without code collision:

  • 第1面 (Plane 1 - JIS 基本文字): JIS X 0208 基本漢字、非漢字記号、第一水準・第二水準漢字。
  • 第2面 (Plane 2 - 補助漢字・拡張): JIS X 0212 補助漢字、JIS X 0213 第3・第4水準漢字、人名用漢字。
  • 第3面 (Plane 3 - 中国語簡体字): GB 2312 規格中国大陸標準文字セット。
  • 第4面 (Plane 4 - 韓国語ハングル・ハンチャ): KS C 5601 規格韓国語文字セット。
  • 第5面〜第9面 (Planes 5-9 - 諸橋大漢和・古典漢字): 『大漢和辞典』完全収録漢字約5万字、古典籍・変体仮名・甲骨文字・金文。
  • 第10面〜第16面 (Planes 10-16 - チベット・サンスクリット・異体字): チベット文字、梵字（悉曇・Siddham）、仏教典籍異体字、GT文字セット。

3. Extended Wylie Tibetan (EWTS) Subsystem (チベット語Wylie変換基盤)

Implemented in src/kernel/tip/wylie.c and verified by src/kernel/tip/test_wylie.c (ported directly from the canonical Erlang implementation by Namdak Tonpa), the Wylie engine provides real-time ASCII-to-Tibetan Unicode transcoding with complete subjoining and stack resolution.
