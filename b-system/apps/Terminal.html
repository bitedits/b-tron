Terminal

TRON端末
Clean, Fast TRON Code & Unicode Terminal
← Back to B-System Applications
"Full TRON Code and Unicode terminal — shell sessions become live Virtual Bodies in any TAD document"

Overview

Clean, fast terminal with full TRON Code / Unicode support. Running shell sessions and output logs can be embedded as live Virtual Bodies into TAD documents or the Workbench canvas.

ターミナル： TRONコード体系および最新Unicodeに完全準拠した、軽快で高機能な端末エミュレータ。実行中のシェルセッションや出力ログをそのまま「生きた仮想オブジェクト」としてTAD文書やワークベンチへ貼り付け可能。

Key Features

  • TRONコード多言語文字コード＆Unicode完全ネイティブ表示
  • 端末出力やシェルセッションの仮身オブジェクト化
  • 低遅延VirtIO-Console & POSIXサブシステム連携
  • Split panes, tabbed sessions, and detachable session Virtual Bodies
  • Shell output can be dragged as a Real Body directly into T-Editor for documentation
  • Integrates with Commander for one-click directory navigation

Typical Workflow

  1. Open a shell session in Terminal.
  2. Run a command; select the output block and drag it — it becomes a Real Body attached to the session.
  3. Drop the output Real Body into a T-Editor document as an inline Virtual Body for reproducible documentation.
  4. Miniaturise the Terminal window from Workbench — it persists as a live Virtual Body in the corner of your canvas.
