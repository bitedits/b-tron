T-Editor

TADエディタ
Native Hypermedia TAD Document Editor (TAD API)
← Back to B-System Applications
"The native TAD authoring environment — deeply connected to the TAD API for text, vector graphics, Virtual Bodies, and hypermedia in one document."

Overview

Premier hypermedia document editor implemented in src/apps/t_editor.c and deeply connected to the BTRON TAD API (tad_browser.h, vobj.h). Directly structures, reads, and writes BTRON3 SPEC 3.20 binary TAD segments (text page, ruler, character font, vector figures, and Virtual Body fusen links). Features full multilingual input via Mozc TIP and smooth collaborative document workflows.

Tエディタ： BTRON TAD API（tad_browser.h、vobj.h）に直結した公式ネイティブ・ハイパーメディア文書編集環境実装（src/apps/t_editor.c）。テキスト、ベクター図形セグメント、仮想オブジェクト（仮身）、各種メディアを単一のバイナリTAD文書内で自在に融合。強力な多言語入力（TRONコード・多言語プレーン）とスムーズな実身・仮身リンク網形成をサポート。

Key Features & Implementation

  • 実体コード実装：src/apps/t_editor.c（TAD文書エディタ open_t_editor_window、セグメント操作）
  • テスト検証基盤：src/apps/test_editor_ui.c（UIレンダリング・セグメント編集検証）
  • TAD API直結による規格準拠バイナリセグメント編集（Text, Ruler, Font, VOBJ Fusen）
  • Mozc TIP連携による高度な漢字変換・多言語TRONコード文字入力
  • 実身（Real Body）と仮身（Virtual Body）の自由な埋め込み・展開・リンク網形成
  • Paintで作成したネイティブTADベクター図形セグメントのインライン埋め込み
  • CRDTベースの差分マージによるリアルタイム共同編集サポート
  • TADキャビネット構造、PDF、プレーンテキストへの双方向エクスポート

Typical Workflow

  1. Open a new or existing TAD document; the TAD API parses binary segments into the document model.
  2. Type multilingual text using Mozc TIP for kanji and TRON Code for multilingual planes.
  3. Drag a vector illustration from Paint — it embeds as a native TAD figure primitive segment (resolution-independent).
  4. Insert a Virtual Body linking to an external document, research note, or media stream.
  5. Save changes via the TAD API to write valid, spec-compliant BTRON3 TAD binary records.
