Overview

Keyboard layouts, key repeat and full MOZC + TRON Code configuration.

TRONキーボード配列・親指シフト・JIS/US配列切替、キーリピート速度、Mozc TIPかな漢字変換エンジン統計モデル、TRONコード直接入力モードの完全カスタマイズ。

Configuration Options

  • TRON keyboard, Oyayubi-shift, JIS, and US layout selection
  • Key repeat rate and initial delay
  • Mozc TIP statistical model: Google NGram, user dictionary
  • TRON Code direct input mode configuration
  • Mouse pointer speed, scroll direction, and gesture bindings
  • Input device hot-plug detection (VirtIO HID)
