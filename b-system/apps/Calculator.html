Calculator

高精度電卓
Precise Scientific Calculator with History
← Back to B-System Applications
"Drag any result or formula out as a Virtual Body — paste live numbers directly into TAD documents"

Overview

Precise calculator with history log, scientific functions and unit conversions. Results and formulas can be dragged out as Virtual Bodies and pasted directly into TAD documents or spreadsheet segments.

電卓： 計算履歴ログ、科学計算、単位変換を備えた高精度電卓。計算結果の数値や算出式そのものを仮想オブジェクトとしてドラッグし、TAD文書や表計算シートへ即座に貼り付け可能。

Key Features

  • 任意精度演算と包括的な計算履歴ジャーナル
  • 計算結果・数式のドラッグ＆ドロップ仮想オブジェクト化
  • 研究用途に最適な単位換算・科学関数ライブラリ
  • History journal stored as Real Bodies searchable from Clarity
  • Formula Virtual Bodies update live when their input variables change
  • Accessible from the Workbench quick-launch bar

Typical Workflow

  1. Open Calculator; type a scientific expression.
  2. The result appears in the history journal as a timestamped Real Body.
  3. Drag the result Virtual Body into a T-Editor document — the number stays linked to the original formula.
  4. When the formula changes, the embedded Virtual Body reflects the new value live.
