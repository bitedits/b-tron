ブート設定（Boot） — B-Systemの多重ハードウェア起動シーケンスおよびハードウェア実値探索パイプラインを統括するブートマネージャ仕様。
"Unified multi-architecture boot manager: single-stage ELF deployment, hardware probing, and preemptive SMP core rendezvous."

概要 (Overview)

B-Systemブートマネージャ（src/kernel/core_boot.c, src/apps/test_ski.c）は、従来の多段階チェーンローダー（MBR/VBR）を廃止し、ダイレクトMultiboot単一ステージ読み込みを採用しています。Raspberry Pi（ARM MMIO）、x86_64 UEFI SMP（ACPI MADT）、NEC PC-98（i386 リアルモード）の各アーキテクチャに対し、固定モックを排したハードウェア実値探索（CPU MSR、IO-APIC、HPET、PC-98ポート）を行い、カーネルエントリポイントへ制御を委譲します。
"B-System boot manager implements single-stage Multiboot ELF loading without fragile MBR/VBR chainloaders, dispatching across ARM, x86_64 UEFI, and PC-98 targets."

Ski インタラクティブ操作仕様 (Interactive Keyboard Bindings)：
・[↑ / ↓] または [W / S]：起動ターゲット（OS／カーネル）のカーソル移動。
・[E]：起動コマンドライン引数（コンソールボーレート、ルートFS等）のインライン編集。
・[+] / [-]：割り当てCPUコア数の動的スケーリング。
・[Enter]：選択ターゲットの起動実行（SMP環境ではAPコアのSIPI整列後にジャンプ）。
・[S]：緊急低レベルT-Monitorデバッグシェルへの直接フォールバック。

1. マルチブート構造と起動機構 (Direct Multiboot & Hardware Discovery)

ファームウェアから1MBメモリ空間への単一ステージ展開およびハードウェア実値探索パイプラインの仕様。
"Single-stage Multiboot 1 execution model (0x1BADB002) and direct hardware register query pipeline."

機構・パイプライン名 動作概要と機能仕様 (Functional Specification) 技術仕様・C99実装 (C99 Architecture)
ダイレクト Multiboot 単一ステージ
(Single-Stage Multiboot)		 2段階MBR/VBRローダーを完全撤廃。ELFバイナリ（0x1BADB002ヘッダ）をハイパーバイザおよびファームウェアが1MB物理RAMへ直接展開。 src/kernel/core_boot.c
Multiboot 1 Header (0x1BADB002)
配置アドレス: 0x00100000 (1 MB)
ハードウェア実値探索
(Zero-Mock Probing)		 固定モック文字列を排し、CPU MSR、CPUIDリーフ、IO-APIC MMIO、HPETカウンタ、PC-98固有ポートからハードウェア属性を直接取得。 btron/core.h フック
MSR: IA32_APIC_BASE (0x1B)
I/O: 0xF2 (A20), 0x21/0xA1 (PIC)
ポリモーフィックカーネル委譲
(Polymorphic Delegation)		 core_boot.c がシーケンス調停役となり、ハードウェア初期化およびメモリログ出力をプラットフォーム別ドライバへ透過委譲。 btron_core_banner()
btron_core_init()
btron_core_mem_log()
緊急 T-Monitor フォールバック
(T-Monitor Fallback)		 デバイスツリー異常またはカーネルフォールト発生時、低レベルROMモニタ（T-Monitor）へ自動退避し、システムデバッグを継続。 キーコード: [S]
tmonitor_entry() デバッグベクタ

4. 起動ワークフロー (Typical Boot Workflow)

システム電源投入からBTRONデスクトップ環境立ち上げまでの標準シーケンス。
"Standard five-phase execution pipeline from cold power-on display activation to BTRON workstation shell handoff."

フェーズ 処理内容 (Execution Stage) 所要時間・制御レジスタ (Timing & Registers)
Phase 1: ディスプレイ初期化 電源投入後、ネイティブディスプレイ（UEFI GOP、Pi VideoCore Mailbox、PC-98 プレナーVRAM）を即時アクティブ化。 T < 50 ms
フレームバッファアドレス確定
Phase 2: Ski ターゲット選択 利用可能なOS・カーネル・ハードウェアターゲットを一覧表示。キーボード（[↑/↓], [W/S]）による選択待機。 インタラクティブ UI
デフォルト待機: 3 秒
Phase 3: 引数・コア数調整 [E]キーでコマンドライン引数を編集、[+]/[-]キーで割り当てCPUコア数をスケール。 引数バッファ: boot_args[]
コア数: smp_core_count
Phase 4: SMP コア整列 [Enter]押下時、BSPコアがLAPIC SIPIシーケンスを発行して全APコアを整列させ、カーネルエントリへジャンプ。 INIT-SIPI-SIPI シーケンス
ベクタ: 0x00009000
Phase 5: BTRON ハンドオフ ブートハンドオフ完了後、選択されたカーネルおよびBTRONワークステーション空間（src/desktop/desktop.c）へ制御移譲。 btron_main()
デスクトップ描画開始
