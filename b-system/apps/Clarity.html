Minimal Knowledge & Reading Environment (TAD API)

"Instant-search knowledge hub – read, annotate, and retrieve any TAD Real Body in milliseconds via the TAD API."

Overview

Minimal knowledge and reading environment powered by the TAD browser core (src/apps/tad_browser.c) and Mozc TIP instant-indexing subsystems (src/tip/mozc_kkc.c, src/tip/tip_vobj.c), deeply connected to the TAD API (tad_browser.h, vobj.h, omgr.h). Features beautiful multilingual typography, millisecond instant search across all indexed Real Bodies, and zero-friction capture of reading notes, research pages, and media as permanent TAD Real Bodies linked directly to their source documents.

クラリティ： TADブラウザー基盤（src/apps/tad_browser.c）およびMozc TIPインデックス連携（src/tip/mozc_kkc.c, src/tip/tip_vobj.c）に直結した、思考を妨げないミニマルな知識・読書環境。洗練された日本語・多言語タイポグラフィ、全TAD実身データベースを対象としたミリ秒単位の瞬時インデックス検索、ノートやWebページ、注釈メディアを永続的なTAD実身として摩擦ゼロで記録・蓄積。

Key Features & Implementation

  • 実体コード実装：src/apps/tad_browser.c（TADドキュメントブラウザー open_tad_browser_window）
  • 瞬時インデックス検索：src/tip/mozc_kkc.c ＆ src/tip/tip_vobj.c（実身全文検索）
  • 和欧混植を極めた美しい組版とリーディングビュー（TRON Code + Unicode）
  • TAD APIを介した全実身データベースの横断インデックス瞬時検索（ミリ秒単位）
  • ゼロ・フリクションなノート＆メディアキャプチャ（TAD Real Body直接生成）
  • Voice-to-text annotation captured as linked Real Bodies
  • Reading progress, bookmarks, and highlights persist inside the TAD object itself
  • Global search indexes TAD Cabinet documents, Browser-converted pages, and Living Book annotations simultaneously

Why the Market Needs It

  • Knowledge workers need a zero-friction read-annotate-search loop across multilingual texts, code, media, and notes.
  • Existing BTRON note apps separate the note store from the document store, forcing disruptive context switches.
  • Provides a unified, millisecond search across TAD Real Bodies, notes, media, and web-converted documents via standard TAD APIs.

Replaces / Normalises

Classic BTRON ProductB-System AdvantageTarget Users
B-TRON Notebook / MemoPad Millisecond global search across every TAD Real Body, not just an isolated note store Knowledge workers, academics, multilingual research teams, documentation authors
Traditional PDF-reader with static notes Notes, media and annotations stored as TAD Real Bodies co-located with the source object via TAD API

Typical Workflow

  1. Open a TAD document, research paper, or Browser-converted Real Body in Clarity's reading view.
  2. Highlight a passage → instantly creates a linked note Real Body attached to that segment via TAD API.
  3. Voice-record a thought → saved as an audio Real Body linked to the highlighted range.
  4. Use the global search bar to jump to any note, annotation, or related object across the entire knowledge base.
  5. Drag any captured note into T-Editor or link it as a Virtual Body in a research report.
