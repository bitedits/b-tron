Language & TRON Code — System language, character planes and font rules.

Overview

System language, character planes and font rules.

多言語システム言語、TRON文字コード面（第1面〜第16面・超漢字収容18万文字）、古代文字・異体字プレーン、文字フォント優先順位（フォールバック）規則。

Configuration Options

  • System UI language selection (Japanese, English, multilingual)
  • TRON Code planes 1–16: 180 000+ kanji and historical characters
  • Variant and archaic character plane activation
  • Font fallback chain: TRON Code → Unicode → system default
  • Locale settings: date, time, number, and currency formats
  • Right-to-left and vertical writing layout support
