1.10 Система (System)管理機能

Система (System)管理機能 , 下記 ような機能 提供している.

  • 例外処理
  • OS構成情報 取得

1.10.1 データ / 定数 定義

□ OSバージョン

Система (System)管理機能 та して OS バージョン 取得機能 用意されている. 

typedef struct {
    UH  maker;      /* メーカー */
    UH  id;         /* Формат / Синтаксис番号 */
    UH  spver;      /* 仕様書バージョン */
    UH  prver;      /* 製品バージョン */
    UH  prno[4];    /* 製品管理情報 */
    UH  cpu;        /* CPU 情報 */
    UH  var;        /* バリエーション記述子 */
} T_VER;

1.10.2 Системні виклики

def_exc
 
例外処理ハンドラ定義

【Формат / Синтаксис】

ERR def_exc(W exckind, FP exchdr)

【Параметри】

W   exckind 例外要因(インプリメント依存)
FP  exchdr  例外処理ハンドラ開始アドレス
            NULL    例外処理ハンドラ 定義解除

【Значення, що повертається】

＝ 0    正常
＜ 0    エラー(Коди помилок)

【Опис та функціонал】

指定した例外要因 対応する自Задача (Task) 例外処理ハンドラ 定義する.

同じ要因 対する例外処理ハンドラ す 定義されている場合 , 後から定義した例外処理ハンドラ 有効 та なる.

例外要因 内容 インプリメント 依存する.

【Коди помилок】

ER_ADR  : アドレス(exc_hdr) アクセス 許されていない. 
ER_CTX  : コンテキストエラー(使用不可 Системні виклики 発行した). 
ER_PAR  : Параметри 不正 ある(exc_vec 定義した例外要因 不正).
ret_exc
 
例外処理ハンドラ終了

【Формат / Синтаксис】

VOID    ret_exc(W ret)

【Параметри】

W   ret リターン指定
＝ 0
例外 発生した位置から実行 再開し, 本Системні викликиから 戻らない. 再開 不可能な種類 例外 場合 , Процес (Process) 異常終了する.
≠ 0
例外 発生した位置から 再開せず , 本Системні викликиから戻って, そ まま実行 続行する. こ 場合, 通常 ハンドラ 最後 longjmp () より制御 他へ移行す るこ та なる.

【Значення, що повертається】

リターンしない (ret = 0  時)
＝0   正常 (ret≠ 0  時)

【Опис та функціонал】

例外処理ハンドラ 終了する.

例外処理ハンドラ 最後 必ず本Системні виклики 実行しなくて いけない. また, 本Системні виклики 例外処理ハンドラ内 み発行するこ та き, それ以外 部分 発行された時 Система (System)エラー та なる.

【Коди помилок】

発生しない.

get_ver
 
バージョン 取得

【Формат / Синтаксис】

ERR get_ver(T_VER* version)

【Параметри】

T_VER*  version バージョン 格納領域

【Значення, що повертається】

＝0    正常
＜0    エラー(Коди помилок)

【Опис та функціонал】

OS バージョン 取り出す.

T_VER TRON 体系 共通 以下 構造体 ある. 

    typedef struct {
        UH  maker;      -- メーカー
        UH  id;         -- Формат / Синтаксис番号
        UH  spver;      -- 仕様書バージョン
        UH  prver;      -- 製品バージョン
        UH  prno[4];    -- 製品管理情報
        UH  cpu;        -- CPU 情報
        UH  var;        -- バリエーション記述子
    } T_VER;

【Коди помилок】

ER_ADR  : アドレス(version) アクセス 許されていない.
get_cnf
 
コンフィグレーション情報 取得

【Формат / Синтаксис】

WERR    get_cnf(TC* name, VP value, W len)

【Параметри】

TC* name    コンフィグレーション項目名

VP  value   コンフィグレーション情報 格納領域

W   len     コンフィグレーション情報 格納領域 バイトРозмір (Size)

【Значення, що повертається】

＝ 0    正常(W  数値情報)
＞ 0    正常(TC 文字列情報：文字数)
＜ 0    エラー(Коди помилок)

【Опис та функціонал】

指定した項目名 Система (System) コンフィグレーション情報 取り出す.

コンフィグレーション情報 W 数値また TC 文字列 あり, 関数値 より区別される.

関数値 = 0 :
W 数値情報
関数値 > 0 :
TC 文字列情報
関数値 文字数 , 文字列 最後 0 格納される.
格納領域 不足する та き 格納領域 Розмір (Size)分 み格納される.

コンフィグレーション情報 項目名 インプリメント 依存する.

【Коди помилок】

ER_ADR      : アドレス(name) アクセス 許されていない. 
ER_NOEXS    : 項目名(name) 存在していない. 
ER_PAR      : Параметри 不正 ある.
