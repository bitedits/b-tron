1.5 Оперативна пам'ять (Memory)管理

1.5.1 Оперативна пам'ять (Memory)管理функціонал / підсистемаの概要

データОперативна пам'ять (Memory)領域には以下に示す 3 種類があり, それぞれの領域に対して指定した大きさのОперативна пам'ять (Memory)ブロックの獲得 / 解放等のфункціонал / підсистемаを提供している.

ローカルОперативна пам'ять (Memory)領域 :

1 つのПроцес (Process)内でのみ使用可能なОперативна пам'ять (Memory)領域であり, 他のПроцес (Process)からはアクセスできない.
ローカルОперативна пам'ять (Memory)として確保した領域は, Процес (Process)終了時に自動的に解放される.

共有Оперативна пам'ять (Memory)領域 :

すべてのПроцес (Process)から使用可能なОперативна пам'ять (Memory)領域である.
獲得したПроцес (Process)の存在とは無関係に存在するが, 獲得したПроцес (Process)の終了時に自動的に解放することもできる.

システムОперативна пам'ять (Memory)領域 :

システム ( OS やПристрій (Device)ドライバー等 ) からのみ使用可能なОперативна пам'ять (Memory)領域である. прикладний додаток / програмаПроцес (Process)からは使用できない.
Процес (Process)とは無関係に存在する.

基本的にはブロック単位 ( 例えば 4KB 単位 ) でОперативна пам'ять (Memory)を割り当てるфункціонал / підсистемаのみを OS は提供する. さらに細かく内部を分割するのはライブラリ, またはприкладний додаток / програма自身で行う. 通常は, системний виклик (System Call)を直接使用せずにライブラリを利用する. ライブラリのфункціонал / підсистемаでは不十分な場合のみсистемний виклик (System Call)を直接利用する.

獲得したОперативна пам'ять (Memory)ブロックは連続した ( 論理 ) адреса пам'ятіを持ち, その先頭 ( 論理 ) адреса пам'ятіがприкладний додаток / програмаに戻される. 一度獲得したОперативна пам'ять (Memory)ブロックの ( 論理 ) адреса пам'ятіは変更されることはないため, 得られたадреса пам'ятіにより直接Оперативна пам'ять (Memory)ブロックをアクセスすることができる. 獲得したОперативна пам'ять (Memory)ブロックへのデータの書込み / 読込みは自由にできるが, 原則として実行することはできない.

Оперативна пам'ять (Memory)管理функціонал / підсистемаのある CPU の場合には, 原則として, 共有Оперативна пам'ять (Memory), システムОперативна пам'ять (Memory)は負のадреса пам'ятіとなり, ローカルОперативна пам'ять (Memory)は正のадреса пам'ятіとなる. CPU の種類によってはこの原則通りにならない場合がある. また, Оперативна пам'ять (Memory)管理функціонал / підсистемаのない CPU の場合は, この限りではない.

Оперативна пам'ять (Memory)に対する排他アクセス制御のфункціонал / підсистемаはないので, 必要であればСемафор (Semaphore)などを利用してприкладний додаток / програмаで行う.

1.5.2 データ／定数の定義

□ Оперативна пам'ять (Memory)属性

#define M_COMMON        0x00000001      /* 共有 */
#define M_SYSTEM        0x00000003      /* システムのみ */
#define M_RESIDENT      0x00004000      /* 常駐 */

□ Оперативна пам'ять (Memory)状態

typedef struct m_state {
        W       blksz;          /* ブロックрозмір у байтах */
        W       total;          /* 全ブロック数 */
        W       free;           /* 残りブロック数 */
} M_STATE;

1.5.3 системний виклик (System Call)

get_mbk
 
Оперативна пам'ять (Memory)ブロックの獲得

【Синтаксис / Прототип】

ERR get_mbk( VP *adr, W nblk, UW atr )

【Параметри】

VP  *adr    獲得したОперативна пам'ять (Memory)ブロックの先頭адреса пам'ятіを返す領域
W   nblk    獲得するОперативна пам'ять (Memory)ブロック数( > 0)
UW  atr     Оперативна пам'ять (Memory)ブロックの属性
            [ (M_COMMON ‖ M_SYSTEM) ] | [M_RESIDENT] | [DELEXIT]
M_COMMON :

共有Оперативна пам'ять (Memory)を指定する.
共有Оперативна пам'ять (Memory)は, すべてのПроцес (Process)からアクセス可能.

M_SYSTEM

システムОперативна пам'ять (Memory)を指定する.
システムОперативна пам'ять (Memory)は, システム ( OS やПристрій (Device)ドライバー等 ) からのみアクセス可能. この指定は, прикладний додаток / програмаПроцес (Process)からは使用してはいけない.

M_COMMON, M_SYSTEM のいずれの指定もなければ, ローカルОперативна пам'ять (Memory)となる. ローカルОперативна пам'ять (Memory)は, Оперативна пам'ять (Memory)ブロックを獲得したПроцес (Process)からのみアクセス可能.

※ 共有 / システム / ローカルОперативна пам'ять (Memory)の指定は, Оперативна пам'ять (Memory)管理функціонал / підсистемаがない CPU の場合には特に意味を持たない. いずれも同じ扱いとなってしまい, 保護されない.

M_RESIDENT :

常駐を指定する. 指定がなければ非常駐となる.

常駐指定されたОперативна пам'ять (Memory)ブロックは, ディスクなどにスワップアウトされることなく常に主Оперативна пам'ять (Memory)上に存在する.

※ 仮想記憶を行っていないシステムの場合には, 特に意味を持たない(常駐と同等になる).

DELEXIT :

Процес (Process)終了時削除を指定する.

この指定があると, Оперативна пам'ять (Memory)ブロックを獲得したПроцес (Process)が終了すると自動的にОперативна пам'ять (Memory)ブロックが解放される. ただし, ローカルОперативна пам'ять (Memory)の場合は, この指定の有無に関係なく, Процес (Process)の終了時に解放される.

【Значення, що повертається】

＝0  Успішне виконання
＜0  Помилка(код помилки)

【Детальний опис】

nblk 個の連続したОперативна пам'ять (Memory)ブロックを獲得し, その先頭адреса пам'ятіを *adr に返す.

【Коди помилок】

er_adr      : адреса пам'яті(adr)のアクセスは許されていない. 
er_nomem    : Оперативна пам'ять (Memory)領域が不足した. 
er_nospc    : システムのОперативна пам'ять (Memory)領域が不足した. 
er_par      : параметриが不正である. 
er_ctx      : 不正なコンテキストから呼び出した.
rel_mbk
 
Оперативна пам'ять (Memory)ブロックの解放

【Синтаксис / Прототип】

ERR rel_mbk( VP adr )

【Параметри】

【Значення, що повертається】

＜ 0 Помилка(код помилки)

【Детальний опис】

adr で示すОперативна пам'ять (Memory)ブロックを解放する. adr は get_mbk() で得たадреса пам'ятіでなければならない.

【Коди помилок】

mbk_sts
 
Оперативна пам'ять (Memory)状態参照

【Синтаксис / Прототип】

ERR mbk_sts( M_STATE *sts )

【Параметри】

M_STATE   sts   Оперативна пам'ять (Memory)状態を返す領域

typedef struct  m_state {
    W   blksz;  /* ブロックрозмір у байтах */
    W   total;  /* 全ブロック数 */
    W   free;   /* 残りブロック数 */
} M_STATE;

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

現在のОперативна пам'ять (Memory)使用状況などを取得する.

blksz :
Оперативна пам'ять (Memory)割り当ての単位( 1 ブロック)のバイト数.
一般には CPU のページрозмір у байтахとなる. 標準的には 4KB.
total :
システム全体の総ブロック数.
free :
システム全体の未使用ブロック数.

仮想記憶を行っているシステムでは, 全ブロック数, 残りブロック数が一意に決定できない場合がある. したがって, 具体的な意味はインプリメントに依存する. ただし, free ÷ total が残りОперативна пам'ять (Memory)の割合の参考値となるような値とする.

インプリメントにより, 具体的な値が設定できない場合は, 全ブロック数, 残りブロック数ともに -1 を設定するものとする.

【Коди помилок】

ER_ADR      : адреса пам'яті(sts)のアクセスは許されていない.

非常駐システムОперативна пам'ять (Memory)から指定したрозмір у байтахのОперативна пам'ять (Memory)を割り当て, その先頭адреса пам'ятіを戻す.

※ прикладний додаток / програмаПроцес (Process)からは使用できない.

Vcalloc
 
非常駐システムОперативна пам'ять (Memory)の獲得(ライブラリ)
Оперативна пам'ять (Memory)属性：M_SYSTEM

【Синтаксис / Прототип】

void*   Vcalloc( size_t nelem, size_t elsize )

【Параметри】

size_t  nelem   獲得したい要素数(> 0)
size_t  elsize  1 要素のバイト数(> 0)

【Значення, що повертається】

≠NULL  Успішне виконання(獲得したОперативна пам'ять (Memory)адреса пам'яті)
＝NULL  Помилка

【Детальний опис】

非常駐システムОперативна пам'ять (Memory)から elsize の大きさの nelem 個の要素を格納する領域を割り当て, その先頭адреса пам'ятіを戻す. 割り当てた領域は 0 で初期化される.

※ прикладний додаток / програмаПроцес (Process)からは使用できない.

Vrealloc
 
非常駐システムОперативна пам'ять (Memory)の再獲得(ライブラリ)
Оперативна пам'ять (Memory)属性：M_SYSTEM

【Синтаксис / Прототип】

void*   Vrealloc( void *ptr, size_t size )

【Параметри】

void    *ptr    розмір у байтах変更したい領域のадреса пам'яті
                NULL を指定した場合は新規獲得
size_t  size    再獲得したいОперативна пам'ять (Memory)のバイト数(≧0)
                0 を指定した場合は解放

【Значення, що повертається】

≠NULL  Успішне виконання(獲得したОперативна пам'ять (Memory)адреса пам'яті)
＝NULL  Помилка

【Детальний опис】

非常駐システムОперативна пам'ять (Memory)中の ptr で指定される領域のрозмір у байтахを size に変更して再獲得し, その先頭адреса пам'ятіを戻す.
ptr は, Vmalloc(), Vcalloc(), Vrealloc() で返されたадреса пам'ятіでなければならない.

※ прикладний додаток / програмаПроцес (Process)からは使用できない.

Vfree
 
非常駐システムОперативна пам'ять (Memory)の解放(ライブラリ)

【Синтаксис / Прототип】

void    Vfree( void *ptr )

【Параметри】

void    *ptr    解放したい領域の先頭адреса пам'яті

【Детальний опис】

ptr で指定された非常駐システムОперативна пам'ять (Memory)内の領域を解放する.
ptr は, Vmalloc(), Vcalloc(), Vrealloc() で返されたадреса пам'ятіでなければならない.

※ прикладний додаток / програмаПроцес (Process)からは使用できない.
