【Параметри】

iput_key
 
テキスト入力ポートへ キー入力

【Формат / Синтаксис】

WERR    iput_key(W tipid, EVENT *evt)

【Параметри】

W       tipid   テキスト入力ポートID
EVENT   *evt    キーПодія (Event)

【Значення, що повертається】

≧0    正常(関数値 テキスト入力ポート 変化状態)
＜0    エラー(Коди помилок)

【Опис та функціонал】

tipid 指定したテキスト入力ポート *evt 指定したキー入力Подія (Event) ( EV_KEYDWN また EV_AUTKEY ) 入力し, そ 結果 テキスト入力ポート 状態 オープン時 割り当てた TIPREC 戻す.

関数値 та して, テキスト入力ポート 状態変化 以下 ビット対応 戻される. 何 変化 також 発生しなかった場合 , 関数値 "0" та なる. додаток こ 関数値 応じた適当な処理 行なう必要 ある. 

    TIP_OUT     0x1 確定文節 発生した
    TIP_CNV     0x2 未確定文字列 変更された
    TIP_CAR     0x4 カレット位置 変化した
    TIP_CL      0x8 対象文節 移動した, また 区切り位置 変化した

*evt 指定したПодія (Event) 内容 以下 いずれか 場合 エラー та なり, TIPREC 内容 一切変化しない.

  • Подія (Event) Тип (Type) EV_KEYDWN, EV_AUTKEY 以外 時
  • 文字Код (Code)自体 不正 時
  • ローマ字入力 та して定義されていない文字Код (Code) 組み合せ 時(インプリメント依存)
  • サポートしていない機能 機能キーКод (Code) 時

【Коди помилок】

EX_CKEY     : 変換中文字列 存在しない状態 機能キーКод (Code) 入力された
EX_KEY      : 不正キーКод (Code) ある
EX_LIMIT    : Система (System) 制限 超えた(変換中文字列 長すぎる)
EX_PAR      : Параметри 不正 ある(EV_KEYDWN, また  EV_AUTKEY   ない)
EX_TID      : テキスト入力ポート(tipid) 存在していない

【Опис та функціонал】

str 指定した文字列 , ローマ字Код (Code) 含まない通常 文字Код (Code), [スペース(=0x20)]および[リクワイアードスペース(=0xA0)] みからなる TNULL(0) 終了する文字列 あり, 途中 ローマ字Код (Code) та , [改行]等 特殊文字キーКод (Code), [変換]等 機能キーКод (Code) 含まれている場合 , EX_KEY エラー та なる.

idsp_car
 
カレット Табл. 示

【Формат / Синтаксис】

ERR idsp_car(CARET *car, W mode)

【Параметри】

CARET   *car    カレットデータ

W       mode    Табл. 示 / 消去 / ブリンク指定

【Значення, що повертається】

≧0    正常
<0    エラー(Коди помилок)

【Опис та функціонал】

car 指定したカレット mode 指定 従って, 消去 / Табл. 示 / ブリンクする.

mode = 0:
消去

car->sts ≠0 場合, car->pos, car->height 示されるカレット 消去し, car->sts 0 設定する.
car->sts = 0 場合 何 також 行なわない.

> 0 :
Табл. 示

car->sts = 0 場合, car->pos, car->height 示されるカレット Табл. 示し, car->sts 1 設定する.
car->sts ≠ 0 場合 何 також 行なわない.

< 0 :
ブリンク

ブリンク 間隔 達していた場合, car->sts 値 応じて, car->pos, car ->height 示されるカレット Табл. 示また 消去し, car->sts 更新する.
ブリンク間隔 達していない場合 何 також 行なわない.

ブリンク 場合 , ブリンク 周期以内 周期的 idsp_car (&car, -1) 実行する必要 ある.

カレット Табл. 示 移動する場合 , まず消去 行なった後, カレット 位置, 高さ 変更して, Табл. 示 行なうこ та なる. また, Табл. 示状態 , カレット構造体 Параметри 変更した場合 動作 保証されない.

【Коди помилок】

EX_ADR      : アドレス(car) アクセス 許されていない
