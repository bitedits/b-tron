Browser

ネイティブTADブラウザ
Native TAD Document Browser with Modular HTML-to-TAD Plugin (TAD API)
← Back to B-System Applications
"Pure, deterministic TAD hypermedia viewing at native speed — modular HTML import and rendering delivered via an extensible plugin filter."

Overview

High-performance native BTRON document browser engineered specifically for the TRON Application Databus (TAD). Implemented in src/apps/tad_browser.c, Browser is optimized for navigating native TAD hypermedia networks, rendering vector graphics, embedded Real Bodies, and fusen link trees with zero overhead. Recognizing that modern web browsers suffer from massive complexity and bloat, B-System decouples web browsing into a modular HTML-to-TAD Plugin Filter (src/apps/browser_html_plugin.c, scripts/html2tad.exs). When accessing web content, the plugin converts HTML4/CSS on the fly into clean, native BTRON3 binary TAD segments, keeping the core browser lean, secure, and crash-proof.

ブラウザ： BTRON3 TAD（TRON Application Databus）仕様に完全準拠した超高速ネイティブ文書ブラウザ。実体コードは src/apps/tad_browser.c（TAD描画・ハイパーメディア閲覧エンジン）および src/apps/browser_html_plugin.c（HTML→TAD変換プラグイン）で構成。コアエンジンを純粋なTADバイナリ処理に特化させることで、極限の軽快さと堅牢性を確保。Web（HTML）の閲覧・取り込みは拡張「HTMLプラグイン／フィルター」として分離され、WebページをリアルタイムにネイティブTAD実身バイナリへと自動コンパイルして表示。Web上の情報を永続的かつ編集可能なTAD知識資産として取り込みます。

Key Features & Implementation

  • 実体コード実装：src/apps/tad_browser.c（ネイティブTADドキュメントブラウザ・セグメントパーサー）
  • 拡張プラグイン基盤：src/apps/browser_html_plugin.c（HTML4/CSS→TAD実身変換フィルター）
  • TADハイパーメディア（実身・仮身・ベクター図形・インライン画像）の超高速レンダリング
  • WebページのワンクリックTAD実身化（永続ローカルアーカイブ＆リンク切れ防止）
  • コアエンジンからのWebブラウザ肥大化（JavaScript脆弱性等）の完全排除による高信頼性
  • T-Editorへのシームレスな編集ハンドオフとCabinetへの自動カタログ登録
  • BTRON3 SPEC 3.20およびNASA JPL安全基準を満たすクリーンルームC99実装

Why the Market Needs It

  • Traditional web browsers are monolithic multi-gigabyte applications that crash easily and cannot integrate with native OS hypermedia databases.
  • Separating the fast native TAD viewing engine from the HTML conversion plugin keeps workstation operations completely deterministic.
  • Web research is automatically converted into permanent, searchable TAD Real Bodies instead of ephemeral browser tabs.

Typical Workflow

  1. Open native TAD documents, books, and specifications directly in Browser at blazing speed.
  2. When navigating to an external HTTP/HTML URL, the browser_html_plugin automatically fetches and converts markup into TAD segments.
  3. Browse the rendered TAD page with full vector fidelity and active hyperlink fusens.
  4. Click Save to Cabinet to retain the page as an editable TAD Real Body for research in Notebook or Clarity.
