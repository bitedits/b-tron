Terminal — Console colours, font size, scrollback buffer, cursor style and background transparency.

Overview

Terminal emulation, console colors, typography, scrollback buffer depth and session preferences conforming to B-right/V and Chokanji workstation console specifications.

端末・通信環境設定：B-right/Vおよび超漢字仕様に準拠した端末エミュレータ（gterm）の配色テーマ（グリーン、アンバー、白黒、BTRON青、ライト）、文字フォントサイズ（12/16/20px）、スクロールバック履歴行数、カーソル形状および背景透過度の統合管理。

Configuration Options

  • 配色テーマ (Colour Schemes): Matrix Green, Amber CRT, High-Contrast White, BTRON Cyan on Navy, Paper Light
  • フォントサイズ (Font Sizes): Compact 12px (32x100), Standard 16px (24x80), Large 20px (18x64)
  • スクロール履歴 (Scrollback Buffer): 100 lines, 300 lines (default), 1000 lines
  • カーソル形状 (Cursor Style): Classic Underline (_), Solid Block (█), Vertical Bar (|)
  • 背景透過度 (Dimming & Transparency): 100% Solid, 80% Dimmed (default), 60% Dimmed
  • 文字コード (Encoding): TRON Multilingual Planes, UTF-8 native
