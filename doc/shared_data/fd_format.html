Розділ 4. Формат дискети та файлової системи BTRON FS

4.1 Огляд формату носіїв BTRON

Стандарт BTRON описує бінарну структуру розмітки фізичних носіїв даних (дискет, змінних дисків, твердотілих накопичувачів) та файлову систему BTRON FS, яка підтримує деревовидно-мережеву структуру Реальних та Віртуальних об'єктів (Real/Virtual Objects), фрагментацію блоків і вбудовані індекси записів.

4.2 Структура файлової системи BTRON FS

4.2.1 Загальна схема розміщення блоків

Диск розділений на фізичні сектори (блоки по 512 або 1024 байти). Перший сектор містить системний блок (System Block), за яким слідують таблиці файлів, таблиці фрагментів та область даних.

4.2.2 Структура системного блоку (System Block)

typedef struct {
    B   boot_code[32];  /* Завантажувальний код або сигнатура OS */
    TC  vol_name[12];   /* Назва тома/диска у TRON Code */
    UW  vol_id;         /* Унікальний ID тома */
    UH  blk_size;       /* Розмір блоку у байтах (512, 1024) */
    UW  total_blks;     /* Загальна кількість блоків на томі */
    UW  free_blks;      /* Кількість вільних блоків */
    UW  file_id_tbl;    /* Сектор початку таблиці ID файлів */
    UW  root_f_id;      /* ID кореневого об'єкта (Root Real Object) */
} SYSTEM_BLOCK;

4.2.3 Таблиця ідентифікаторів файлів (File ID Table)

typedef struct {
    UW  file_id;        /* Унікальний ідентифікатор файлу */
    UW  header_blk;     /* Номер першого блоку заголовка файлу (Header Block) */
    UW  file_size;      /* Розмір файлу у байтах */
    UH  attr;           /* Атрибути файлу (системний, лише для читання, захищений) */
} FILE_ID_ENTRY;

4.2.4 Таблиця коротких назв файлів

typedef struct {
    UW  file_id;        /* ID файлу */
    TC  short_name[8];  /* Коротке ім'я файлу у кодуванні TRON Code */
} SHORT_NAME_ENTRY;

Додаток A: Квазі-стандартний формат дискет

Описує сумісність з традиційними форматами дискет 3.5" 1.44MB (MF2HD) та 1.2MB (2HD) для зчитування та запису даних на сумісних приводах накопичувачів.

Додаток B: Приклад практичної реалізації драйвера дискети

Містить приклад низькорівневих команд контролера накопичувача на гнучких магнітних дисках (FDC).
