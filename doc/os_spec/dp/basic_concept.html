2.2 Базові концепції (Basic Concepts)

2.2.1 Координатна площина, точки та прямокутники

Графічна система BTRON базується на дискретній 2D-координатній сітці (Grid) цілих чисел (від -32768 до +32767). Вісь X спрямована зліва направо, вісь Y — зверху вниз. Пікселі розташовуються у проміжках між цілими лініями координат.

Точка (PNT)

typedef struct {
    H   x;      /* Координата X */
    H   y;      /* Координата Y */
} PNT;

Розмір (SIZE)

typedef struct {
    H   w;      /* Ширина (width >= 0) */
    H   h;      /* Висота (height >= 0) */
} SIZE;

Прямокутник (RECT)

typedef struct {
    H   c_left;     /* Ліва межа X */
    H   c_top;      /* Верхня межа Y */
    H   c_right;    /* Права межа X (не включно) */
    H   c_bottom;   /* Нижня межа Y (не включно) */
} RECT;

Прямокутник задається напіввідкритим інтервалом: пікселі [left, right) по горизонталі та [top, bottom) по вертикалі. Ширина = right - left, висота = bottom - top.

2.2.2 Бітові карти (Bitmaps)

Бітова карта — це прямокутна область графічної пам'яті (VRAM або системна пам'ять RAM), де кожен піксель зберігається у вигляді бітової послідовності.

Структура бітової карти (BITMAP / BM_DESC)

typedef struct {
    W       planes;     /* Кількість бітових площин (planes > 0; від'ємне = апаратний VRAM) */
    W       pixbits;    /* Глибина кольору пікселя в бітах (1, 2, 4, 8, 16, 24, 32) */
    H       rowbytes;   /* Байт у рядку растру (Row Bytes) */
    RECT    bounds;     /* Межі растру в координатах бітової карти */
    B       *addr;      /* Вказівник на початок буфера пам'яті */
} BITMAP;

Специфікація графічного пристрою (DEV_SPEC)

typedef struct {
    UW  attr;       /* Атрибути пристрою (Lock, наявність VRAM, Color Map, Color Mode) */
    W   planes;     /* Кількість площин */
    W   pixbits;    /* Біт на піксель */
    H   hpixels;    /* Фізична ширина у пікселях */
    H   vpixels;    /* Фізична висота у пікселях */
    H   hres;       /* Роздільна здатність по горизонталі (пікс/см або -пікс/дюйм) */
    H   vres;       /* Роздільна здатність по вертикалі */
    H   color[4];   /* Біти каналів кольору (RGB / CMY / Gray) */
    H   resv[6];    /* Зарезервовано */
} DEV_SPEC;

2.2.3 Представлення кольору (COLOR)

Колір у BTRON позначається 32-бітним цілим COLOR:

  • Прямий RGB / Прозорий (Transparent) : біт 31 = 1 (прозорий, колір не наноситься).
  • Індексний колір (Color Palette / Color Map) : піксельне значення індексу в палітрі.
  • Абсолютний RGB (0x00RRGGBB) : 8 біт на кожен канал Червоний, Зелений, Синій. 
typedef UW  COLOR;  /* 32-бітне значення кольору */

Специфікація колірної палітри (CSPEC)

typedef struct {
    W       attr;       /* Атрибути кольору */
    H       info[4];    /* Кількість елементів палітри або маски каналів */
    COLOR   *colmap;    /* Вказівник на масив кольорів палітри */
} CSPEC;

2.2.4 Середовище малювання (Drawing Environment / GID)

Середовище малювання (Drawing Environment, дескриптор GID) містить повний поточний графічний контекст для виконання операцій візуалізації:

  • Цільова бітова карта : растр призначення для малювання.
  • Область відсікання (Clip Region) : довільна форма регіону (перетин VisibleRect, FrameRect, ClipRect).
  • Режим растрових операцій (RasterOp / Draw Mode) : копіювання (PAINT), інверсія (XOR), прозоре накладання тощо.
  • Патерн заповнення (PAT) : штриховка або текстура заповнення фігур.
  • Стиль ліній (Pen / Line Style) : товщина пера, суцільна/пунктирна лінія, форма кінців.
  • Кольори тексту, шрифт, кут нахилу та міжсимвольні інтервали.

Режими накладання (Draw Mode / RasterOp)

#define DM_PAINT    0   /* Заміщення пікселів (Source Copy) */
#define DM_OVER     1   /* Накладання поверх з урахуванням прозорості */
#define DM_XOR      2   /* Побітове виключне АБО (Invert / Toggle) */
#define DM_OR       3   /* Побітове АБО */
#define DM_AND      4   /* Побітове І */

Патерн малювання (PAT)

typedef struct {
    SIZE    size;       /* Розмір патерну (зазвичай 8x8, 16x16) */
    H       rowbytes;   /* Байт у рядку */
    B       data[1];    /* Бітова маска патерну */
} PAT;

2.2.5 Виведення тексту та шрифти

Малювання тексту виконується з урахуванням переднього кольору (chfgc), кольору фону символів (chbgc), напрямку виведення (CharacterDirection) та міжсимвольних інтервалів (CharacterGap).

Напрямок виведення тексту (CharacterDirection)

enum CharacterDirection {
    TORIGHT = 0,    /* Зліва направо (горизонтальне письмо) */
    TOLEFT  = 1,    /* Справа наліво */
    TOUP    = 2,    /* Знизу вгору */
    TODOWN  = 3,    /* Згори вниз (вертикальне японське письмо) */
    TOARB   = 4     /* Довільний напрямок за вектором */
};

Міжсимвольні інтервали (CharacterGap / CGAP)

typedef struct {
    H   dir;        /* 0 = в напрямку письма, 1 = у зворотному напрямку */
    UH  gap;        /* Інтервал у пікселях або частках розміру символу */
} SGAP;

typedef struct {
    SGAP    hgap;   /* Горизонтальний інтервал */
    SGAP    vgap;   /* Вертикальний інтервал */
    SGAP    hspgap; /* Додатковий інтервал після пробілу */
    SGAP    vspgap; /* Додатковий вертикальний інтервал після пробілу */
} CGAP;
