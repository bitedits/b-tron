2.5 Функції виводу тексту та символів (Text & Character Functions)

2.5.1 Налаштування параметрів текстового середовища

gset_chp / gget_chp
Set / Get Text Position
Встановлення та отримання поточної позиції виведення тексту

【Синтаксис / Прототип】

ERR gset_chp(GID gid, PNT *pos)
ERR gget_chp(GID gid, PNT *pos)

【Параметри】

GID  gid    Ідентифікатор середовища малювання
PNT *pos    Точка поточної текстової позиції

【Значення, що повертається】

= 0     Успішне виконання (E_OK)
< 0     Помилка (EG_GID, EG_ADR)
gset_chc / gget_chc
Set / Get Text Color
Встановлення та отримання кольору тексту (передній план / фон)

【Синтаксис / Прототип】

ERR gset_chc(GID gid, COLOR fg, COLOR bg)
ERR gget_chc(GID gid, COLOR *fg, COLOR *bg)

【Параметри】

GID   gid   ID середовища малювання
COLOR fg    Колір переднього плану тексту (символу)
COLOR bg    Колір фону під текстом
gset_chd / gget_chd
Set / Get Text Direction and Spacing
Встановлення та отримання напрямку письма й міжсимвольних інтервалів

【Синтаксис / Прототип】

ERR gset_chd(GID gid, W dir, CGAP *gap)
ERR gget_chd(GID gid, W *dir, CGAP *gap)

【Параметри】

GID   gid   ID середовища малювання
W     dir   Напрямок письма (TORIGHT = зліва направо, TODOWN = зверху вниз)
CGAP *gap   Міжсимвольні інтервали (ch_gap, line_gap)
gset_fon / gget_fon
Set / Get Font Specifier
Призначення та зчитування специфікації шрифту FSSPEC

【Синтаксис / Прототип】

ERR gset_fon(GID gid, FSSPEC *spec)
ERR gget_fon(GID gid, FSSPEC *spec, FNTINFO *info)

【Параметри】

GID      gid    ID середовища малювання
FSSPEC  *spec   Специфікація шрифту (гарнітура, розмір, атрибути накреслення)
FNTINFO *info   Буфер для розрахованих метрик шрифту (ширина, висота, базова лінія)
gset_scr / gget_scr
Set / Get Script Language
Встановлення та отримання кодової площини / мовного скрипту

【Синтаксис / Прототип】

ERR gset_scr(GID gid, W script)
ERR gget_scr(GID gid, W *script)

【Параметри】

GID gid     ID середовища малювання
W   script  Код мовної кодової площини TRON Code (наприклад, LANG_JAPAN, LANG_CYRILLIC)

2.5.2 Метрики та вимірювання тексту

gget_chw / gget_chh
Get Character Width / Height
Отримання ширини та висоти окремого символу

【Синтаксис / Прототип】

W gget_chw(GID gid, TC ch)
W gget_chh(GID gid, TC ch)

【Значення, що повертається】

>= 0    Ширина / висота символу у пікселях
 < 0    Помилка (EG_GID, EG_PAR)
gget_stw / gget_sth / gget_str
Get String Metrics / Bounding Box
Вимірювання повної довжини, висоти та обмежувального прямокутника рядка

【Синтаксис / Прототип】

W   gget_stw(GID gid, TC *str, W len)
W   gget_sth(GID gid, TC *str, W len)
ERR gget_str(GID gid, TC *str, W len, RECT *r)

【Параметри】

GID   gid   ID середовища малювання
TC   *str   Вказівник на рядок символів TRON Code
W     len   Кількість символів у рядку
RECT *r     Буфер для збереження обмежувального прямокутника (Bounding Box)

【Значення, що повертається】

>= 0    Довжина / висота у пікселях (для stw / sth) або E_OK (для gget_str)
 < 0    Помилка (EG_GID, EG_ADR, EG_PAR)

2.5.3 Функції малювання символів та рядків

gdra_chr / gdra_chp
Draw Character (Auto / Specified Position)
Малювання символу у поточній або вказаній позиції

【Синтаксис / Прототип】

WERR gdra_chr(GID gid, TC ch, DCM mode)
WERR gdra_chp(GID gid, W x, W y, TC ch, DCM mode)

【Параметри】

GID  gid    ID середовища малювання
W    x, y   Координати виведення символу на площині
TC   ch     Символьний код TRON Code
DCM  mode   Режим растрової операції (DM_PAINT, DM_OVER, DM_XOR)

【Детальний опис】

Виводить символ ch у поточній позиції (або точці x, y). Після виведення позиція автоматично зміщується відповідно до напрямку письма й міжсимвольного інтервалу. Якщо символ перемикає мовний скрипт, функція повертає код нового скрипту (> 0).

【Значення, що повертається】

= 0     Успішне виконання (без зміни мовного скрипту)
> 0     Успішне виконання (повертає ID нового мовного скрипту SCRIPT)
< 0     Помилка (EG_GID, EG_PAR)
gdra_str / gdra_stp
Draw String (Auto / Specified Position)
Малювання рядка символів

【Синтаксис / Прототип】

WERR gdra_str(GID gid, TC *str, W len, DCM mode)
WERR gdra_stp(GID gid, W x, W y, TC *str, W len, DCM mode)

【Параметри】

GID  gid    ID середовища малювання
W    x, y   Початкові координати рядка
TC  *str    Рядок символів TRON Code
W    len    Кількість символів у рядку
DCM  mode   Режим накладання (DM_PAINT, DM_OVER тощо)

【Значення, що повертається】

= 0     Успіх
> 0     Повертає ID підключеного мовного скрипту
< 0     Помилка (EG_ADR, EG_GID, EG_PAR)
gcop_chr
Copy Character Image / Glyph Bitmap
Малювання довільного растрового гліфа символу

【Синтаксис / Прототип】

ERR gcop_chr(GID gid, SIZE asize, SIZE isize, UB *img, DCM mode)

【Параметри】

GID   gid    ID середовища малювання
SIZE  asize  Реальний розмір відображення на екрані (ширина, висота з масштабуванням)
SIZE  isize  Оригінальний розмір растру гліфа у байтах/пікселях
UB   *img    Вказівник на бітову маску зображення символу
DCM   mode   Режим растрової операції (DM_PAINT, DM_OVER, DM_XOR)

【Детальний опис】

Малює растрову маску гліфа img розміром isize, масштабуючи її до розмірів asize. Базова лінія розраховується за формулою: 

Base = asize.v * FNTINFO.base / FNTINFO.height
Мал. 42 : Малювання та масштабування растрового гліфа символу

【Значення, що повертається】

= 0     Успішне виконання (E_OK)
< 0     Помилка (EG_ADR, EG_GID, EG_PAR)
