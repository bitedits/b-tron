Commander

Dual-Pane Object & File Manager
← Back to B-System Applications
"Keyboard-driven dual-pane power — bulk-manage Real and Virtual Bodies with deep TAD link integration"

Overview

Dual-pane object and file manager. Keyboard-driven power with full drag-and-drop of Real and Virtual Bodies and deep TAD link integration.

コマンダー： キーボード主導の高速操作が可能な左右2画面オブジェクト・ファイルマネージャ。実身と仮身の直感的なドラッグ＆ドロップ、深いTADハイパーリンク統合、高速な一括属性変更に対応。

Key Features

  • 熟練研究者のための高速キーボード主導2画面レイアウト
  • 実身と仮身の一括整理・相互リンク自動生成
  • TADキャビネット構造の階層ツリー＆一覧表示
  • Inline attribute editor: change metadata on hundreds of Real Bodies in one keystroke
  • Diff view between two TAD Cabinet trees for sync and archival
  • Integration with Terminal for shell operations from within the file view

Typical Workflow

  1. Open Commander; left pane shows source TAD Cabinet, right pane shows destination.
  2. Select multiple Real Bodies with keyboard shortcuts; press F6 to move or F5 to copy.
  3. Commander auto-creates Virtual Body links in the destination so originals remain accessible.
  4. Use the inline attribute panel to tag, rename, or re-classify all selected objects at once.
