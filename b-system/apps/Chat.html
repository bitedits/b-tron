Overview

Native real-time messaging and team collaboration application categorized under the TAD Applications plane. Implemented in src/apps/chat.c and src/apps/chat_xml.c, Chat is powered by an XMPP protocol core and features a simplified TAD layouter derived from T-Editor. Messages are not restricted to plain text: chat bubbles support inline rich-text formatting (bold, italic, color highlights), interactive Fusen badges (仮身付箋), and live Real Body drops (image snippets, Matrix formulas, and code blocks). Important conversations and research exchanges can be archived permanently as searchable TAD Real Bodies in Cabinet.

チャット： BTRON3 TADアプリケーション層（TAD Application）に位置づけられたリアルタイム対話・共同作業クライアント。実体コードはチャットUI・通信基盤（src/apps/chat.c）およびXMPP/XMLスタンザ処理部（src/apps/chat_xml.c）で構成。

最大の特徴は「T-Editorから継承された簡易TADレイアウター（Simplified TAD Layouter）」です。単なるプレーンテキスト送受信にとどまらず、発言バブル内で見出し・太字・文字色などの簡易リッチテキストや仮身付箋（Virtual Body Fusen）を美しく表示。画像スニペット、Matrix計算式、ソースコードをドラッグ＆ドロップで即座に共有でき、重要な対話ログはそのまま1つのTAD実身（Real Body）としてキャビネットへ永続アーカイブ可能です。

Key Features & Implementation

  • 実体コード実装：src/apps/chat.c（TADチャットUI・簡易レイアウター）
  • XML・XMPP基盤：src/apps/chat_xml.c（XMPPプロトコル・メッセージスタンザパーサー）
  • T-Editor派生の簡易自動TADレイアウターによる美しい発言バブルレンダリング
  • インライン仮身付箋（Fusen）および実身（画像・数式・コード）の直接ドロップ送信
  • Mozc TIP 日本語入力完全対応による高速な日本語リアルタイムチャット
  • 対話ログのワンクリックTAD実身アーカイブ（Cabinet連携）
  • BTRON HMI標準に準拠したクリーンなバディリスト・プレゼンス管理

Why the Market Needs It

  • Modern chat tools (Slack, Discord, Teams) are bloated, track user activity, and silo conversations away from the operating system.
  • Technical teams need an instant, privacy-respecting native XMPP chat client that integrates directly with their local hypermedia workspace.
  • Chat allows research notes, code, and diagrams to be discussed and archived as first-class TAD objects.

Typical Workflow

  1. Open Chat from Deskbar and connect to your team's XMPP collaboration server.
  2. Engage in 1-on-1 direct messaging or multi-user research group channels.
  3. Type messages using Mozc TIP; use simplified TAD formatting for key terms and formulas.
  4. Drag a Virtual Body Fusen link directly from Cabinet into the chat to share a document with colleagues.
  5. Export the entire discussion transcript as a TAD Real Body to include in a T-Editor or Clarity report.
