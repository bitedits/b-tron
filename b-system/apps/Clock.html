Clock

時刻・タイマー
System Clock, Timers & World Time (RTC / μITRON)
← Back to B-System Applications
"High-precision system timekeeping — pure C99 desktop accessory interfacing directly with hardware RTC, HPET, and μITRON timers."

Overview

Lightweight, high-precision system clock and timekeeping utility built in pure C99, backed by the kernel timekeeping subsystems (src/kernel/clk_mgr.c, src/kernel/timer.c, src/kernel/time_calls.c) and hardware RTC drivers (src/drivers/bcm283x/clk/rtc.c). Directly interfaces with the hardware Real-Time Clock (RTC), High Precision Event Timer (HPET), and μITRON kernel timer services (btron/clk.h, btron/timer.h). Features customizable analog and digital clock faces rendered with Display Primitives (dp.h), multiple simultaneous world timezones, millisecond-accurate stopwatch, countdown timers, and system event alarms.

時計： カーネル計時サブシステム（src/kernel/clk_mgr.c, timer.c）およびハードウェアRTC（src/drivers/bcm283x/clk/rtc.c）に直結した純粋C99製システム時計ユーティリティ。TRON Display Primitivesによる高品位なアナログ・デジタル盤面描画、ミリ秒精度のストップウォッチ、カウントダウンタイマー、世界各国の複数タイムゾーン表示、およびシステムアラームを搭載し、低リソースで常駐稼働。

Key Features & Implementation

  • 実体コード実装：src/kernel/clk_mgr.c ＆ src/kernel/timer.c（高精度タイマー・クロック管理）
  • ハードウェアRTC直結：src/drivers/bcm283x/clk/rtc.c（時刻保持・割込み通知）
  • ハードウェアRTCおよびμITRON高精度タイマー直結のジッターフリー計時
  • 純粋C99システム設計（常駐時もCPU負荷最小）
  • Display Primitivesによる鮮明なアナログ針表示およびデジタルLED表示
  • 世界主要都市の複数タイムゾーン同時表示
  • ミリ秒精度ストップウォッチおよびカウントダウンタイマー
  • システムアラーム通知（サウンドおよび画面フラッシュ連動）

Typical Workflow

  1. Clock launches as a compact, floating accessory or docks into the Workbench deskbar.
  2. Set world clocks for your team's locations (Tokyo, Zurich, San Francisco).
  3. Start a countdown timer or precision stopwatch for build benchmarks or tasks.
  4. Configure scheduled alarms that trigger system notifications directly via the μITRON scheduler.
