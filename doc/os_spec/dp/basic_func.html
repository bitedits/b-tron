2.3 Базові функції (Basic Display Functions)

2.3.1 Створення та видалення середовища малювання

gini_dsp
Initialize Display Primitive
Ініціалізація підсистеми графічних примітивів

【Синтаксис / Прототип】

ERR gini_dsp(void)

【Детальний опис】

Виконує початкову ініціалізацію Display Primitives. Зазвичай викликається системою при старті.

【Значення, що повертається / Коди помилок】

= 0 (E_OK) : Успіх
< 0        : EG_NOSP (Нестача системної пам'яті)
gfin_dsp
Finish Display Primitive
Завершення роботи підсистеми графічних примітивів

【Синтаксис / Прототип】

ERR gfin_dsp(void)

【Детальний опис】

Завершує роботу підсистеми Display Primitives та звільняє виділені ресурси.

gcls_env
Delete Drawing Environment
Видалення середовища малювання

【Синтаксис / Прототип】

ERR gcls_env(GID gid)

【Параметри】

GID gid     ID середовища малювання

【Детальний опис】

Видаляє середовище малювання gid. Викликати може лише процес-власник.

【Коди помилок】

EG_GID  : Недійсний дескриптор gid.
gopn_dev
Open Device Drawing Environment
Створення середовища малювання для графічного пристрою

【Синтаксис / Прототип】

GID gopn_dev(TC *dev, B *par)

【Параметри】

TC *dev     Назва графічного пристрою (екрана/вікна)
B  *par     Параметри пристрою

【Значення, що повертається】

>= 0    Дескриптор середовища малювання (GID)
 < 0    Помилка (EG_ADR, EG_DEV, EG_LIMIT, EG_NOEXS, EG_NOSPC)

【Детальний опис】

Створює екземпляр GID, прив'язаний до фізичного екрана чи VRAM пристрою dev.

gopn_mem
Open Memory Drawing Environment
Створення середовища малювання в оперативній пам'яті (Off-screen)

【Синтаксис / Прототип】

GID gopn_mem(TC *dev, BITMAP *bmap, B *par)

【Параметри】

TC     *dev     Назва пристрою (або NULL для універсального середовища)
BITMAP *bmap    Опис цільової бітової карти у пам'яті
B      *par     Параметри кольору CSPEC (NULL = без колірної інформації)

【Значення, що повертається】

>= 0    GID
 < 0    Помилка (EG_ADR, EG_DEV, EG_LIMIT, EG_NOSPC, EG_PAR)

【Детальний опис】

Створює позаекранний графічний буфер у пам'яті RAM для малювання подвійної буферизації.

gnew_env
Duplicate Drawing Environment
Дублювання середовища малювання

【Синтаксис / Прототип】

GID gnew_env(GID gid)

【Детальний опис】

Створює точну копію середовища малювання gid, що розділяє ту саму бітову карту.

gini_env
Reset Drawing Environment
Скидання параметрів середовища малювання до значень за замовчуванням

【Синтаксис / Прототип】

ERR gini_env(GID gid)
gget_spc
Get Device Specification
Отримання характеристик пристрою

【Синтаксис / Прототип】

ERR gget_spc(TC *dev, DEV_SPEC *spec)
gget_dev
Get Drawing Environment Device
Отримання назви пристрою середовища

【Синтаксис / Прототип】

ERR gget_dev(GID gid, TC *dev)
gget_dsp
Get Device Specification by GID
Отримання специфікації пристрою за GID

【Синтаксис / Прототип】

ERR gget_dsp(GID gid, DEV_SPEC *spec)
gget_csp
Get Color Specification
Отримання специфікації кольору середовища

【Синтаксис / Прототип】

ERR gget_csp(GID gid, CSPEC *cspec)
gset_bcs
Set Color Conversion Specification
Встановлення специфікації колірної конверсії

【Синтаксис / Прототип】

ERR gset_bcs(GID gid, CSPEC *cspec)
gget_bcs
Get Color Conversion Specification
Отримання специфікації колірної конверсії

【Синтаксис / Прототип】

ERR gget_bcs(GID gid, CSPEC *cspec)

2.3.2 Управління палітрою (Color Map)

gset_col
Set Color Map Entries
Запис елементів у колірну палітру

【Синтаксис / Прототип】

W   gset_col(GID gid, UW p, COLOR *cv, UW cnt)

【Параметри】

GID     gid     ID середовища малювання
UW      p       Початковий індекс палітри
COLOR  *cv      Масив кольорів для запису
UW      cnt     Кількість записів

【Значення, що повертається】

>= 0    Кількість успішно встановлених кольорів
 < 0    Помилка (EG_ADR, EG_ENV, EG_GID, EG_PAR)
gget_col
Get Color Map Entries
Зчитування елементів колірної палітри

【Синтаксис / Прототип】

W   gget_col(GID gid, UW p, COLOR *cv, UW cnt)
gcnv_col
Convert Color to Pixel Value
Перетворення кольору RGB у значення пікселя

【Синтаксис / Прототип】

W   gcnv_col(GID gid, COLOR cv, PIXVAL *pixv)

【Значення, що повертається】

>= 0    Похибка наближення кольору (0 = точний збіг, 100 = протилежний колір)
 < 0    Помилка

2.3.3 Доступ до параметрів середовища малювання

gset_msk / gget_msk
Set/Get Mask Pixel Value
Встановлення та зчитування маскового пікселя
ERR gset_msk(GID gid, PIXVAL pixv)
ERR gget_msk(GID gid, PIXVAL *pixv)
gset_clp / gget_clp
Set/Get Clipping Region
Встановлення та зчитування області відсікання
ERR gset_clp(GID gid, GRGN *clip)
ERR gget_clp(GID gid, GRGN *clip, W csize, W *a_size)
gset_fra / gget_fra
Set/Get Frame Rectangle
Встановлення та зчитування прямокутника кадру (FrameRect)
ERR gset_fra(GID gid, RECT *rp)
ERR gget_fra(GID gid, RECT *rp)
gset_vis / gget_vis
Set/Get Visible Rectangle
Встановлення та зчитування прямокутника видимості (VisibleRect)
ERR gset_vis(GID gid, RECT *rp)
ERR gget_vis(GID gid, RECT *rp)
gset_for / gget_for
Set/Get Forward Rectangle List
Встановлення та зчитування списку передніх прямокутників перекриття
ERR gset_for(GID gid, RLIST *rlp)
ERR gget_for(GID gid, RLIST *rlp, W size, W *a_size)
gsiz_pat / gcre_pat
Size/Create Pattern Image
Визначення розміру та створення внутрішнього патерну малювання
ERR gsiz_pat(GID gid, UW kind, UW hsize, UW vsize, W *size)
ERR gcre_pat(GID gid, PAT *def, UB *loc, UB **pat, W *size, W cvt)
gset_lmk / gget_lmk
Set/Get Line Mask Pattern
Встановлення та зчитування бітової маски лінії (пунктир)
ERR gset_lmk(GID gid, UW nbytes, UB *mask)
W   gget_lmk(GID gid, UB *mask)
gget_bmp / gget_bnd
Get Bitmap / Bounds
Отримання цільової бітової карти та меж растру
ERR gget_bmp(GID gid, BITMAP *bmap)
ERR gget_bnd(GID gid, RECT *rp)
gmov_bnd / gmov_cor
Move Bitmap Bounds / Coordination
Зсув меж растру та переміщення системи координат
ERR gmov_bnd(GID gid, W dh, W dv)
ERR gmov_cor(GID gid, W dh, W dv)

2.3.4 Перетворення координат та блокування

gcnv_abs / gcnv_rel
Convert Coordinates (Absolute <-> Relative)
Перетворення між абсолютними та відносними координатами
ERR gcnv_abs(GID gid, PNT *pp)
ERR gcnv_rel(GID gid, PNT *pp)
gloc_env
Lock/Unlock Drawing Environment
Блокування / розблокування середовища малювання

【Синтаксис / Прототип】

ERR gloc_env(GID gid, W lock)

【Параметри】

GID gid     ID середовища малювання
W   lock    1 = заблокувати доступ іншим процесам; 0 = розблокувати
