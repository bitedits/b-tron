Clarity

知識環境
Minimal Knowledge & Reading Environment
← Back to B-System Applications
"Instant-search knowledge hub – read, annotate and retrieve any object in milliseconds, never leave your workspace."

Overview

Minimal knowledge and reading environment. Beautiful multilingual typography, instant millisecond search across all Real Bodies, and zero-friction capture of notes, pages and media as permanent Real Bodies linked to their source.

クラリティ： 思考を妨げないミニマルな知識・読書環境。洗練された日本語・多言語タイポグラフィ、全オブジェクトを対象としたミリ秒単位の瞬時検索、ノートやWebページ、メディアを永続的な実身として摩擦ゼロで記録・蓄積。

Key Features

  • 和欧混植を極めた美しい組版とリーディングビュー（TRON Code + Unicode）
  • 全実身データベースを横断するインデックス瞬時検索（ミリ秒単位）
  • ゼロ・フリクションなノート＆メディアキャプチャ
  • Voice-to-text annotation captured as linked Real Bodies
  • Reading progress and highlights persist inside the TAD object itself
  • Global search indexes Workbench objects, Browser-converted pages, and Living Book annotations simultaneously

Why the Market Needs It

  • Knowledge workers need a zero-friction read-annotate-search loop across multilingual texts, code, media and notes.
  • Existing BTRON note apps separate the note store from the document store, forcing context switches.
  • No unified millisecond search across Real Bodies, notes, media, and web-converted documents in classic BTRON tools.

Replaces / Normalises

Classic BTRON ProductB-System AdvantageTarget Users
B-TRON Notebook / MemoPad Millisecond global search across every Real Body, not just the note store Knowledge workers, academics, multilingual research teams
Traditional PDF-reader with static notes (separate app) Notes, media and annotations stored as TAD Real Bodies co-located with the source object

Typical Workflow

  1. Open a TAD document, PDF or Browser-converted Real Body in Clarity's reading view.
  2. Highlight a passage → instantly creates a linked note Real Body attached to that location.
  3. Voice-record a thought → saved as an audio Real Body linked to the highlighted range.
  4. Use the global search bar to jump to any note, annotation, or related object across the entire knowledge base.
  5. Drag any captured note into Workbench or embed it as a Virtual Body in a T-Editor document.
