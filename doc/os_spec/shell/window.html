3.1 Менеджер вікон (Window Management)

3.1.1 Огляд підсистеми віконного менеджера

Менеджер вікон ядра BTRON3 керує багатовіконним середовищем робочого столу, перекриттям вікон у Z-стеку, переміщенням, зміною розмірів, обробкою фокусу введення та графічними елементами рамки вікна (заголовок Titlebar, кнопки згортання/розгортання, полоси прокрутки Scrollbars).

Кожне вікно ідентифікується унікальним системним дескриптором WID та прив'язується до власника-процесу.

3.1.2 Системні виклики віконного менеджера

opn_wnd
Open Window
Створення та відкриття вікна

【Синтаксис / Прототип】

WERR    opn_wnd(RECT *rect, W attr, TC *title, LINK *lnk)

【Параметри】

RECT   *rect    Екранні координати та початковий розмір вікна
W       attr    Прапори системних атрибутів вікна W_ATTR
TC     *title   Заголовок вікна у кодуванні TRON Code
LINK   *lnk     Посилання на реальний об'єкт (NULL для звичайного вікна)

【Значення, що повертається】

> 0      Успішне виконання (Дескриптор відкритого вікна WID)
< 0      Помилка (Код помилки)

【Детальний опис】

Створює нове вікно у графічній оболонці BTRON з вказаними координатами rect, атрибутами attr та заголовком title.

【Коди помилок】

EW_ADR     : Неприпустима адреса вказівника rect або title.
EW_LIMIT   : Перевищено системний ліміт відкритих вікон.
EW_NOSPC   : Недостатньо пам'яті ядра.
cls_wnd
Close Window
Закриття вікна

【Синтаксис / Прототип】

ERR     cls_wnd(WID wid)

【Параметри】

WID     wid     Дескриптор вікна

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Закриває вікно wid та вивільняє системні віконні ресурси.

【Коди помилок】

EW_WID     : Недійсний ідентифікатор вікна wid.
