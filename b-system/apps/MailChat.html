Mail & Chat

統合通信
Unified XMPP Mail & Real-Time Chat (TAD API)
← Back to B-System Applications
"Every message and thread connects via the TAD API — archive conversations and drop citations straight into your TAD documents."

Overview

Unified XMPP-based mail and real-time messaging environment implemented in src/apps/chat.c and src/apps/chat_xml.c (launch_beos_chat), connected to the TAD API (tad_browser.h, vobj.h). Important conversations, research exchanges, and attachments can be archived directly as permanent TAD Real Bodies and referenced as Virtual Body citations across research reports and T-Editor documents.

メール＆チャット： XMPPプロトコルおよびXMLスタンザ処理基盤（src/apps/chat.c, src/apps/chat_xml.c）を基盤とするメールとリアルタイム対話の統合通信環境。TAD API（tad_browser.h、vobj.h）と連携し、重要なやり取りや添付ファイルを永続的なTAD実身（Real Body）として自動アーカイブ。研究メモやTAD報告書へ仮身（Virtual Body）として引用・埋め込み可能。

Key Features & Implementation

  • 実体コード実装：src/apps/chat.c（チャットクライアントUI・ウィンドウ管理 launch_beos_chat）
  • プロトコル処理：src/apps/chat_xml.c（XMLパーサー・ストリーミング処理・スタンザ生成）
  • テスト検証基盤：src/apps/test_chat.c（XMPPメッセージング・対話セッション検証）
  • 標準XMPP / Erlang Pub-Sub基盤による堅牢な暗号化通信（OMEMO）
  • TAD APIを介した対話メッセージの実身化・仮身リンク生成
  • 連絡先ごとのリアルタイムプレゼンス＆ステータス表示
  • 添付ファイルのTAD Real Body自動関連付けとメタデータ保存
  • Clarityのミリ秒グローバル検索から会話スレッドを横断検索可能
  • T-Editor文書内へメッセージを引用仮身（Virtual Body Fusen）として直接埋め込み

Typical Workflow

  1. Send or receive messages in Mail & Chat over secure XMPP / VirtIO-Net.
  2. Select an important discussion thread → archive it as a permanent TAD Real Body via the TAD API.
  3. Drop the thread's Virtual Body into a T-Editor report or Living Book annotation to cite the exchange inline.
  4. Search for any message content instantly from Clarity's global search bar.
