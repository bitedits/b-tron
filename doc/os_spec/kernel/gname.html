1.4 Глобальне ім'я (Global Name)管理

1.4.1 Глобальне ім'я (Global Name)データ

Глобальне ім'я (Global Name)データ管理функціонал / підсистемаは, Процес (Process)間で共有的に使用されるデータを任意の名前により生成するфункціонал / підсистема, および生成された名前によるデータの参照функціонал / підсистемаを提供している. このように名前付けられて生成された共有データをГлобальне ім'я (Global Name)データと呼ぶ.

生成されるデータは 1 つの 32 ビットデータ ( W ) であり, データに付けられる名前は最大 8 文字である. 名前としては通常, 文字コードとして意味のあるものが使用されるが特に制限はなく, TNULL(0) までの最大 8 文字分 (16 バイト ) の任意のデータが名前とされる.

生成されたГлобальне ім'я (Global Name)データは, すべてのПроцес (Process)から参照 / 変更可能である.

Глобальне ім'я (Global Name)データとしては, 生成 / 変更したПроцес (Process)の存在とは無関係に存在し続けるものと, 生成 / 変更したПроцес (Process)が終了した場合に自動的に削除されるものの 2 種類があり, Глобальне ім'я (Global Name)データの生成／変更時に指定できる. 前者の場合はГлобальне ім'я (Global Name)データが不要となった時点で明示的に削除する必要がある.

このфункціонал / підсистемаは, 主にある種のデータを不特定多数のПроцес (Process)から参照可能とするために使用され, 例えば, 以下に示すようなデータを対応する固定的な名前により生成し, 参照することが考えられる.

  • サーバфункціонал / підсистемаを持ったПроцес (Process)のПроцес (Process)ID
  • 特定に資源に対応したСемафор (Semaphore)ID
  • 共通的に使用される環境параметри

1.4.2 データ / 定数の定義

□ Глобальне ім'я (Global Name)管理

#define N_CREATE	0x0000		/* Глобальне ім'я (Global Name)データの新規生成 */
#define N_MODIFY	0x0001		/* Глобальне ім'я (Global Name)データの変更     */
#define N_FORCE		0x0002		/* Глобальне ім'я (Global Name)データの強制生成 */

1.4.3 системний виклик (System Call)

cre_nam
 
Глобальне ім'я (Global Name)データ生成

【Синтаксис / Прототип】

WERR    cre_nam(TC* name, W data, W opt)

【Параметри】

TC* name    対象Глобальне ім'я (Global Name)(先頭8文字(16バイト)までが有効)
W   data    登録するデータ
W   opt     Глобальне ім'я (Global Name)属性
            ( N_CREATE ‖ N_MODIFY ‖ N_FORCE ) | [ DELEXIT ]
N_CREATE :

指定した名前のГлобальне ім'я (Global Name)データが存在していない場合に生成する (すでに存在している場合はПомилка).

N_MODIFY :

指定した名前のГлобальне ім'я (Global Name)データが存在している場合にそのデータを変更する (存在していない場合はПомилка).

N_FORCE :

指定した名前のГлобальне ім'я (Global Name)データが存在していない場合は新規に生成し, すでに存在している場合はそのデータを変更する.

DELEXIT :

生成したПроцес (Process), または最後にデータを変更したПроцес (Process)の終了時にГлобальне ім'я (Global Name)データを自動削除する. 既に他のПроцес (Process)から DELEXIT 指定が行なわれていた場合でも, DELEXIT 指定により本системний виклик (System Call)を最後に実行したПроцес (Process)が対象となる.

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

name で指定した名前のГлобальне ім'я (Global Name)データを生成または変更する.

【Коди помилок】

ER_ADR      : адреса пам'яті(name)のアクセスは許されていない. 
ER_EXS      : 名前(name)は既に存在している(N_CREATEの時). 
ER_NOEXS    : 名前(name)は存在していない(N_MODIFYの時). 
ER_NOSPC    : システムのОперативна пам'ять (Memory)領域が不足した. 
ER_PAR      : параметриが不正である(optが不正,nameが空).

【Значення, що повертається】
