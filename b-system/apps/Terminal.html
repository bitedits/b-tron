Terminal

TRON端末
Low-Latency TRON Code & Unicode System Terminal (gterm)
← Back to B-System Applications
"Clean, low-latency TRON Code and Unicode terminal emulator — pure C99 system console over VirtIO and POSIX PTYs."

Overview

Ultra-fast, low-latency terminal emulator implemented in pure C99 (src/apps/gterm.c). Provides native TRON Code character planes and modern UTF-8 support, ANSI/VT100 escape sequence processing, ring-buffered scrollback, and direct integration with VirtIO-Console, hardware UART, and POSIX pseudo-terminals (PTY). Ensures a robust, lightweight command-line interface under all operating conditions.

ターミナル： TRONコード体系（多言語プレーン）および最新Unicode (UTF-8) に完全準拠した、純粋C99実装（src/apps/gterm.c）の低遅延・高機能システム端末エミュレータ。ANSI/VT100エスケープシーケンス、リングバッファスクロールバック、VirtIO-Console、シリアルUART、POSIX擬似端末（PTY）に直結し、システム障害時でも確実に動作する軽量で堅牢なCLI環境を提供。

Key Features & Implementation

  • 実体コード実装：src/apps/gterm.c（端末ウィンドウ open_gterm_window、VT100解釈、PTY/UART通信）
  • TRONコード多言語文字コード体系＆Unicode (UTF-8) 完全ネイティブ表示
  • 純粋C99システム設計（極小フットプリント・高速スクロール）
  • 低遅延VirtIO-Console、ハードウェアUART、およびPOSIX PTYサブシステム連携
  • ANSI/VT100エスケープシーケンス完全解釈（256色カラー・カーソル制御）
  • 分割ペイン（Split Panes）、タブセッション、およびリングバッファ履歴
  • システムクリップボードとのシームレスなテキスト選択・コピー＆ペースト

Typical Workflow

  1. Launch Terminal from Workbench or the Deskbar — window and font renderers initialize in microseconds.
  2. Run shell commands, interactive utilities, or launch background daemon processes.
  3. Switch between multiple tabs or split panes for side-by-side compile and log monitoring.
  4. Select text or command logs and copy them to the system clipboard for use across any application.
  5. Use Commander integration for one-click shell jumping to the current directory.
