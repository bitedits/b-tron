1.3 Процес (Process)/Задача (Task)間同期通信管理

Процес (Process) / Задача (Task)間の同期や通信を行うための機構として, 下記の同期通信функціонал / підсистемаを提供する.

  • Семафор (Semaphore)
  • Подія (Event)フラグ
  • Повідомлення (Message)バッファ
  • Ранデву (Rendezvous)

これらの同期・通信オブジェクトは動的に生成され, 生成時に割り当てられたID ( > 0 ) により識別される.

Повідомлення (Message)による通信と一番大きく異なる点は, Повідомлення (Message)がПроцес (Process)間の通信であるのに対し, Задача (Task)間の通信であることである. したがって, 主な用途はПроцес (Process)内のЗадача (Task)間の同期・通信である. 生成したオブジェクトはすべてのПроцес (Process)から使用可能となるので, Процес (Process)間の同期・通信にも使用できる.

1.3.1 データ / 定数の定義

□ タイムアウト定義

typedef W   TMOUT;          /* タイムアウト指定 (ミリ秒) */

#define T_NOWAIT    ( 0)    /* 待たない */
#define T_FOREVER   (-1)    /* 永久待ち */

□ Семафор (Semaphore)定数定義

#define SEM_SYNC    0x0000  /* 同期用Семафор (Semaphore) */
#define SEM_EXCL    0x4000  /* 排他制御用Семафор (Semaphore) */

□ Подія (Event)フラグ定数定義

#define WF_AND      0x0000  /* Подія (Event)フラグ AND 待ち */
#define WF_OR       0x0002  /* Подія (Event)フラグ OR  待ち */

1.3.2 системний виклик (System Call)

cre_sem
 
Семафор (Semaphore)の生成

【Синтаксис / Прототип】

WERR    cre_sem(W cnt, UW opt)

【Параметри】

W   cnt Семафор (Semaphore)初期値
        同期用Семафор (Semaphore)の場合には cnt ≧ 0 でなければならない. 
        排他制御用Семафор (Semaphore)の場合には cnt = 1 でなければならない. 

UW  opt Семафор (Semaphore)属性
        ( SEM_SYNC ‖ SEM_EXCL ) | [ DELEXIT ]
        SEM_SYNC    同期用Семафор (Semaphore)
        SEM_EXCL    排他制御用Семафор (Semaphore)
        DELEXIT     生成Процес (Process)終了時に自動削除

【Значення, що повертається】

> 0      Успішне виконання(生成したСемафор (Semaphore)ID)
< 0      Помилка (Код помилки)

【Детальний опис】

Семафор (Semaphore)を生成する. 生成したСемафор (Semaphore)は, すべてのПроцес (Process)から使用可能である.

SEM_EXCL -- 排他制御用Семафор (Semaphore)
  • 必ず, 獲得 ( wai_sem ) 〜 開放 ( sig_sem ) の順で使用しなくてはならない.
  • Семафор (Semaphore)を獲得したまま解放せずにЗадача (Task)が終了した場合には, 自動的に解放される.
  • 初期値は 1 でなければならない.
SEM_SYNC -- 同期用Семафор (Semaphore)
  • Семафор (Semaphore)の獲得 ( wai_sem ), 開放 ( sig_sem ) の順序に対する制限はない.
  • Задача (Task)が終了した場合の自動解放は行われない.
  • 生成時の初期値に制限はない.

【Коди помилок】

ER_NOSPC    : システムのОперативна пам'ять (Memory)領域が不足した. 
ER_LIMIT    : Семафор (Semaphore)の数がシステムの制限を超えた. 
ER_PAR      : параметриが不正である.

sig_sem
 
Семафор (Semaphore)へ資源の返却

【Синтаксис / Прототип】

ERR sig_sem(ID id)

【Параметри】

ID  id  Семафор (Semaphore)ID

【Значення, що повертається】

＝0  Успішне виконання
＜0  Помилка(код помилки)

【Детальний опис】

Семафор (Semaphore)へ資源を 1 つ返却する.

Семафор (Semaphore)の資源待ちのЗадача (Task)があれば, 待ち行列の先頭のЗадача (Task)の待ちを解除する. 資源待ちのЗадача (Task)がなければ, Семафор (Semaphore)の資源を 1 増やす.

排他制御用Семафор (Semaphore)の場合には, 対象Семафор (Semaphore)の資源を獲得していない状態で返却しようとした場合は ER_OBJ になる.

【Коди помилок】

ER_ID       : Семафор (Semaphore)IDが不正である. 
ER_LIMIT    : Семафор (Semaphore)のカウント値が制限を越えた. 
ER_NOEXS    : Семафор (Semaphore)は存在していない. 
ER_OBJ      : 排他制御用Семафор (Semaphore)に対しての不正操作である.
wai_sem
 
Семафор (Semaphore)から資源の獲得

【Синтаксис / Прототип】

ERR wai_sem(ID id, TMOUT tmo)

【Параметри】

ID      id      Семафор (Semaphore)ID

TMOUT   tmo         タイムアウト指定 (ミリ秒)
        T_NOWAIT    資源を獲得できなくても待たない
        T_FOREVER   資源を獲得できるまで待つ
        >0          資源を獲得できるまで最長 tmo ミリ秒待つ

【Значення, що повертається】

＝0  Успішне виконання
＜0  Помилка(код помилки)

【Детальний опис】

Семафор (Semaphore)から資源を 1 つ獲得する. Семафор (Semaphore)に 1 つ以上の資源がある場合には, その資源を 1 つ獲得する ( 減らす ). 資源が 0 の場合には, sig_sem() により資源が返却されるのを待つ. 指定された待ち時間が経過しても資源が獲得できない場合には, ER_NONE が返される.

排他制御用Семафор (Semaphore)の場合 :

  • 対象Семафор (Semaphore)の資源をすでに獲得している状態で, 再度獲得しようとした場合には ER_OBJ になる.

  • 資源を獲得しているЗадача (Task)が終了した場合には, 自動的に資源は返却される.

【Коди помилок】

ER_DLT      : Семафор (Semaphore)は獲得待ちの間に削除された. 
ER_ID       : Семафор (Semaphore)IDが不正である. 
ER_MINTR    : Повідомлення (Message)ハンドラが起動されたため待ち処理が中断された. 
ER_NOEXS    : Семафор (Semaphore)は存在していない. 
ER_NONE     : Семафор (Semaphore)を獲得できずにタイムアウトした. 
ER_PAR      : параметриが不正である. 
ER_OBJ      : 排他制御用Семафор (Semaphore)に対しての不正操作である.

wai_flg
 
Подія (Event)フラグ待ち

【Синтаксис / Прототип】

WERR    wai_flg(ID id, W ptn, UW mode, TMOUT tmo)

【Параметри】

ID  id  Подія (Event)フラグID

W   ptn 待ちパターン (>0)

UW  mode    待ち解除条件
        ( WF_AND ‖ WF_OR ) | [ NOCLR ]
        WF_AND  0x0000  ptn で1のビットがすべてセットされるまで待つ
        WF_OR   0x0002  ptn で1のビットのいずれかがセットされるまで待つ
        NOCLR   0x0008  待ち解除条件が満たされた時, Подія (Event)フラグの値を
                        クリアしない

TMOUT   tmo タイムアウト指定 (ミリ秒)
        T_NOWAIT    待ち解除条件が満たされなくても待たない
        T_FOREVER   待ち解除条件が満たされるまで待つ
        >0          待ち解除条件が満たされるまで最長 tmo ミリ秒待つ

【Значення, що повертається】

> 0      Успішне виконання(待ち状態が解除されたときのПодія (Event)フラグの値)
< 0      Помилка (Код помилки)

【Детальний опис】

mode で指定された条件にしたがって, Подія (Event)フラグがセットされるのを待つ.

次の条件が満たされたとき待ち解除となる. 

WF_AND の時 ( flg & ptn ) == ptn
WF_OR の時  ( flg & ptn ) != 0
        ∵ flg はПодія (Event)フラグの値

NOCLR が指定された時には, 待ち解除条件が満たされたときПодія (Event)フラグの値は変化しない. NOCLR の指定がない場合には, 待ち解除条件が満たされたときПодія (Event)フラグの値 ( 全ビット ) が 0 クリアされる.

指定された待ち時間が経過しても待ち解除条件が満たされない場合には, ER_NONE が返される.

【Коди помилок】

ER_DLT      : Подія (Event)フラグが待ちの間に削除された. 
ER_ID       : Подія (Event)フラグIDが不正である. 
ER_MINTR    : Повідомлення (Message)ハンドラが起動されたため待ち処理が中断された. 
ER_NOEXS    : Подія (Event)フラグは存在していない. 
ER_NONE     : Подія (Event)フラグの条件が満たされずにタイムアウトした. 
ER_PAR      : параметриが不正である.

一旦受け付けたРанデву (Rendezvous)を回送する.

呼出Задача (Task)のРанデву (Rendezvous)は, fwd_por() で指定された条件で行われる. つまり, fwd_por() で指定された calptn により選択条件が満たされるとРанデву (Rendezvous)が成立する.
