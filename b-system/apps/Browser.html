Browser

HTML→TAD変換
Lightweight HTML 4.1 Browser with TAD Export
← Back to B-System Applications
"One-click bridge: turn any web page into a live, editable Real Body that lives inside your TAD universe."

Overview

Lightweight HTML 4.1 browser with one-click HTML-to-TAD conversion. Any page can become a native, editable Real Body — permanently stored in the knowledge base, linkable as a Virtual Body inside any TAD document.

ブラウザ： 軽量・軽快なHTML 4.1 Webブラウザ。ワンクリックで閲覧中のWebページをネイティブかつ編集可能な実身（TAD Real Body）へと変換・ローカル保存。Webの知識を永久に散逸しない知識資産へ。

Key Features

  • 1クリックでWebページをTAD実身文書へ完全変換
  • 無駄なスクリプトを排した超高速レンダリング（HTML 4.1 + CSS2）
  • T-Editorでの即座な再編集・注釈追記
  • Converted Real Bodies immediately linkable as Virtual Bodies in any TAD document
  • Persistent local archive — web knowledge never siloed or lost
  • Back-link from the saved Real Body to the original URL preserved as metadata

Why the Market Needs It

  • Web content stays siloed in classic browsers: you can read it, but cannot edit or embed it back into the BTRON knowledge base.
  • Researchers lose the "permanent knowledge" link between a web page and a TAD document every time a tab is closed.
  • Heavyweight modern browsers (V8, full JS engine) are inappropriate for a minimal unikernel environment.

Replaces / Normalises

Classic BTRON ProductB-System AdvantageTarget Users
Classic B-TRON WebView (plain HTML renderer, read-only) One-click export to editable TAD Real Body; full round-trip editing Researchers, technical writers, developers capturing web-based knowledge
Stand-alone TAD-Viewer (read-only) Live web + TAD in one window, seamless back-link to knowledge base

Typical Workflow

  1. Open any web page in Browser.
  2. Press Export → TAD; the page becomes a Real Body (editable TAD document).
  3. Annotate, add inline code notes, or embed the Real Body into other TAD documents via Virtual Bodies.
  4. Search the saved Real Body instantly from Clarity's global search bar.
