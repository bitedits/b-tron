1.9 Системний годинник та таймери (Clock Management)

1.9.1 Функції керування часом

Підсистема керування часом підтримує глобальний системний час STIME (кількість секунд, що минули від 1 січня 1985 року, 00:00:00 GMT), часові пояси (TIMEZONE), перехід на літній час (Daylight Saving Time, DST) та перетворення у календарний формат дати/часу (DATE_TIM).

Локальний час обчислюється за формулою: 

  Локальний_час = Системний_час - adjust + (dst_flg ? dst_adj * 60 : 0)

1.9.2 Структури даних та константи

□ Специфікація часового поясу (TIMEZONE)

typedef struct {
    W   adjust;     /* Різниця із системним часом GMT у секундах (-43200..+43200) */
    W   dst_flg;    /* 0 = без DST, != 0 = увімкнено літній час */
    W   dst_adj;    /* Величина корекції DST у хвилинах */
} TIMEZONE;

□ Календарна дата та час (DATE_TIM)

typedef struct {
    W   d_year;     /* Рік як зсув від 1900 (наприклад, 126 = 2026 рік) */
    W   d_month;    /* Місяць (1..12; 0 = спецрежим з використанням d_days) */
    W   d_day;      /* День місяця (1..31) */
    W   d_hour;     /* Година (0..23) */
    W   d_min;      /* Хвилина (0..59) */
    W   d_sec;      /* Секунда (0..59) */
    W   d_week;     /* Номер тижня року (1..54) */
    W   d_wday;     /* День тижня (0..6; 0 = неділя) */
    W   d_days;     /* День від початку року (1..366) */
} DATE_TIM;

1.9.3 Системні виклики керування часом

get_tim
Get System Time
Отримання поточного системного часу та часового поясу

【Синтаксис / Прототип】

ERR get_tim(STIME *time, TIMEZONE *tz)

【Параметри】

STIME    *time  Буфер для системного часу GMT (NULL = не зберігати)
TIMEZONE *tz    Буфер для часового поясу (NULL = не зберігати)

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (ER_ADR)
set_tim
Set System Time
Встановлення системного часу та часового поясу

【Синтаксис / Прототип】

ERR set_tim(STIME time, TIMEZONE *tz)

【Параметри】

STIME     time  Нове значення системного часу (<= 0 = не змінювати)
TIMEZONE *tz    Нове значення часового поясу (NULL = не змінювати)

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (ER_ACCES — потрібні права рівня 0, ER_ADR, ER_PAR)
get_tod
Get Time of Day / Calendar
Перетворення системного часу в календарну дату

【Синтаксис / Прототип】

ERR get_tod(DATE_TIM *dt, STIME time, Bool local)

【Параметри】

DATE_TIM *dt    Буфер для календарної дати
STIME     time  Системний час для перетворення (<= 0 = поточний системний час)
Bool      local 0 = час за GMT; != 0 = локальний час із поправкою поясу

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (ER_ADR)
set_tod
Set Time of Day / Calendar to System Time
Перетворення календарної дати в системний час або встановлення годинника

【Синтаксис / Прототип】

ERR set_tod(DATE_TIM *dt, STIME *time, Bool local)

【Параметри】

DATE_TIM *dt    Календарна дата для перетворення
STIME    *time  Буфер для розрахованого часу (NULL = встановити як системний час)
Bool      local 0 = дата вказана за GMT; != 0 = локальна дата

【Значення, що повертається】

= 0     Успішне виконання
< 0     Помилка (ER_ACCES, ER_ADR, ER_PAR)
