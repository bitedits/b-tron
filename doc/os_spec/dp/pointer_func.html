2.6 Функції управління курсором та поінтером (Pointer & Cursor Functions)

2.6.1 Огляд підсистеми відображення графичного курсора

Підсистема управління курсором контролює візуальне відображення маски курсора миші/поінтера на екрані, обробляє відсікання з іншими вікнами та забезпечує плавне апаратне чи програмне переміщення курсора при русі миші.

gset_ptr
Set Cursor BitMap
Встановлення форми та растрової маски курсора

【Синтаксис / Прототип】

ERR     gset_ptr(BMP *bmp, PNT hot)

【Параметри】

BMP    *bmp     Вказівник на структуру растрового масиву курсора BitMap
PNT     hot     Координати активної точки (Hotspot) всередині курсора (X, Y)

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Встановлює нову растрову форму маски курсора bmp та прив'язує гарячу точку (Hotspot) hot.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника bmp.
EG_PAR     : Некоректні координати hot.
gget_ptr
Get Pointer Position
Отримання координат та стану курсора

【Синтаксис / Прототип】

ERR     gget_ptr(PNT *pos, H *stat)

【Параметри】

PNT    *pos     Буфер для збереження поточних екранних координат курсора (Вихід)
H      *stat    Буфер для збереження стану кнопок миші (Вихід)

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Повертає поточні екранні координати курсора pos та побітовий стан його кнопок stat.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника pos або stat.
