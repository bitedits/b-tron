3.5.1 Менеджер системного лотка (Tray Manager) 機能

3.5.1.1 Загальний огляд

Менеджер системного лотка (Tray Manager) є основою 1つ та して位置付けられ, 基本的なデータ移動 / 複写 操作 ある«切り取る», «写し取る», «貼り込む»および«取り込む» 使用されるЛоток (Tray) 管理 行ない, Лоток (Tray)内 データ 操作する機能 提供する також ある.

また, ドラッグ よるデータ移動 / 複写等 ため 一時的 使用される «一時Лоток (Tray)» 管理 також 行ない, そ 操作機能 提供している.

Менеджер системного лотка (Tray Manager) 単 Лоток (Tray) 格納されるデータ領域 管理 行ない, そ 内容 関して 一切関知しない.

додаток , 常 ユーザから 明示的な操作 よって みЛоток (Tray) 操作 行なわなくて いけない. すなわち, ユーザ 操作 та 無関係 додаток間 データ交換等 Лоток (Tray) 使用して いけない.

3.5.1.2 Лоток (Tray)

Лоток (Tray) , 各ユーザ毎 1つ存在する特殊な«データ格納容器» あり, «切り取る»また «写し取る» 操作 ディスティネーション та してデータ 格納され, «貼り込む»また «取り込む» 操作 ソース та してデータ 取り出される容器 ある.

«切り取る／取り込む» 操作 ソースデータ 失われ(即ち, 移動), «写し取る／貼り込む» 操作 , ソースデータ 保存される(即ち, 複写).

Лоток (Tray) スタック構造 持ち, 基本的 最後 格納したデータ 最初 取り出される , そ 順番 変更したり任意 位置 データ 取り出すこ та також 可能 ある. データ , 先頭(最後 格納されたデータ) "1" та した連続番号 あるデータ位置 より識別される.

Лоток (Tray) 格納されたデータ , «データ 削除»操作 行なうか, また Лоток (Tray) 最大容量 オーバーして溢れた場合 自動的 消滅する. Лоток (Tray) 最大容量 , インプリメント 依存する , 原則的 最後 格納されたデータから遡って, 少なく та також 5 個 データ 保証される також та する ( 通常 10 個程度 ) .

3.5.1.4 Лоток (Tray) 操作

Лоток (Tray) , ユーザ毎 1つ用意される. 通常 ユーザ 初期Процес (Process) よりオープンされ, そ ユーザ Процес (Process) そ Лоток (Tray) 常 対象 та する. Лоток (Tray) ユーザ 使用 終了した時点 クローズされ, そ 内容 消える.

tpsh_dat
 
Лоток (Tray)へ データ格納

【Формат / Синтаксис】

W   tpsh_dat(TRAYREC *data, W nrec, TC *name)

【Параметри】

TRAYREC *data   Лоток (Tray) 格納するデータ
W       nrec    レКод (Code)数
TC      *name   データ 付ける名前

【Значення, що повертається】

≧0    正常(関数値 格納したレКод (Code)数)
＜0    エラー(Коди помилок)

【Опис та функціонал】

Лоток (Tray) 先頭 data 指定した nrec 個 データレКод (Code) 格納し, そ データ «選択状態» та する. 関数値 та して格納したレКод (Code)数 戻る.

name データ 対して付ける任意 名称 あり, 先頭 12文字(TC)ま 有効 та なる. 名称 付けない場合 , name = NULL та する.

データ 格納 より, Лоток (Tray) 溢れ 生じた場合 , 最後 データ 自動的 消滅する.

EX_PAR      : Параметри 不正 ある(nrec≦0, Лоток (Tray)レКод (Code) 内容 不正).

tpop_dat
 
Лоток (Tray)から データ取り出し

【Формат / Синтаксис】

W   tpop_dat(TRAYREC *data, W size, W *a_size, W rec, TC *name)

【Параметри】

TRAYREC *data   Лоток (Tray)から取り出すデータ格納場所
W       size    data  バイト数
W       a_size  全体 バイト数
W       rec     取り出し方法
        < 0 :  全体取り出し
        = 0 :  ヘッダ取り出し
        > 0 :  指定レКод (Code)データ取り出し(rec  指定したレКод (Code))
TC      *name   データ名称 格納場所

【Значення, що повертається】

≧0    正常(関数値 データ レКод (Code)数 / レКод (Code)Тип (Type))
＜0    エラー(Коди помилок)

【Опис та функціонал】

Лоток (Tray)内 選択されているデータ , rec 指定 従って取り出し, data 指定した size バイト 領域 格納する.

格納すべきデータ Розмір (Size)より size 小さい場合 , size 分だけ格納され, EX_PAR エラー та なる. data = NULL 場合 , size 値 無視され, データ 一切格納されない. いずれ 場合 також *a_size 格納すべきデータ 全体 バイトРозмір (Size) 戻される. こ ため例えば, rec < 0, data = NULL та するこ та より, 格納されているデータ全体 Розмір (Size) 知るこ та きる.

なお, データ 取り出した後 також Лоток (Tray)内 データ 削除されず 残っており, 選択状態 まま та なる. name データ 付けられた名称 格納する領域へ Вказівник (Pointer) あり, 12 + 1文字(TC) 領域 ある必要 ある ( 格納された名称 最後 TNULL 付けられる ) . name = NULL 場合 , 名称 格納されない.

関数値 та して, 全体取り出し / ヘッダ取り出し ( rec ≦ 0 ) 時 , データ 総レКод (Code)数 戻り, 指定レКод (Code)取り出し ( rec ＞ 0 ) 時 , 取り出したレКод (Code) レКод (Code)Тип (Type) 戻る. 存在しないレКод (Code)番号 指定した場合 , EX_PAR エラー та なり, *a_size "0" 戻される.

Лоток (Tray) 空 場合 , 取り出し方法 無関係 , *a_size "0" 戻され, 関数値 "0" та なる.

【Коди помилок】

EX_ADR      : アドレス(data,a_size,name) アクセス 許されていない. 
EX_PAR      : Параметри 不正 ある
              (size≦0, 領域 Розмір (Size) 不足, rec 値 不正). 
EX_TRAY     : Лоток (Tray) オープンされていない.
