MediaPulse

リアルタイム
Unified Real-Time Media Environment
← Back to B-System Applications
"Drop any media, get a live scrubbable Virtual Body — BeOS Media Kit spirit, BTRON-native"

Overview

Unified real-time media environment. Drop any audio, video, GIF or PNG and it becomes a live, scrubbable Virtual Body. Supports timeline annotations, live queries, frame-accurate work and direct embedding into any TAD document. Extremely responsive, BeOS Media Kit spirit.

メディアパルス： あらゆる音声、動画、GIF、PNGをドラッグ＆ドロップするだけで即座にスクラブ可能な「生きた仮想オブジェクト」へと変換。タイムライン注釈、ライブクエリ検索、フレーム精度の編集、およびTAD文書へのシームレスな直接埋め込みに対応。BeOS Media Kitの精神を受け継ぐ超低遅延応答性を実現。

Key Features

  • 任意メディアのドラッグ＆ドロップ即時仮想オブジェクト化
  • フレーム精度（Frame-Accurate）のシークとタイムライン注釈
  • TADハイパーメディア文書へのシームレス直接埋め込み
  • Live-query filtering across all media objects by metadata, duration, or tag
  • Zero-copy VirtIO audio/video pipeline — no intermediate buffer copies
  • Music app round-trip: import patterns as audio Virtual Bodies

Typical Workflow

  1. Drop a video or audio file onto MediaPulse — it instantly becomes a scrubbable Virtual Body.
  2. Scrub the timeline; click to insert a timestamped annotation Real Body at the current frame.
  3. Drag the Virtual Body into any T-Editor TAD document or Workbench canvas.
  4. Use live-query to filter all media objects by tag or duration without a separate search tool.
