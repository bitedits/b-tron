1.9 Системний годинник та таймери (Clock & Timer Management)

1.9.1 Огляд підсистеми системного часу (Overview)

Підсистема системного годинника надає засоби для зчитування та налаштування поточного системного часу реального часу (Real-Time Clock), а також для зчитування відносного системного часу виконання операційної системи.

Системний час вимірюється у секундах або мілісекундах починаючи з відлікової епохи BTRON: 1 січня 1985 року, 00:00:00 GMT (Greenwich Mean Time).

1.9.2 Визначення типів даних та констант (Data Types & Constants)

typedef W       STIME;          /* Системний час у секундах від 01.01.1985 GMT */

1.9.3 Системні виклики підсистеми годинника (Clock System Calls)

get_tim
 
Зчитання системного часу реального часу (Get System Time)

【Синтаксис / Прототип】

ERR     get_tim(STIME *pk_time)

【Параметри】

STIME  *pk_time Буфер для збереження поточного системного часу у секундах (Вихід)

【Значення, що повертається】

= 0      Успішне виконання (Час записано в *pk_time)
< 0      Помилка (Код помилки)

【Детальний опис】

Зчитує поточний системний час астрономічного реального часу у секундах від 1 січня 1985 року 00:00:00 GMT та записує його за адресою pk_time.

【Коди помилок】

ER_ADR     : Неприпустима адреса вказівника pk_time.
set_tim
 
Налаштування системного часу (Set System Time)

【Синтаксис / Прототип】

ERR     set_tim(STIME time)

【Параметри】

STIME   time    Нове значення системного часу у секундах від 01.01.1985 GMT

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Установлює нове значення системного астрономічного часу реального часу у секундному форматі. Потребує системних привілеїв суперкористувача / системного процесу.

【Коди помилок】

ER_ACCES   : Відсутні системні привілеї для зміни годинника.
ER_PAR     : Неприпустиме або від'ємне значення часу time.
