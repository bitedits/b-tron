Розділ 3. Детальна специфікація формату документів TAD (TRON Application Databox)

3.1 Вступ

Ця специфікація описує деталізовану структуру даних TAD (TRON Application Databus). Пояснення базових концепцій специфікації BTRON, таких як «Реальний об'єкт» (Real Object), «Віртуальний об'єкт» (Virtual Object), «Наліпка / Вкладка» (Fusen), а також мети та призначення TAD, у цьому документі опущено.

Крім того, передбачається, що читач має базові знання про системи на базі специфікації BTRON (зокрема про файлову систему та графічні примітиви Display Primitives), а також про систему кодування TRON Code.

3.2 Структура Реального об'єкта TAD (Real Object Layout)

3.2.1 Загальні відомості

Формат TAD (TRON Application Databus) розміщується всередині Реального об'єкта (Real Object). У специфікації BTRON Реальний об'єкт (файл) може містити й інші структури даних, окрім TAD.

Реальний об'єкт (файл) у специфікації BTRON має такі основні характеристики:

  • Реальний об'єкт (Real Object / Файл):

    Відповідає файлу у файловій системі BTRON і є безпосереднім контейнером даних.

  • Тип Реального об'єкта (Application Type):

    Для кожного Реального об'єкта визначається тип додатка, якому відповідають піктограми (іконки) тощо. Також існують пристроєві Реальні об'єкти (Device Real Objects).

  • Дані Реального об'єкта (Real Object Data):

    Складаються з одновимірного ланцюжка кодових сегментів, для яких визначено типи записів (Record Type) та правила структури даних.

3.4 Формат та структура TAD

3.4.1 Загальний огляд

У цьому розділі описуються конкретні формати та структури даних TAD. Детальну специфікацію текстових сегментів (вкладок) наведено у Розділі 3.5, а графічних сегментів — у Розділі 3.6.

Сегменти даних TAD мають такий загальний базовий формат: 

ID  :  Ідентифікатор сегмента (Segment ID).
LEN :  Довжина даних сегмента в байтах (для змінної довжини позначається "~").
DATA:  Блок даних сегмента (корисне навантаження).

3.4.6 Сегмент Віртуального об'єкта (Virtual Object Segment TS_VOBJ)

□ Загальний огляд:

Сегмент Віртуального об'єкта (TS_VOBJ) призначений для вбудовування вказівників (посилань) на Віртуальні об'єкти (Virtual Object) у текстові або графічні дані TAD. Це дозволяє Реальному об'єкту (Real Object) посилатися на інші Реальні об'єкти, створюючи мережеві гипертекстові структури BTRON.

Сегмент TS_VOBJ задає атрибути відображення іконки та рамки Віртуального об'єкта. Між сегментом TS_VOBJ у документі TAD та записом посилання (Link Record) у файловій системі BTRON існує взаємно однозначна відповідність 1-до-1.

Сегмент містить такі основні відомості:

  • Тип Віртуального об'єкта та ID піктограми / іконки
  • Ідентифікатор цільового Реального об'єкта (Real Object ID)
  • Ідентифікатор пов'язаного додатка (Application ID)

Обробка сегмента Віртуального об'єкта здійснюється взаємодією з Менеджером реальних та віртуальних об'єктів BTRON та відповідними прикладними програмами.

□ Формат / Синтаксис:

ID  :   TS_VOBJ                 -- Сегмент Віртуального об'єкта (TS_VOBJ)
LEN :   ~                       -- Змінна довжина
DATA:   RECT    view            -- Область відображення (View Region)
        H       height          -- Висота рамки Віртуального об'єкта
        CHSIZE  chsz            -- Розмір іконки / шрифту (CHSIZE)
        COLOR   frcol           -- Колір рамки
        COLOR   chcol           -- Колір символів / назви
        COLOR   tbcol           -- Колір смуги заголовка
        COLOR   bgcol           -- Колір фону
        UH      dlen            -- Довжина додаткових даних
        UB      data[dlen]      -- Додаткові дані розширення (довжиною dlen)

□ Опис параметрів:

view:
Область відображення (View Region) Віртуального об'єкта.
height:
Висота рамки Віртуального об'єкта у пікселях відносно view. Якщо height = -1, використовується висота текстового рядка; якщо height = 0, висота вираховується автоматично.
chsz:
Розмір іконки та шрифту назви Віртуального об'єкта (тип CHSIZE).
frcol:
Колір рамки Віртуального об'єкта.
chcol:
Колір символів назви Віртуального об'єкта.
tbcol:
Колір смуги заголовка Віртуального об'єкта.
bgcol:
Колір фону прямокутника відображення.
data:
Додаткові дані розширення додатка довжиною dlen байт.
