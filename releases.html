第1部：B-System Alpha 1「Ceremony」公式リリース
Part 1 — Official Announcement: B-System Alpha 1 ("Ceremony")

「初めてマシンに火を入れる瞬間は、賭け事ではなく厳粛な儀式であるべきだ —— スキー・ブートローダーはすべての起動を意図的で、美しき所作へと昇華させる。」
"The first time you turn on a machine should feel like a ceremony, not a gamble — Bootloader makes every boot a deliberate, beautiful act."

Synrc Research Centerは、B-System Alpha 1（バージョン 3.20-alpha.1、コードネーム「Ceremony」）の正式公開をお知らせします。 B-Systemは、日本のパーソナルコンピュータ規格の金字塔であるBTRON3 SPEC 3.20仕様に準拠したクリーンルーム再構築OSです。標準C99で設計され、坂村健博士とTRONプロジェクトが提唱した直感的な造形美、リアルタイム応答性、そして実身・仮身ハイパーデータ構造を現代のオープンソース環境に甦らせます。

Alpha 1 の主な機能と到達点（Release Highlights）

12日間にわたる集中的なシステム開発を結実させ、単一コードベースから完全に再現可能なリリースパッケージを構築しました：

  • 7大ハードウェア＆ハイパーバイザー統合対応： 単一のBSD Makefileから、開発ホスト（macOS/Linux POSIX）、ARM QEMU VirtIO、Raspberry Pi 2B実機ベアメタル、坂村T-Kernel 2.0、x86_64 UEFI SMPマルチコアワークステーション、NEC PC-9801/PC-9821 VM、そして64ビットAArch64 Raspberry Pi 4Bまでを統合起動。
  • ダイレクトMultiboot単一段階ローディング： 脆弱な2段階MBR/VBRチェーンローダーを撤廃し、Multiboot 1ヘッダー（0x1BADB002）によりファームウェア／QEMUから1MB空間へ直接展開。
  • 本物の「実身／仮身」ハイパーデータエンジン： 文書内にキャビネット内の実身（Real Body）へのポインタ（仮身・Virtual Body）を無制限に埋め込める坂村ハイパーメディア構造を忠実に実装。
  • Mozc TIPネイティブ日本語入力環境： Google Mozcのかな漢字変換エンジン（mozc_kkc.c）およびTIP（Text Input Primitives / IFE）を内蔵し、F10キーによる英数・ひらがな・カタカナ変換をサポート。
  • 14種のコンシューマアプリ＆8種の設定パネル： ワークベンチ、端末（gterm）、コマンダー、電卓、時計、環境設定、ブートマネージャ（🎿）、T-Editor、Clarity、Notebook, Review、ブラウザ、メール＆チャット（XMPP）、Cassette、ペイント、音楽の全14アプリを完備。
  • 4大公式TAD電子書籍を標準同梱： BTRON3仕様書、T-Kernel 2.0、B-Free OS（1994年）、B-System（2026年）の全4冊を同梱。Elixirバッチコンパイラ（html2tad.exs）により106仕様文書からバイナリTAD（.tad）を自動生成。
  • 適合性テスト90%合格： 370項目（全410検証項目中90.2%）の仕様要件およびシステムコールが自動検証スイートで完全通過。未実装サブシステムはE_NOSPTを誠実に返し、仕様境界を明示。

対応カーネル一覧と先駆者トリビュート（7 Unified Targets & Pioneer Tributes）

Alpha 1では、日本の組み込みリアルタイムOSおよびシステムプログラミングの道を切り拓いた先駆者たち（高田広章、常田浩、横林貴広、坂村健、内田公太、Awe Morris）への敬意を込め、各ターゲットにその名を冠しています。各カーネルの詳細な機能・アーキテクチャ解説および起動コマンドは、ブートローダー製品ページ（Boot.html）の統合カーネル表にて完全掲載されています。

第2部：初コミットからの全開発記録
エンジニアリング・ログ (Development History Log)

B-Systemは、マキシム・ソハツキー（Maxim Sokhatsky / Namdak Tonpa / 5HT）により、2026年8月22日から9月2日までの12日間にわたる集中的な開発スプリントで設計・実装されました。 計280コミット、21セッション（実稼働約71.7時間）にわたり、何もない空のGitツリーから複数アーキテクチャ対応の仕様完全準拠OSへと進化を遂げました。


Phase 1 · 構想と仕様策定 (Inception & Specification Architecture)

1. 礎石の敷設 (Laying the Bedrock · Commits 1–84 · Aug 22–24)

Sessions 1–3 · 実動約11.7時間 · +31,991 / -7,205 lines

リポジトリは8月22日深夜のコミット 236bc32 にて初期化。数時間のうちに正規の日本語BTRONヘッダ構造（<btron/btron.h>、types.h、itron.h、dp.h、wnd.h、vobj.h）が確立され、TRON基本データ型（W, H, UW, ID, RECT, COLOR）が定義されました。 8月23日にはカーネルメッセージバス、プロセス管理（kernel/proc, kernel/message）、動的メモリアロケータ、坂村ウィンドウマネージャ（wnd.c）、メニュー、タスクトレイ、Display Primitives（DP）が稼働。同時にBTRON3仕様書のウクライナ語翻訳と詳細用語辞書（glossary.txt）が作成されました。

Phase 2 · 仮想化と実機T-Kernel統合 (VirtIO & Bare-Metal T-Kernel Ingestion)

2. 仮想化とRaspberry Piベアメタル (Virtualization & Raspberry Pi Silicon · Commits 85–131 · Aug 25–27)

Sessions 4–8 · 実動約17.5時間 · +50,917 / -762 lines

ホストエミュレーションからハイパーバイザーおよび実機シリコンへの展開。VirtIO 1.4 MMIO仕様（virtio.html）を定義し、QEMU向け標準GPUおよびタブレット絶対ポインティングデバイスを確立。 8月26日の6.5時間に及ぶ深夜セッションでは、坂村T-Kernel 2.0の完全なソースツリー（48,000行以上）を統合。横林貴広氏によるBCM2836（Raspberry Pi 2B Cortex-A7）低レベルドライバを移植し、Raspberry Pi 4（BCM2711）の初期配線、マルチコアCPUアフィニティスケジューリング、macOS ClangおよびLinux WSL対応を完了しました。

Phase 3 · Mozc日本語入力とCI自動化 (Mozc Kana-Kanji IME & Continuous Integration)

3. 日本語入力環境とCI自動テスト (Japanese Input & CI Automation · Commits 132–150 · Aug 28–29)

Sessions 9–10 · 実動約6.3時間 · +14,667 / -456 lines

日本のワークステーションに不可欠なネイティブ日本語入力の実現。Google Mozcのかな漢字変換エンジン（mozc_kkc.c）およびTRON Text Input Primitives（tip_ife.c, tip_task.c）をクリーンルーム移植。辞書引き、F10キーによる英数・ひらがな・カタカナ相互変換、画面上の候補表示ポップアップを実装しました。 あわせてGitHub ActionsによるmacOSおよびUbuntu Linux両対応のCI自動ビルドパイプラインを構築しました。

Phase 4 · 実身・仮身エンジンとTAD電子書籍 (Hyper-Data Engine & 4 Books in Native TAD)

4. 実身・仮身ハイパーデータとTAD閲覧環境 (Real Body / Virtual Body & TAD Browser · Commits 151–181 · Aug 29–30)

Sessions 11–13 · 実動約12.1時間 · +5,850 / -374 lines

8月29日の9.9時間に及ぶマラソンセッションにて、BTRONの真髄である「実身・仮身（Real Body / Virtual Body）」ハイパーデータエンジン（vobj.c）、キャビネット（CAB）ストレージ、およびTADブラウザを実装。 さらにElixir製バッチコンパイラ（scripts/html2tad.exs）を開発し、106本の仕様書から1MB以上のバイナリTADファイル（.tad）を自動生成。BTRON3仕様書、T-Kernel 2.0、B-Free OS（1994年）、B-System（2026年）の全4冊の電子書籍をシステム内に完全格納しました。

Phase 5 · BeOS調UI、XMPPチャット、ターミナル (BeOS Styling, XMPP Chat & Terminal Shell)

5. スライディングタブ、通信、端末環境 (Accessories, Sliding Tabs & Chat · Commits 182–213 · Aug 31)

Sessions 14–17 · 実動約11.8時間 · +5,074 / -1,034 lines

BeOS調の黄色いスライディング・ウィンドウタイトルボックス、レトロなウィンドウ装飾、自由なウィンドウスタッキングとディミング効果を導入。 30KBの超軽量XMPPチャットクライアント（src/apps/chat.c）を移植し、ANSIカラー端末（gterm.c）を強化。コードベース全域において「オブジェクト」という汎用呼称を正統なTRON用語である「実身・仮身（Body）」へと体系的に統一しました。

Phase 6 · 適合性認証とRaspberry Pi USB HID (Conformance Audit & Raspberry Pi USB HID)

6. 適合性テスト体系とUSB入力ドライバ (Conformance Suite & USB HID Drivers · Commits 214–243 · Sept 1)

Session 18 · 実動約6.9時間 · +6,756 / -536 lines

BTRON 3.20仕様への厳密な準拠を証明する公式認証スイート（CERTIFICATION.md、conformance.html）を策定。自動テスト実行バイナリ（verify/btron_verify.c）により全410項目中370項目（90.2%）の機能合格を証明。 同時に、Raspberry Pi 2B実機ベアメタルのUSBキーボードおよびマウスHIDスタック（test_tkernel.sh）を組み上げ、物理ハードウェアでの確実な対話操作を保証しました。

Phase 7 · UEFI SMP、PC-98、マルチターゲット統合 (The Multi-Target Grand Unification)

7. マルチターゲット大統合 (The Multi-Target Grand Unification · Commits 244–280 · Sept 2)

Sessions 19–21 · 実動約7.4時間 · +7,252 / -237 lines

Alpha 1公開直前のクライマックス。内田公太氏へのオマージュである64ビットx86_64 UEFI SMPカーネル（btron-uchida.elf、ACPI MADT/LAPIC/GOP）と、Awe Morris氏へのオマージュであるNEC PC-9801/PC-9821 VMカーネル（btron-morris.elf、プレナーVRAM/ポート0xF2 A20ゲート）を相次いで完成。 14大コンシューマアプリ群（b-system/apps/）、64ビットPi 4Bターゲット（core_arm64.c）、そして全7カーネルの先駆者トリビュート体系を統合しました。

今後のロードマップ：Beta 1への展望（Future Roadmap: Path to Beta 1）

Alpha 1のマイルストーン達成を受け、今後のB-System開発ロードマップでは以下の主要機能に注力します：

  • 内蔵C99コンパイラ（Integrated C99 Compiler）： Fabrice BellardのTCC設計に基づく超軽量Cコンパイラを移植し、B-System上でのセルフホスティング環境を確立。
  • 完全なseL4マイクロカーネル・ペルソナ（seL4 Persona）： Synrc VE OS.1環境下でミッションクリティカル・エッジ計算を支える形式検証済みマイクロカーネル・ペルソナの拡充。
  • HTML 4.1 / TADハイパーメディアWebエンジン： Web TADストリームのネイティブ描画と軽量NetSurfベースのWebブラウジング機能。
  • Raspberry Pi 5実機シリコン対応： BCM2712 / RP1サウスブリッジのハードウェアMMIO対応をエミュレーションから実機検証へ展開。
