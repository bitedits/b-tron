"Lightweight, distraction-free Wordpad-class authoring — responsive text formatting, styles, and margins with basic automatic TAD layout and live Fusen links."

Overview

Clean, responsive Wordpad-class word processor designed for everyday writing, memos, and reports, equipped with a native basic automatic TAD layout engine. Implemented in src/apps/t_editor.c and validated by src/apps/test_editor_ui.c, T-Editor provides instant startup and intuitive rich-text formatting: paragraph styles (Heading 1–3, Body, Blockquote), visual rulers, customizable margins, bulleted/numbered lists, and auto-wrapping text flow. While heavy desktop publishing is reserved for Clarity, T-Editor gives daily authors lightning-fast auto-layout that embeds multimedia Real Bodies (実身) and Virtual Body fusen links (仮身付箋) directly into binary TAD segments.

Tエディタ： Windows Wordpadのような軽快さと直感性を追求した、日常業務・執筆用汎用ワードプロセッサ。基本自動TADレイアウトエンジン（t_editor_auto_layout）を搭載し、実体コードは src/apps/t_editor.c および src/apps/test_editor_ui.c で構成。起動の瞬発力と軽快なレスポンスを最優先とし、見出しスタイル（Heading 1〜3）、ルーラー、余白設定、自動行折り返し、箇条書きなど日常執筆に必要な機能を網羅。さらにTAD独自のハイパーメディア機能により、テキスト行内に画像や表計算（Matrix）を「実身（Real Body）」として挿入し、関連資料を「仮身付箋（Virtual Body Fusen）」として自在にリンク。日常の文書作成をストレスなく快適に行えます。

Key Features & Implementation

  • 実体コード実装：src/apps/t_editor.c（Wordpad級UI・自動TADレイアウター・セグメント操作）
  • 検証テストスイート：src/apps/test_editor_ui.c（184/184項目全テスト自動検証パス）
  • 基本自動TADレイアウト：余白・行幅に応じた高速自動行折り返しとベースライン揃え
  • 見出しスタイル（Heading 1〜3、本文、引用、箇条書きリスト）のワンタッチ適用
  • 実身インライン埋め込み：画像・音声・Matrix表計算スニペットを行内に直接挿入
  • 仮身付箋（Virtual Body Fusen）のドラッグ＆ドロップ挿入と相互リンク解決
  • Mozc TIP 日本語入力エンジン（F6〜F10ファンクションキー変換）完全統合
  • 極小メモリフットプリントとミリ秒単位の超高速起動

Why the Market Needs It

  • Heavy monolithic word processors take seconds to launch and clutter the interface with hundreds of rarely used DTP buttons.
  • Plain text editors lack rich typography, styles, and multimedia links necessary for structured business memos and daily reports.
  • T-Editor strikes the perfect balance: Wordpad-level simplicity and responsiveness paired with the non-linear power of the BTRON TAD hypermedia databus.

Typical Workflow

  1. Launch T-Editor instantly from Deskbar or with a hotkey.
  2. Type document content with seamless Mozc Japanese conversion (F10/F7/F8) and apply Heading or Body styles.
  3. The basic auto TAD layouter automatically formats line breaks and paragraph spacing to match current page margins.
  4. Drag reference Fusen links or Matrix charts from Cabinet directly into the text flow.
  5. Save the document directly as a BTRON3 binary TAD Real Body or export cleanly to plain text.
