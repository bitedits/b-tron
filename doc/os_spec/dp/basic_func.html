gloc_env
Lock Drawing Environment
gloc_env
【Формат / Синтаксис】
ERR gloc_env ( GID gid W lock )
【Опис та функціонал】

gid 指定した«Пристрій (Device)Графічний контекст (Draw Environment)» та , 同一 Пристрій (Device) 対する他 «デバ イスГрафічний контекст (Draw Environment)»から 書込みアクセス ロック(lock≠ 0 時), また ロック 解除(lock = 0 時)する.

Пристрій (Device) ロック対象外 Пристрій (Device) 場合, また Пам'ять (Memory)Графічний контекст (Draw Environment) 場合 , ロック 適用されず無視される.

ロックされたГрафічний контекст (Draw Environment) 描画(書込み) 行なった場合 , ロック 解除され るま 待たされる. 待たされている描画 複数存在した場合, 解除後 描画順 序 待たされた順番 та なる. 待つこ та よりデッドロック та なるような場合 , 待たず EG_LOCK エラー 各種 描画関数 戻されるこ та なる. ただし, こ デッドロック 検出 インプリメント 依存する.

【Значення, що повертається】
= 0(E_OK) : 正常終了
< 0 : エラー (関数値 Коди помилок)
【Коди помилок】
EG_GID
指定したГрафічний контекст (Draw Environment)ID 不正(存在しない).
EG_LOCK
既 ロックされている, また ロック 多すぎる.
EG_PAR
Параметри 不正, また 範囲外 ある. (ロックしたПроцес (Process) ない)
