Browser

HTML→TAD変換
Lightweight HTML 4.1 Browser with HTML-to-TAD Conversion (TAD API)
← Back to B-System Applications
"One-click bridge: turn any web page into a live, editable Real Body that lives inside your TAD universe via the TAD API."

Overview

Lightweight HTML 4.1 browser and TAD document converter. Renders hypermedia pages using the TAD browser engine (src/apps/tad_browser.c) and native conversion pipeline (scripts/html2tad.exs). Directly leverages the TAD API (tad_browser.h) and compiler engine to transform remote web articles, technical standards, and documentation into native BTRON3 binary TAD Real Bodies — permanently preserved in the knowledge base and linkable as Virtual Bodies inside any TAD document.

ブラウザ： 軽量・軽快なHTML 4.1 Webブラウザ。TADブラウザー表示基盤（src/apps/tad_browser.c）およびTAD変換パイプライン（scripts/html2tad.exs）に直結し、閲覧中のWebページをワンクリックでネイティブかつ編集可能なBTRON3バイナリ実身（TAD Real Body）へと変換・ローカル保存。Webの知識を永久不変のTAD知識資産として取り込みます。

Key Features & Implementation

  • 実体コード実装：src/apps/tad_browser.c（TADドキュメントブラウザー・パーサー）
  • TAD API直結による1クリックでのWebページ→TAD実身バイナリ完全変換
  • 無駄なスクリプトを排した超高速レンダリング（HTML 4.1 + CSS2）
  • T-Editorでの即座な再編集・注釈追記・実身リンク形成
  • 変換後のTAD実身は任意のドキュメント内に仮身（Virtual Body）として即座に埋め込み可能
  • 永続的なローカルアーカイブ — Web知識のサイロ化やリンク切れを完全防止
  • 元のURLおよび取得タイムスタンプをTADメタデータとして自動保持

Why the Market Needs It

  • Web content stays siloed in classic browsers: you can read it, but cannot edit or embed it back into the BTRON knowledge base.
  • Researchers lose the permanent knowledge link between a web page and a document every time a remote tab or URL changes.
  • Heavyweight modern browsers are inappropriate for a minimal, deterministic workstation environment; a lean HTML-to-TAD pipeline provides permanent knowledge stability.

Replaces / Normalises

Classic BTRON ProductB-System AdvantageTarget Users
Classic B-TRON WebView (plain HTML renderer, read-only) One-click export to editable TAD Real Body via TAD API; full round-trip editing in T-Editor Researchers, technical writers, developers capturing web-based knowledge
Stand-alone TAD-Viewer (read-only) Live web + TAD in one window, seamless back-link to knowledge base

Typical Workflow

  1. Open any web page or documentation in Browser.
  2. Press Export → TAD; the TAD API compiler transforms the page into a native Real Body.
  3. Annotate, add inline notes, or embed the Real Body into other documents via Virtual Bodies in T-Editor.
  4. Search the saved Real Body instantly from Clarity's global search bar.
