3.9 Метод введення TRON (Input Process FEP)

3.9.1 Огляд вхідного процесора методів введення (FEP)

Вхідний процесор методів введення (Front-End Processor / FEP) виконує інтерактивну конверсію фонотичних послідовностей у графічні та багатомовні символи TRON Code (включаючи ієрогліфічні конверсії Kana-Kanji, багатомовні введення).
