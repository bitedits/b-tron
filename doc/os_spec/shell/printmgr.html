3.8 Підсистема друку (Print Manager Specification)

3.8.1 Огляд підсистеми друку

Підсистема друку (Print Manager) BTRON3 керує форматуванням сторінок, підготовкою векторних та растрових графічних завдань друку та безпосередньою передачею сторінок на друкуючі пристрої (принтери, плотери).

opn_prn
Open Printer Job
Відкриття завдання друку

【Синтаксис / Прототип】

PRNID   opn_prn(TC *prnnm, PAGE_PARAM *param)

【Параметри】

TC         *prnnm   Логічна назва друкуючого пристрою (наприклад, "prn0")
PAGE_PARAM *param   Параметри сторінки (орієнтація, орієнтація A4/Letter, попиксельне розширення DPI)

【Значення, що повертається】

> 0      Успішне виконання (Дескриптор завдання друку PRNID)
< 0      Помилка (Код помилки)

【Детальний опис】

Ініціалізує нове графічне завдання друку на принтері prnnm з параметрами сторінки param.

【Коди помилок】

ER_ACCES   : Пристрій друку заблокований іншим завданням.
ER_ADR     : Неприпустима адреса вказівника prnnm або param.
ER_NOEXS   : Друкуючий пристрій відсутній.
