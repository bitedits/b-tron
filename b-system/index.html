Специфікація B-System (BTRON3 3.20)

B-System — це сучасна ергономічна реалізація стандартів BTRON3 3.20 та µITRON, розповсюджувана під пермісивними ліцензіями MIT / BSD 2-Clause / ISC. Система спроектована для віртуалізованих середовищ VirtIO 1.4, гіпервізорів seL4 / Synrc VE OS.1, радіотехнічної обробки сигналів (DSP/SDR) та неонової векторної wireframe-графіки (TRON / NetWars).

Примітка щодо сучасної архітектури 2026 року

Усі архаїчні апаратні обмеження (FDC, CHS, 16-бітна сегментація, ISA/VLB, COM-порти 8250/16550) повністю вилучені. B-System спирається на плоску адресацію RISC-V 64 / ARM64 / x86_64, VirtIO-MMIO/PCI, безблокувальні черги Virtqueue та хостовий біт-блітінг SDL2. Детальніше див. Умови ліцензії B-System.
