Calculator

高精度電卓
Scientific & Programmer Desktop Calculator
← Back to B-System Applications
"Precise scientific and programmer calculation — pure C99 mathematical engine with paper tape history and radix conversion."

Overview

Scientific and programmer desktop calculator engineered in pure C99 and rendered via Display Primitives (src/apps/calculator.c, src/graphics/dp_core.c). Provides arbitrary-precision integer arithmetic, IEEE-754 double precision floating-point evaluation, comprehensive trigonometric/hyperbolic/logarithmic functions, and programmer bitwise operations (HEX, DEC, OCT, BIN). Features a continuous paper roll calculation tape and seamless copy/paste to the system clipboard.

電卓： Display Primitives描画（src/graphics/dp_core.c）に基づく純粋C99製デスクトップ計算機。IEEE-754倍精度浮動小数点演算、任意桁整数計算、科学関数、およびプログラマー向け基数変換（HEX/DEC/OCT/BIN）とビット演算を完備。過去の計算履歴を連続記録するロールペーパーテープ機能、システムクリップボードへの直接コピー＆ペーストをサポートし、常に瞬時に起動して軽快に動作。

Key Features & Implementation

  • 実体UI描画：src/graphics/dp_core.c（電卓盤面・ボタン・ロールペーパー描画）
  • 科学技術計算（三角関数、双曲線関数、対数、累乗根）と高精度浮動小数点演算
  • 純粋C99システム設計（極小フットプリント・超低遅延起動）
  • プログラマー向け基数変換（16進数/10進数/8進数/2進数）とビット演算（AND, OR, XOR, NOT, SHL, SHR）
  • 計算履歴を追跡可能なスクロール対応ロールペーパーテープ
  • システムクリップボードを介した数値・数式のコピー＆ペースト
  • 単位換算（物理量・データサイズ・周波数・熱量）ライブラリ内蔵

Typical Workflow

  1. Open Calculator from Workbench or via global hotkey.
  2. Perform scientific or programmer calculations; formula and output are cleanly recorded on the history tape.
  3. Toggle between decimal and hexadecimal view to verify binary bit masks and registers.
  4. Press Copy (Ctrl+C) to copy the result or full formula to the OS clipboard.
  5. Paste values into Terminal, source code, or any document without proprietary hypermedia entanglement.
