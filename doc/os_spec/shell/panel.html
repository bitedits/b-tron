3.2 Менеджер панелей та діалогів (Panel & Dialog Management)

3.2.1 Огляд підсистеми управління панелями

3.2.1.1 Призначення діалогових панелей

Підсистема управління панелями (Panel Manager) призначена для побудови інтерактивних діалогових вікон, системних запитів, вікон параметрів налаштування та повідомлень про помилки в графічному середовищі BTRON3.

Панелі поділяються на модальні (Modal Panels) та немодальні (Modeless Panels). Модальні панелі блокують користувацький ввід у всі інші вікна програми до моменту закриття панелі кнопкою підтвердження (OK) або скасування (Cancel).

3.2.1.2 Типи панелей та системних повідомлень

Підтримуються наступні типи системних панелей:

  • Панелі системних сповіщень (System Message Panels): Виведення повідомлень про статус виконання системних операцій.
  • Панелі помилок (Error Alert Panels): Критичні сповіщення про помилки введення/виведення чи браку ресурсів.
  • Діалоги файлових операцій (File Request Panels): Панелі вибору реальних файлів, збереження та створення нових віртуальних об'єктів.

3.2.2 Системні виклики управління панелями

opn_pnl
Open Panel
Відкриття та відображення панелі діалогу

【Синтаксис / Прототип】

PNID    opn_pnl(WID wid, RECT *rect, W attr, TC *title, ITEM *items)

【Параметри】

WID     wid     Ідентифікатор батьківського вікна (або NULL)
RECT   *rect    Екранні координати та розміри панелі
W       attr    Прапори системних атрибутів панелі (Modal/Modeless)
TC     *title   Заголовок діалогової панелі у кодуванні TRON Code
ITEM   *items   Масив елементів та віджетів панелі (кнопки, текстові поля)

【Значення, що повертається】

> 0      Успішне виконання (Дескриптор відкритої панелі PNID)
< 0      Помилка (Код помилки)

【Детальний опис】

Створює та відображає панель діалогу pnl з елементами items у вікні wid.

【Коди помилок】

EW_ADR     : Неприпустима адреса вказівника rect, title або items.
EW_WID     : Недійсний ідентифікатор батьківського вікна wid.
EW_NOSPC   : Недостатньо оперативної пам'яті.
