2.3 Базові графічні функції та системний контекст (Core Graphics Functions)

Усі функції підсистеми графічних примітивів (Display Primitives) повертають значення типу W (або цілочисельний ідентифікатор). У разі виникнення помилки функція повертає від'ємне значення коду помилки. При успішному виконанні повертається 0 або додатне значення ідентифікатора.

Загальні коди помилок підсистеми графічних примітивів:

EG_ADR ( ((-64) << 16) )
Неприпустима адреса вказівника у графічному контексті або буфері.
EG_PAR ( ((-65) << 16) )
Некоректний параметр операції або значення виходить за допустимі межі.
EG_NOSPT ( ((-66) << 16) )
Запитана графічна функція чи режим не підтримується даною реалізацією ядра.
EG_NOSPC ( ((-67) << 16) )
Недостатньо оперативної пам'яті ядра для виділення растрового буфера.
EG_GID ( ((-68) << 16) )
Недійсний ідентифікатор графічного контексту GID (контекст відсутній або знищений).
EG_LOCK ( ((-69) << 16) )
Графічний контекст заблокований іншим паралельним процесом.
EG_LIMIT ( ((-70) << 16) )
Перевищено системний ліміт кількості відкритих графічних портів.
EG_NOEXS ( ((-71) << 16) )
Зазначений графічний пристрій не зареєстрований у системі.
EG_DEV ( ((-72) << 16) )
Некоректний тип пристрою або невідповідність форматів BitMap.
EG_ERDEV ( ((-73) << 16) )
Апаратна помилка графічного адаптера або відеопам'яті VRAM.

Усі координати малювання задаються у декартовій системі зі значеннями від $-32768$ до $+32767$.

2.3.1 Створення та видалення графічного контексту (Environment Allocation)

gini_dsp
Initialize Display Primitive Subsystem
Ініціалізація підсистеми графічних примітивів

【Синтаксис / Прототип】

ERR     gini_dsp(W mode)

【Параметри】

W   mode    Режим ініціалізації системної графіки

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Виконує початкову системну ініціалізацію підсистеми графічних примітивів BTRON3. Викликається ядром при старті графічної оболонки.

【Коди помилок】

EG_NOSPC   : Недостатньо системної пам'яті для графічних структур.
gcls_env
Delete Drawing Environment
Видалення графічного контексту

【Синтаксис / Прототип】

ERR     gcls_env(GID gid)

【Параметри】

GID gid     Ідентифікатор видаляємого графічного контексту

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Знищує графічний контекст gid та вивільняє пов'язану з ним оперативну пам'ять і буфери. Контекст може бути видалений лише тим процесом, що його створив.

【Коди помилок】

EG_GID     : Недійсний ідентифікатор контексту gid або спроба видалення стороннім процесом.
gopn_dev
Open Device Drawing Environment
Створення графічного контексту пристрою

【Синтаксис / Прототип】

GID     gopn_dev(TC *dev, B *par)

【Параметри】

TC *dev     Логічне ім'я пристрою відображення (наприклад, "disp0")
B  *par     Параметри пристрою

【Значення, що повертається】

>= 0     Успішне виконання (Новий ідентифікатор контексту GID)
< 0      Помилка (Код помилки)

【Детальний опис】

Створює новий графічний контекст пристрою для безпосереднього виведення на екран/пристрій dev та повертає дескриптор GID.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника dev.
EG_DEV     : Вказаний пристрій не підтримує графічний вивід.
EG_LIMIT   : Перевищено системний ліміт відкритих портів.
EG_NOEXS   : Пристрій dev відсутній у системі.
EG_NOSPC   : Недостатньо оперативної пам'яті.
gopn_mem
Open Memory Drawing Environment
Створення контексту малювання в пам'яті

【Синтаксис / Прототип】

GID     gopn_mem(TC *dev, BMP *bmap, B *par)

【Параметри】

TC  *dev    Пристрій прив'язки (NULL — загальний растровий контекст)
BMP *bmap   Вказівник на структуру растрового масиву BitMap у пам'яті
B   *par    Додаткові кольорові параметри

【Значення, що повертається】

>= 0     Успішне виконання (Новий ідентифікатор контексту GID)
< 0      Помилка (Код помилки)

【Детальний опис】

Створює новий контекст малювання в пам'яті на основі растрового масиву bmap. Усі наступні операції малювання спрямовуватимуться у виділений буфер у пам'яті.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника dev або bmap.
EG_DEV     : Невідповідність формату пікселів буфера bmap.
EG_LIMIT   : Перевищено ліміт відкритих портів.
EG_NOSPC   : Недостатньо пам'яті.
