2.2 Фундаментальні концепції графіки (Basic Graphics Concepts)

2.2.1 Координатні системи та растрові буфери

Усі графічні операції виконуються у двовимірній декартовій системі координат з віссю X, спрямованою праворуч, та віссю Y, спрямованою донизу.

1. Растровий масив BitMap :

Прямокутний масив пікселів у пам'яті, що містить кольорові значення або бітові маски.

2. Графічний порт GRAFPORT :

Системна структура контексту малювання, яка зберігає поточний колір ліній, колір заповнення, візерунок (Pattern), товщину пера, відсікальний регіон (Clip Region) та початкові координати зміщення.

typedef struct {
    H       x;          /* Координата X */
    H       y;          /* Координата Y */
} PNT;

typedef struct {
    H       left;       /* Ліва межа X */
    H       top;        /* Верхня межа Y */
    H       right;      /* Права межа X */
    H       bottom;     /* Нижня межа Y */
} RECT;
