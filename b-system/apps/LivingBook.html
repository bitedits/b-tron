Living Book

双方向書籍
Interactive Hypermedia TAD Experience
← Back to B-System Applications
"From static manual to interactive laboratory – every page becomes a live, multimedia-rich sandbox."

Overview

Turns any TAD document — including the four BTRON system books — into a fully interactive experience. Expand illustrations into scrubbable media, run embedded code examples live inside the page, and attach voice/video annotations that travel with the text as the reader navigates.

リビングブック： 4つのシステム解説書をはじめとするあらゆるTAD文書を、動的で双方向な体験へと進化。静止図版を動画メディアへ展開し、掲載コードをその場で実行。文書に連動して移動する音声・ビデオ注釈を添付可能。

Key Features

  • BTRON 4大システム書の完全インタラクティブ化
  • 紙面コードのインライン・ライブ実行環境（その場で出力確認）
  • ドキュメントに密着して移動するマルチメディア注釈（音声・動画）
  • Static illustrations expand into scrubbable video / 3-D Virtual Bodies on click
  • Export any enriched page as a permanent Real Body to Workbench or Clarity
  • Annotations and code results persist inside the TAD Real Body — no separate notebook needed

Why the Market Needs It

  • BTRON system books are still distributed as static PDFs; developers cannot run example code or see live demos while reading.
  • Learning material is isolated from the interactive TAD workflow — annotating a PDF does not create a Real Body.
  • Conventional e-book readers have no concept of Virtual Body embedding or TAD hypermedia structure.

Replaces / Normalises

Typical Workflow

  1. Open a System Book or any TAD document in Living Book.
  2. Click a diagram → it expands to a scrubbable video Virtual Body inline.
  3. Click a code block → run it in place; output appears as a linked Real Body below the snippet.
  4. Record a voice note at a heading → it attaches to the paragraph and moves with it on navigation.
  5. Export the enriched page as a Real Body into Workbench for long-term reference, or embed it in a Clarity reading session.
