3.10 Системний трей та сповіщення (Tray Manager Specification)

3.10.1 Огляд підсистеми управління треєм

Підсистема Менеджера трею (Tray Manager) відповідає за візуалізацію та управління фоновими статусними віджетами, системним годинником, індикаторами мережі, батареї та чергою сповіщень системної оболонки BTRON3.

3.10.2 Системні виклики Менеджера трею

topn_tra
Open Tray
Створення та відкриття системного трею

【Синтаксис / Прототип】

TRAYID  topn_tra(RECT *rect, W attr, TC *title)

【Параметри】

RECT   *rect    Екранні координати розміщення системного трею
W       attr    Атрибути трею (Horizontal / Vertical, AutoHide)
TC     *title   Назва трею у кодуванні TRON Code

【Значення, що повертається】

> 0      Успішне виконання (Дескриптор трею TRAYID)
< 0      Помилка (Код помилки)
tcls_tra
Close Tray
Закриття системного трею

【Синтаксис / Прототип】

ERR     tcls_tra(TRAYID trayid)
tpsh_dat
Push Data to Tray
Додавання нового елемента / сповіщення у трей

【Синтаксис / Прототип】

ITEMID  tpsh_dat(TRAYID trayid, TRAY_ITEM *item)

【Параметри】

TRAYID     trayid  Дескриптор відкритого системного трею
TRAY_ITEM *item    Структура опису елемента трею (іконка, заголовок, підказка)

【Значення, що повертається】

> 0      Дескриптор елемента ITEMID
< 0      Помилка (Код помилки)
tpop_dat
Pop Data from Tray
Вилучення останнього елемента з трею

【Синтаксис / Прототип】

ERR     tpop_dat(TRAYID trayid, TRAY_ITEM *item)
tdel_dat
Delete Tray Item
Видалення елемента трею за ідентифікатором

【Синтаксис / Прототип】

ERR     tdel_dat(TRAYID trayid, ITEMID itemid)
tsel_dat
Select Tray Item
Вибір або активація елемента у треї

【Синтаксис / Прототип】

ERR     tsel_dat(TRAYID trayid, ITEMID itemid)
tmov_dat
Move Tray Item
Зміна позиції елемента у треї

【Синтаксис / Прототип】

ERR     tmov_dat(TRAYID trayid, ITEMID itemid, W pos)
tget_sts
Get Tray Status
Зчитання загального стану системного трею

【Синтаксис / Прототип】

ERR     tget_sts(TRAYID trayid, TRAY_STAT *stat)
tset_dat
Set Tray Item Data
Налаштування параметрів елемента трею

【Синтаксис / Прототип】

ERR     tset_dat(TRAYID trayid, ITEMID itemid, TRAY_ITEM *item)
tget_dat
Get Tray Item Data
Зчитання даних елемента системного трею

【Синтаксис / Прототип】

ERR     tget_dat(TRAYID trayid, ITEMID itemid, TRAY_ITEM *item)

【Параметри】

TRAYID     trayid  Дескриптор системного трею
ITEMID     itemid  Ідентифікатор елемента трею
TRAY_ITEM *item    Буфер для збереження даних елемента (Вихід)

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)
