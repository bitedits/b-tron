Workbench

空間デスクトップ
Spatial Desktop & Object Manager
← Back to B-System Applications
"Your objects, your space – a 3-D-aware desktop that treats every file, window and virtual-body as a first-class object."

Overview

Spatial desktop and object manager. Icons are Real Bodies. Any window can be miniaturised and dropped into a document as a living Virtual Body. Fluid, always-snappy navigation with strong attribute and live-query support.

ワークベンチ： アイコンそのものが「実身（Real Body）」。開いているあらゆるウィンドウを瞬時にミニチュア化し、ドキュメント内へ生きた仮想オブジェクトとしてドロップ可能。属性検索とライブクエリをフルサポートした、滑らかで軽快極まる空間デスクトップマネージャ。

Key Features

  • 実身アイコンとウィンドウのミニチュア仮身オブジェクト化
  • 属性ベースのリアルタイム・ライブクエリ（Live Query）
  • ファイル階層を超越した空間的オブジェクト管理
  • Real Body ↔ Virtual Body relationships visualised spatially
  • Snap to custom workspaces or switch to list mode for power navigation
  • Instant search across all Real Bodies without opening a separate indexer

Why the Market Needs It

  • Users still juggle multiple list-views, separate file-managers and "virtual-body" windows with no unified context.
  • Classic B-TRON Desktop and Object-Manager have no visual spatial representation of Real Body ↔ Virtual Body relationships.
  • No live-query without a separately launched indexer application.

Replaces / Normalises

Classic BTRON ProductB-System AdvantageTarget Users
B-TRON Desktop (icon-grid file manager) Spatial, 3-D-aware; Real/Virtual Body unified view with hover miniatures Power users, system integrators, UI/UX designers needing a "virtual office"
B-TRON Object-Manager (list only) Live-query across all objects in real time — no separate indexer needed

Typical Workflow

  1. Drag a Real Body (e.g. PDF, image, code snippet) onto the Workbench canvas.
  2. Rearrange objects freely in spatial mode, or snap to a named workspace group.
  3. Switch to list mode for quick keyboard-driven navigation when needed.
  4. Live-query bar: type an attribute to filter all visible objects in real time.
  5. Miniaturise any open window and drop it into a TAD document as a Virtual Body.
