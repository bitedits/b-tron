Music

音響制作
Lightweight Composition & Audio Synthesis
← Back to B-System Applications
"Compose patterns as Virtual Bodies — reuse them directly in MediaPulse timelines or TAD documents"

Overview

Lightweight composition and audio playback tool backed by the pure C99 audio pipeline in src/apps/audio_player.c. Patterns, samples and entire projects exist as Virtual Bodies reusable in MediaPulse timelines or embedded in TAD documents.

ミュージック： リアルタイムC99オーディオエンジン（src/apps/audio_player.c）を基盤とする軽量な音楽制作・波形編集・シンセシスツール。作曲したパターン、録音サンプル、プロジェクト全体が仮想オブジェクトとして存在し、MediaPulseのタイムラインやTAD文書で直接再利用可能。

Key Features & Implementation

  • 実体コード実装：src/apps/audio_player.c（オーディオバッファ管理・PCMストリーミング・再生エンジン）
  • μITRON高精度タイマーに基づくジッターフリー再生エンジン
  • パターンやサンプル単位での仮身オブジェクト再利用
  • MediaPulseとのゼロコピー・オーディオルーター連携
  • Step sequencer, waveform editor and basic synthesis in one minimal tool
  • Export patterns as audio Real Bodies that can be attached to Living Book pages
  • MIDI Virtual Body output linkable to external hardware via VirtIO

Typical Workflow

  1. Create a rhythm pattern in Music's step sequencer.
  2. Drag the pattern out as a Virtual Body — drop it into a MediaPulse timeline for instant playback in context.
  3. Embed the audio Virtual Body into a Living Book page to make a tutorial interactive.
  4. Export the full project as an audio Real Body for long-term archival in the TAD Cabinet.
