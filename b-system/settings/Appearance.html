Appearance — Themes, colours, window style, icons, fonts and animation level.

Overview

Themes, colours, window style, icons, fonts and animation level.

デスクトップテーマ、配色パレット、坂村クラシックスタイル／モダンウィンドウスタイル、アイコンセット、明朝・ゴシックフォント指定、UIアニメーション速度の調整。

Configuration Options

  • Theme selector: Sakamura Classic, Modern Glass, or High-Contrast
  • Per-app colour palette overrides stored as Real Bodies
  • Icon set switching (BTRON standard, minimal, custom)
  • Typeface assignment: Mincho / Gothic / Mixed for UI and documents
  • Animation speed: Off / Reduced / Full
  • Accent colour picker with live preview in Workbench
