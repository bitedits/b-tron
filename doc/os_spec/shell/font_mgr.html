3.7 Менеджер шрифтів (Font Manager Specification)

3.7.1 Огляд підсистеми Менеджера шрифтів

3.7.1.1 Архітектура Менеджера шрифтів

Менеджер шрифтів (Font Manager) є системною підсистемою BTRON3, що забезпечує реєстрацію, вилучення, вибір альтернативних замінників та надання растрових (BitMap) та векторних (Outline Vector) шрифтових гарнітур для виведення багатомовного тексту в кодуванні TRON Code.

Підсистема малювання графічних примітивів (Display Primitives) використовує Менеджер шрифтів для отримання растрових масок символів та їхніх системних метрик (ширина, висунення, аскендер/дескендер).

Мал. 125: Схема взаємодії Менеджера шрифтів та підсистеми Display Primitives

3.7.1.2 Гарнітури, класи та атрибути шрифтів

Шрифти BTRON3 класифікуються за трьома основними параметрами:

1. Гарнітура / Родина шрифту (Font Family) :

Назва родини шрифтів (до 12 символів TRON Code, наприклад "Ming-style", "Gothic").

2. Клас шрифту (Font Class / FTC) :

32-бітне числове значення, що описує стилістичні характеристики дизайну символів та використовується для автопідбору подібного шрифту-замінника при відсутності запитаної гарнітури (FTC_DEFAULT = 0x80000000).

3. Атрибути шрифту (Font Attributes) :

Варіації накреслення: товщина пера (Normal/Bold), нахил (Roman/Italic), моноширинність та пропорційність.

3.7.2 Системні виклики Менеджера шрифтів

reg_fnt
Register Font Data
Реєстрація нового шрифту у системі

【Синтаксис / Прототип】

ERR     reg_fnt(LINK *lnk, W mode)

【Параметри】

LINK   *lnk     Посилання на файл шрифтових даних (ROM / File Font)
W       mode    Режим реєстрації шрифту (System Global / Process Local)

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Реєструє новий шрифтовий файл lnk у системному реєстрі Менеджера шрифтів.

【Коди помилок】

ER_ACCES   : Відсутні права доступу до файла шрифту.
ER_ADR     : Неприпустима адреса вказівника lnk.
ER_NOEXS   : Файл шрифту відсутній.
ER_NOSPC   : Недостатньо пам'яті для завантаження шрифтових метрик.
lst_fnt
List Installed Fonts
Отримання списку встановлених шрифтів

【Синтаксис / Прототип】

WERR    lst_fnt(FNT_INFO *buf, W max_cnt)

【Параметри】

FNT_INFO *buf   Буфер для збереження масиву інформаційних структур шрифтів
W       max_cnt Максимальна кількість елементів буфера

【Значення, що повертається】

>= 0     Успішне виконання (Фактична кількість зареєстрованих шрифтів)
< 0      Помилка (Код помилки)

【Детальний опис】

Повертає перелік усіх встановлених у системі гарнітур та їхніх метрик у масив buf.

【Коди помилок】

ER_ADR     : Неприпустима адреса буфера buf.
