Overview

Ski Bootloader (ski.c) is the official boot manager application for B-System. It combines the aesthetic quality and interactive grace of Haiku's BootManager with the rigorous engineering standards of NetBSD's boot infrastructure, all while authentically preserving the legacy BTRON booting experience. Ski Bootloader provides both a rich graphical presentation and an authentic ANSI console selector with live kernel command-line editing and multi-core affinity allocation.

スキー・ブートローダー（Ski Bootloader）： B-Systemの公式ブートマネージャ・アプリケーション（ski.c）。Haiku流の洗練されたUI造形美とNetBSD水準の堅牢なブートマネージャ品質を融合し、BTRON伝統の起動体験（実身ブートログ、T-Monitorカウントダウン）を完全再現。Raspberry Pi 1〜5（ARM MMIO）、x86_64 UEFI SMP（ACPI MADT AP起動）、そしてNEC PC-98（i386/i486/Pentium リアルモード）という3大ハードウェアアーキテクチャを統合サポートします。

Key Features

  • 🎿 Ski Interactive Boot Menu (ski.c) — Dual mode: Graphical BTRON glyph canvas and ANSI terminal with keyboard navigation ([↑/↓], [W/S]), inline command line editing ([E]), and multi-core CPU affinity control ([+]/[-]).
  • ARM MMIO Boot Drivers (Raspberry Pi 1, 2, 3, 4, 5) — Native VideoCore Mailbox initialization (Channel 8 properties), PL011 UART console mirror, DWC2 USB / SMSC9118 Ethernet stubs, and BCM2712 / RP1 south-bridge ABI mappings for Pi 5.
  • x86_64 UEFI SMP (core_smp.c) — Cleanroom UEFI implementation without TianoCore EDK II dependencies: GOP framebuffer discovery, ACPI 6.5 XSDT/MADT parser, LAPIC MMIO (0xFEE00000), 16-bit AP trampoline at 0x9000, and INIT-SIPI-SIPI multi-core rendezvous.
  • Authentic PC-98 i386 Real-Mode Boot (boot_pc98.c) — Full NEC PC-9801/PC-9821 support: planar VRAM text splash at 0xA0000/0xA2000, INT 1Ah RTC clock reads, INT 2Fh BTRON protocol handshake, A20 gate activation via port 0xF2, and 32-bit Protected Mode transition.
  • Multi-OS & Unikernel Card Registry — Instant boot targets for B-System BTRON3, T-Kernel 2.0, seL4 Microkernel, NetBSD 11.0 (smolBSD MICROVM), PC-98 Linux 7.1, NEC V30 os8088, NuttX 12.0, FreeRTOS, and Erlang/OCaml unikernels.
  • TAD Real Body Boot Persistence — Automatically archives boot selections, kernel arguments, and hardware timestamps into permanent TAD Real Body logs for inspection via Clarity.
  • Emergency T-Monitor Fallback — Direct failover to low-level T-Monitor shell ([S]) upon kernel fault or invalid device tree configuration.

Why the Market Needs It

  • Classic B-TRON systems lacked a dynamic multi-architecture boot manager — booting alternate kernels required manual configuration file modifications prior to power-on.
  • Modern UEFI bootloaders (GRUB2, systemd-boot) are heavy, POSIX-dependent, and lack cleanroom integration with T-Kernel and BTRON real-body file structures.
  • Haiku's BootManager is restricted to x86 BeOS systems and does not address ARM MMIO mailboxes or Japanese retrocomputing architectures like the PC-98.
  • Developers deploying microkernels (seL4) and hypervisors need seamless transfer of boot parameters into shared memory buffers across heterogeneous CPU topologies.

Typical Workflow

  1. Firmware Handoff — Within 50 ms of system power-on, Ski Bootloader activates the native display (GOP on UEFI, VideoCore mailbox on Pi, planar VRAM on PC-98).
  2. Interactive Selection — The Ski menu presents available operating systems, unikernels, and hardware targets. Use [↑/↓] or [W/S] to highlight an entry.
  3. Fine-Tuning — Press [E] to customize boot arguments (e.g., console baud rate, root filesystem, memory limits). Press [+] or [-] to scale allocated CPU cores.
  4. Execution & Rendezvous — Press [Enter] to boot. On SMP systems, Ski coordinates all AP cores via LAPIC SIPI sequences before leaping into the kernel entry point.
  5. TAD Knowledge Archival — Boot parameters, hardware discovery logs, and timestamps are recorded into a persistent TAD Real Body for post-boot diagnostics.
