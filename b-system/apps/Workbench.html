"Minimalist spatial desktop and instant root menu — pure C99 workspace manager and application launcher in the spirit of CTWM and Haiku Deskbar."

Overview

Spatial desktop canvas and central system root menu inspired by CTWM's workspace manager and the Haiku / BeOS Deskbar menu. Implemented as a pure C99 system application backed by src/desktop/main.c (main launcher and event loop) and src/desktop/desktop.c (desktop compositor and screen device manager), directly interfacing with the BTRON window manager (btron/wnd.h), display primitives (btron/dp.h), and event loop (btron/event.h). Future enhancements will introduce a dedicated root menu system and tracker.c for desktop task and window tracking. Rather than acting as a file manager — a role fulfilled exclusively by Cabinet Explorer and Commander — Workbench provides the desktop backdrop, spatial window management, multi-workspace virtual desktops, process task switching, and instantaneous root menu launching.

ワークベンチ： CTWMのルートメニューやHaiku Deskbarの即応性を継承した、純粋C99製デスクトップ＆システムメニュー。実体コードは src/desktop/main.c（メインランチャー＆イベントループ）および src/desktop/desktop.c（デスクトップコンポジタ＆背景描画）で構成され、将来的な拡張として階層型 menu サブシステムおよびタスク追跡モジュール tracker.c の統合を予定。ファイルやオブジェクトの管理はキャビネット・エクスプローラー（Cabinet Explorer）が担うため、ワークベンチ自身はファイルマネージャではなく、空間デスクトップキャンバス、仮想ワークスペース切り替え、タスク管理、および右クリック/タスクバーによる階層型ルートメニューの提供に特化。

  • 実体コード実装：src/desktop/desktop.c（デスクトップコンポジタ、背景描画、画面デバイス管理）
  • 将来ロードマップ：CTWM風ルート menu サブシステム ＆ タスク追跡 tracker.c モジュール
  • CTWM風ルートメニュー＆Haiku Deskbarスタイルの高速階層型アプリケーションランチャー
  • 純粋C99システム設計（超軽量・低レイテンシ・極小メモリフットプリント）
  • 仮想ワークスペース管理（マルチデスクトップ切り替え）
  • アクティブウィンドウ一覧・タスク切り替えおよびウィンドウ配置制御
  • Cabinet Explorer、Terminal、T-Editor、各種アクセサリへのワンクリック即座アクセス

Why the Market Needs It

  • Monolithic desktop shells frequently combine the desktop canvas, root menus, file indexing, and document authoring into a bloated single process.
  • Separating the desktop and menu orchestration (Workbench) from the object/cabinet manager (Cabinet Explorer) ensures the system shell remains uncrashable, instantaneous to initialize, and purely focused on window management.
  • Delivers the lightning-fast, keyboard-and-mouse-friendly feel of CTWM and Haiku Deskbar on modern TRON workstations.

Typical Workflow

  1. Boot into B-System — Workbench renders the desktop canvas and initializes the system root menu and Deskbar in microseconds.
  2. Click anywhere on the desktop or press the menu key to trigger the CTWM/Haiku-style root launcher menu.
  3. Launch Cabinet Explorer to browse Real Body cabinets and documents, or launch Terminal for shell operations.
  4. Switch smoothly between virtual workspaces to organize active tasks and windows.
  5. Use the window list in the menu to jump directly to minimized or covered windows.
