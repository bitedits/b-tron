3.3 Системні меню (Menu System)

3.3.1 Огляд підсистеми управління меню

Підсистема системних меню забезпечує стандартний графічний інтерфейс команд користувача у вигляді випадаючих меню (Pulldown Menus) у верхній частині вікна та контекстних вспливаючих меню (Popup Context Menus).

3.3.2 Типи елементів системних меню

У специфікації BTRON3 виділяють наступні типи контрольних елементів меню:

  • Text Button (TB): Текстова кнопка команди меню.
  • Icon Button (XB): Графічна кнопка-іконка.
  • Number Box (NB): Поле введення числових значень.
  • String Box (SB): Поле введення текстових рядків.
  • Attribute Selector (AS): Перемикач атрибутів та вибір режимів.
  • Menu Selector (MS): Селектор підменю.
  • Palette (PA): Палітра кольорів та інструментів малювання.
  • Popup Menu (PM): Вспливаюче контекстне меню.
  • Window Selector (WS): Список активних відкритих вікон.
  • System Selector (SS): Системний селектор конфігурації.
  • Value Level (VL): Ползунок/індикатор рівня числових значень.
opn_mnu
Open Menu
Відображення системного меню

【Синтаксис / Прототип】

MNID    opn_mnu(WID wid, PNT pos, MENU *mnu, W attr)

【Параметри】

WID     wid     Ідентифікатор батьківського вікна
PNT     pos     Екранні координати відображення меню (X, Y)
MENU   *mnu     Структура опису елементів меню
W       attr    Прапори атрибутів (Context Popup / Main Pulldown)

【Значення, що повертається】

> 0      Успішне виконання (Дескриптор меню MNID)
< 0      Помилка (Код помилки)

【Детальний опис】

Відображає системне меню mnu в екранних координатах pos у вікні wid.

【Коди помилок】

EW_ADR     : Неприпустима адреса вказівника mnu.
EW_WID     : Недійсний ідентифікатор вікна wid.
