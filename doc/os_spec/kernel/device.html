1.8 Менеджер пристроїв (Device Management)

1.8.1 Загальні відомості

Підсистема управління пристроями ядра BTRON забезпечує уніфікований асинхронний та синхронний ввід/вивід для символьних (Character), блокових (Block) та спеціальних пристроїв через дескриптор пристрою (DID).

1.8.2 Іменування та типи пристроїв

Пристрої ідентифікуються логічними назвами у кодуванні TRON Code (наприклад, "fdd", "hdd", "com", "kbd").

1.8.3 Структури даних та константи

□ Режими відкриття пристрою (Open Mode)

#define TD_READ     0x0001  /* Дозвіл на читання */
#define TD_WRITE    0x0002  /* Дозвіл на запис */
#define TD_EXCL     0x0100  /* Ексклюзивний монопольний доступ */
#define TD_WAIT     0x0200  /* Очікування вивільнення пристрою */

□ Інформація про пристрій (DEV_INFO)

typedef struct {
    TC  name[L_DEVNM];      /* Логічна назва пристрою */
    UW  attr;               /* Атрибути пристрою (тип, блоковий/символьний, знімний) */
    W   blksz;              /* Розмір блоку у байтах (для блокових пристроїв) */
    W   nblk;               /* Загальна кількість блоків */
} DEV_INFO;

1.8.4 Системні виклики Менеджера пристроїв

opn_dev
Open Device
Відкриття пристрою та отримання дескриптора DID

【Синтаксис / Прототип】

DID opn_dev(TC *devnm, W mode)

【Параметри】

TC *devnm   Логічна назва пристрою
W   mode    Режим відкриття (TD_READ, TD_WRITE, TD_EXCL, TD_WAIT)

【Значення, що повертається】

> 0     Дескриптор пристрою (DID)
< 0     Помилка (ER_NOEXS, ER_BUSY, ER_NOSPC, ER_PAR)
cls_dev
Close Device
Закриття пристрою

【Синтаксис / Прототип】

ERR cls_dev(DID did)

【Параметри】

DID did     Дескриптор відкритого пристрою
rea_dev
Read Device
Зчитування даних з пристрою

【Синтаксис / Прототип】

WERR rea_dev(DID did, W start, VP buf, W size, TMO tmout)

【Параметри】

DID   did   Дескриптор пристрою
W     start Початковий номер блоку (або зсув)
VP    buf   Буфер для зчитаних даних
W     size  Кількість байтів для зчитування
TMO   tmout Таймаут очікування у мілісекундах (TMO_FEVR = нескінченно, TMO_POL = без очікування)

【Значення, що повертається】

>= 0    Кількість фактично зчитаних байтів
 < 0    Помилка (ER_DID, ER_IO, ER_TMOUT)
wri_dev
Write Device
Запис даних на пристрій

【Синтаксис / Прототип】

WERR wri_dev(DID did, W start, VP buf, W size, TMO tmout)

【Значення, що повертається】

>= 0    Кількість фактично записаних байтів
 < 0    Помилка (ER_DID, ER_IO, ER_TMOUT)
chg_dmd
Change Device Mode
Зміна режиму відкриття пристрою

【Синтаксис / Прототип】

ERR chg_dmd(DID did, W mode)
dev_sts
Device Status / Control (ioctl)
Отримання статусу та керування пристроєм

【Синтаксис / Прототип】

WERR dev_sts(DID did, W req, VP buf)

【Параметри】

DID did     Дескриптор пристрою
W   req     Команда керування або запиту статусу
VP  buf     Буфер передачі/прийому параметрів
get_dev
Get Device Information
Отримання інформації про зареєстрований пристрій

【Синтаксис / Прототип】

ERR get_dev(TC *devnm, DEV_INFO *info)
lst_dev
List Registered Devices
Отримання переліку зареєстрованих у системі пристроїв

【Синтаксис / Прототип】

WERR lst_dev(DEV_INFO *info, W cnt)

【Значення, що повертається】

>= 0    Кількість зареєстрованих пристроїв
 < 0    Помилка
sus_dev
Suspend Device
Переведення пристрою у стан сну / зупинки

【Синтаксис / Прототип】

ERR sus_dev(DID did, W mode)
