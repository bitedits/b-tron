3.6 Менеджер даних та датабоксів (Data Manager & Data Box)

3.6.1 Огляд підсистеми Менеджера даних

3.6.1.1 Архітектура Датабоксів (Data Box Concept)

Менеджер даних (Data Manager) відокремлює фіксовані системні та прикладні графічні/текстові ресурси від виконуваного коду програм і централізовано зберігає їх у спеціальних ресурсових контейнерах — **Датабоксах (Data Boxes)**.

Датабокси поділяються на 2 основні типи:

  • Системний датабокс (System Data Box): Єдиний глобальний системний контейнер, що містить системні шрифти, стандартні піктограми, системні курсори, палітри та шаблони вікон.
  • Прикладний датабокс (Application Data Box): Контейнер ресурсів конкретного додатка, що зберігає власні меню, діалогові вікна, малюнки та локалізований текст.

3.6.1.2 Типи даних у датабоксах (Data Types)

Кожен ресурс у датабоксі ідентифікується за парами: **Ідентифікатор типу даних (Data Type ID)** та **Унікальний номер (Data Number > 0)**.

PICT_DATA2Графічні піктограми системних об'єктів
PAT_DATA3Візерунки штриховки та растрові патерни
BMAP_DATA4Растрові зображення BitMap

TEXT_DATA6Текстові масиви TRON Code

PANEL_DATA10Описи діалогових панелей
USER_DATA64+Прикладні ресурси додатків користувача

3.6.2 Системні виклики Менеджера даних

opn_dtb
Open Data Box
Відкриття датабоксу ресурсів

【Синтаксис / Прототип】

DTBID   opn_dtb(LINK *lnk, W mode)

【Параметри】

LINK   *lnk     Посилання на файл датабоксу (NULL — Системний датабокс)
W       mode    Режим відкриття датабоксу

【Значення, що повертається】

> 0      Успішне виконання (Дескриптор датабоксу DTBID)
< 0      Помилка (Код помилки)

【Детальний опис】

Відкриває файл ресурсового датабоксу lnk та завантажує його індексну таблицю у спільну оперативну пам'ять ядра.

【Коди помилок】

ER_ACCES   : Відсутні права доступу до файла датабоксу.
ER_ADR     : Неприпустима адреса вказівника lnk.
ER_NOEXS   : Зазначений файл датабоксу відсутній.
get_dat
Get Data Item
Отримання вказівника на ресурс з датабоксу

【Синтаксис / Прототип】

VP      get_dat(UH type, H no)

【Параметри】

UH      type    Тип даних ID (PICT_DATA, BMAP_DATA, PANEL_DATA тощо)
H       no      Унікальний номер ресурсу

【Значення, що повертається】

!= NULL  Успішне виконання (Адреса ресурсу у спільній пам'яті)
= NULL   Помилка (Ресурс з вказаним типом та номером відсутній)

【Детальний опис】

Шукає ресурс за типом type та номером no серед усіх відкритих датабоксів процесу та повертає вказівник на його структуру у пам'яті.

【Коди помилок】

ER_PAR     : Неіснуючий тип даних type або від'ємний номер no.
