1.3 Синхронізація та комунікація задач (Task Communication & Synchronization)

Підсистема ядра надає наступні 4 фундаментальні механізми для синхронізації та обміну даними між задачами:

  • Семафори (Semaphores) — лічильні та взаємовиключні м'ютекси
  • Подієві прапорці (Event Flags) — бітові маски сигналізації
  • Буфери повідомлень (Message Buffers) — локальна черга повідомлень
  • Рандеву (Rendezvous) — синхронне двостороннє передавання даних

, ID ( > 0 ) .

Головна відмінність від міжпроцесних повідомлень полягає в тому, що ці механізми призначені для швидкої прямої синхронізації між окремими задачами (потоками). Базовим призначенням є внутрішньопроцесна взаємодія задач, проте створені об'єкти за наявності ID доступні для використання будь-якими процессами системи.

1.3.1 Визначення типів даних та констант

□ Визначення інтервалів таймауту

typedef W   TMOUT;          /* Значення таймауту (у мілісекундах) */

#define T_NOWAIT    ( 0)    /* Режим без очікування (T_NOWAIT = 0) */
#define T_FOREVER   (-1)    /* Нескінченне очікування (T_FOREVER = -1) */

□ Константи типів сефору

#define SEM_SYNC    0x0000  /* Семафор синхронізації (SEM_SYNC) */
#define SEM_EXCL    0x4000  /* Семафор взаємного виключення / М'ютекс (SEM_EXCL) */

□ Константи режимів очікування прапорців

#define WF_AND      0x0000  /* Очікування виконання всіх бітів (WF_AND) */
#define WF_OR       0x0002  /* Очікування виконання хоча б одного біта (WF_OR) */
