Clock

時刻・タイマー
Elegant Clocks, Timers & World Time
← Back to B-System Applications
"A live clock Virtual Body that sits in any TAD document or Workbench corner — always available, never intrusive"

Overview

Elegant clock, timers, alarms and world clocks. Can live as a small always-available Virtual Body in any TAD document or on the Workbench canvas.

時計： 美麗なアナログ・デジタル表示、高精度タイマー、アラーム、世界時計。デスクトップの隅や任意の文書内に常駐する、軽量で常時利用可能な仮想オブジェクトとして稼働。

Key Features

  • 世界各国のタイムゾーン表示とミリ秒精度タイマー
  • TAD文書内へライブ稼働する時計オブジェクトを埋め込み
  • システムアラームとμITRONリアルタイムスケジューラ連動
  • Multiple simultaneous world-clock faces as separate Virtual Bodies
  • Countdown timer Virtual Body embeddable in Living Book or meeting notes
  • Alarm triggers can fire Real Body creation events in other apps

Typical Workflow

  1. Open Clock; set a world clock for Tokyo, Zurich, and New York.
  2. Drag any clock face onto the Workbench canvas — it persists as a live Virtual Body.
  3. Embed a countdown Virtual Body into a T-Editor meeting agenda — it ticks live inside the document.
  4. Set an alarm; when it fires it creates a timestamped Real Body entry in Clarity's journal.
