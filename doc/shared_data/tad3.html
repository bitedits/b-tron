3.6 Графічні сегменти (Figure Fusen)

3.6.1 Загальний огляд

Графічні сегменти (Figure Fusen) призначені для представлення векторних та растрових графічних елементів у форматі TAD. Перелік основних типів графічних сегментів та їхні ідентифікатори (ID) наведено у таблиці нижче.

Графічний сегментID
Графічний примітив (Figure Primitive)TS_FPRIM(0xB0)
Визначення графіки (Figure Definition)TS_FDEF(0xB1)
Графічна група (Figure Group)TS_FGRP(0xB2)
Графічний макрос / виклик (Figure Macro/Call)TS_FMAC(0xB3)
Графічні атрибути (Figure Attribute)TS_FATTR(0xB4)
Сторінка графічного сегмента (Figure Page Fusen)TS_FPAGE(0xB5)
(Зарезервовано)------(0xB6〜0xBD)
Замітка графічного сегмента (Figure Memo Fusen)TS_FMEMO(0xBE)
Графічний сегмент додатка (Application Figure Fusen)TS_FAPPL(0xBF)

Кожен графічний сегмент містить ідентифікатор типу (ID). Ідентифікатори підтипів від 0 до 127 визначені специфікацією TAD як системні, а значення від 128 до 255 відведені для специфічних розширень додатків (Application Fusen). Для сегментів додатків указується додатковий ідентифікатор додатка.

Мал. 46 : Структура графічного сегмента

Графічні сегменти, як і інші види сегментів TAD, можуть розширюватися додатками. Додатки, які не підтримують окремі графічні сегменти, можуть безпечно пропускати їх без порушення обробки решти документа.

3.6.2 Графічні примітиви (Figure Primitive Segment TS_FPRIM)

Загальний огляд

Сегмент графічних примітивів (TS_FPRIM) визначає елементарні геометричні фігури. Примітиви поділяються на заповнені фігури, контурні (лінійні) фігури, текстові елементи та растрові зображення. Вони безпосередньо відображаються функціями графічних примітивів (Display Primitives).

<Заповнені фігури> 
Прямокутник (Rectangle)           -- Заповнений прямокутник
Скруглений прямокутник            -- Прямокутник зі скругленими кутами
Еліпс / Коло (Ellipse / Circle)   -- Заповнений еліпс або коло
Сектор (Pie / Sector)             -- Сектор, обмежений дугою та радіусами
Хорда (Chord)                     -- Сегмент, обмежений дугою та хордою
Багатокутник (Polygon)            -- Заповнений багатокутник
<Контурні / Лінійні фігури> 
Відрізок прямої (Line)            -- Лінійний відрізок
Дуга (Arc)                        -- Дуга еліпса або кола
Ламана лінія (Polyline)           -- Послідовність з'єднаних відрізків

<Текстовий примітив>

<Растрове зображення> 
Бітова матриця (Bitmap)           -- Растрове зображення

Кожен графічний примітив містить параметри малювання, які визначають режим накладання (Mode), товщину лінії, візерунки лінії та заповнення, а також координати.

<Режим малювання (Mode)>

Режим малювання задає логічну операцію між пікселями джерела (src) та пікселями призначального зображення (dest) з виведенням результату (result): 

        0       STORE   : (src)                         →  (result) (Прямий запис)
        1       XOR     : (src) XOR (dest)              →  (result) (Виключне АБО)
        2       OR      : (src) OR  (dest)              →  (result) (Логічне АБО)
        3       AND     : (src) AND (dest)              →  (result) (Логічне І)
        4       CPYN    : (NOT (src))                   →  (result) (Інверсія джерела)
        5       XORN    : (NOT (src)) XOR (dest)        →  (result)
        6       ORN     : (NOT (src)) OR  (dest)        →  (result)
        7       ANDN    : (NOT (src)) AND (dest)        →  (result)
        8〜255   Зарезервовано
<Атрибут лінії (l_atr)>

Параметр l_atr описується величиною типу UH (16 біт), де молодші 8 біт задають товщину лінії (0-255 пікселів), а старші 8 біт задають ідентифікатор стилю лінії. 

    TTTT TTTT WWWW WWWW
W : Товщина лінії (Line Width) (8 біт) (0〜255)
Задає товщину лінії в пікселях. Якщо товщина дорівнює 0, лінія не малюється.
T : ID стилю лінії (8 біт) (0〜255)
Ідентифікатор стилю або візерунка контуру.
<Візерунок контуру та заповнення (l_pat, f_pat)>

Параметр l_pat визначає ID візерунка для контурної лінії, а f_pat — ID візерунка заповнення внутрішньої області фігури. Якщо товщина лінії дорівнює 0, контур не виводиться. 

    0       : 
    0: «» ID
<Візерунок лінії / контуру (l_pat)>

Параметр l_pat визначає ідентифікатор (ID) візерунка контурної лінії. Значення 0 відповідає суцільній лінії за замовчуванням.

<Візерунок заповнення (f_pat)>

Параметр f_pat визначає ідентифікатор (ID) візерунка заповнення внутрішньої області фігури. Значення 0 відповідає суцільному заповненню за замовчуванням.

<Описовий прямокутник та кут обертання>

Для фігур (прямокутник, еліпс, сектор тощо) задається описовий прямокутник (RECT frame) та кут обертання (angle). Якщо кут angle ≠ 0, фігура повертається навколо центра прямокутника frame проти годинникової стрілки (повне коло виражається значенням 360 градусів або 65536).

Мал. 52 : Матриця трансформації координат

Координати точок (x, y) трансформуються у нові координати (x''', y''') за наступними кроками:

  1. Скос / нахил: 
            x' ＝ x ＋ y * tan(vangle)
        y' ＝ y
  2. Обертання: 
            x'' ＝ x' * cos(hangle) ＋ y' * sin(hangle)
        y'' ＝ −x' * sin(hangle) ＋ y' * cos(hangle)
  3. Зсув: 
            x''' ＝ x'' ＋ dh
        y''' ＝ y'' ＋ dv
