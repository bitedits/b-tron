Clarity

DTP組版出版環境
QuarkXPress 4.0 Class Publishing & Layout Engine (TAD Source Linking)
← Back to B-System Applications
"QuarkXPress 4.0 class professional publishing — multi-column layout frames, master pages, and live TAD source linking for modern publishers."

Overview

Professional desktop publishing (DTP) and high-precision page layout engine engineered to compete directly with QuarkXPress 4.0. Implemented in pure C99 over the TAD browser and layout core (src/apps/tad_browser.c) and Display Primitives (src/graphics/dp_core.c), Clarity provides publishers, book designers, and editorial teams with geometric multi-column text frames, arbitrary polygon runaround, master pages, and baseline grids. What sets Clarity apart is its native TAD source linking: rather than copying static text, publication frames link directly to living TAD Real Bodies (実身) and Virtual Bodies (仮身). When authors edit chapters in T-Editor or diagrams in Paint, the publication layout in Clarity updates live in real time.

クラリティ： QuarkXPress 4.0の精密組版機能を凌駕する、出版社・エディトリアルデザイナー向けプロフェッショナルDTP組版レイアウト環境。実体コードはTADブラウザー＆レイアウト基盤（src/apps/tad_browser.c）およびDisplay Primitives（src/graphics/dp_core.c）で構成。複数段組テキストボックス、任意ポリゴン回り込み、マスターページ、ベースライングリッド、トラッキング/カーニング精密制御を完備。最大の特長は「TADソース・リンク能力」であり、静的テキストの流し込みではなくTAD実身（Real Body）や仮身（Virtual Body）をフレームに直結。著者や編集者がT-Editorで原稿を更新したりPaintで図版を修正すると、Clarity上の出版組版紙面へリアルタイムに自動反映されます。

Key Features & Implementation

  • 実体コード実装：src/apps/tad_browser.c（DTPレイアウトエンジン、フレーム連結、段組処理）
  • 描画サブシステム：src/graphics/dp_core.c（ベクター枠、ポリゴン回り込み、トンボ/裁ち落とし描画）
  • QuarkXPress 4.0準拠の本格DTP組版（複数段組テキストフレーム、連結ストーリーフロー）
  • 任意形状ポリゴン画像枠および図形回り込み（Runaround / Text Wrap）
  • マスターページ（見開き左右ページ、親ページ継承、ヘッダー/ノンブル連動）
  • TADソース動的リンク：T-Editor原稿実身やPaintベクター図形をフレームに直結し、更新を即時紙面に反映
  • ミリポイント単位の高精度タイポグラフィ（文字詰め、行送り、カーニング、ベースライングリッド）
  • CMYK分版プレビュー、特色（Spot Color）、トンボ・ブリード裁ち落とし対応のPostScript/PDF出力

Why the Market Needs It

  • Traditional DTP software (QuarkXPress, InDesign) treats text and images as detached static imports; every editorial revision requires tedious manual re-importing and layout reflow.
  • Clarity's live TAD source linking connects editorial writing directly with prepress layout: authors write in T-Editor, illustrators draw in Paint, and the publication layout updates continuously.
  • Eliminates massive proprietary subscription bloat with a lightning-fast, crash-proof C99 publishing engine tailored for professional books, magazines, journals, and newspapers.

Typical Workflow

  1. Define master pages, column grids, margins, and folio numbering in Clarity.
  2. Create linked text frames across pages to establish the main story flow.
  3. Link external TAD Real Bodies (chapters written in T-Editor) directly into text frames via the TAD API.
  4. Drop vector illustrations or charts from Paint/Matrix — text automatically wraps around polygon borders.
  5. When the editorial team revises text in T-Editor, Clarity automatically updates the publication layout in real time.
  6. Export camera-ready CMYK PostScript or PDF with bleed marks for high-end press production.
