Mail

システム電子メール
Native System Email, IMAP/SMTP Client & Mailbox Manager (System Plane)
← Back to B-System Applications
"Clean, distraction-free system email — robust IMAP/SMTP client, mailbox organization, and unified system notifications."

Overview

Official system-level email client for B-System, categorized under the core System Applications plane. Implemented in src/apps/mail.c with network protocol backend in src/apps/mail_client.c, Mail provides reliable, high-throughput email communication supporting standard IMAP4, SMTP, and local Maildir formats. Built for professionals who value speed and clarity, Mail delivers multi-account inboxes, threaded message conversations, background mail synchronization, and system Deskbar notifications without bloated web wrappers.

メール： B-Systemの基本システム層（System Plane）に位置づけられた公式電子メールクライアント。実体コードはメールUI・フォルダ管理基盤（src/apps/mail.c）およびIMAP/SMTP通信エンジン（src/apps/mail_client.c）で構成。標準的なIMAP4、SMTP、およびローカルMaildir形式に完全対応。マルチアカウント受信箱、スレッド表示、バックグラウンド定期受信、およびDeskbar連動通知を軽快なネイティブC99設計で提供。日常のビジネス連絡やシステム通知を確実に処理します。

Key Features & Implementation

  • 実体コード実装：src/apps/mail.c（システムメールUI・受信箱スレッド管理）
  • ネットワークエンジン：src/apps/mail_client.c（IMAP4、SMTP、TLS暗号化通信）
  • 基本システムアプリ（System Application）としての確実なバックグラウンド動作
  • マルチアカウント対応（複数プロバイダの受信箱・送信箱一元管理）
  • スレッド別メッセージ一覧および高速プレビューペイン表示
  • Deskbarタスクトレイへの新着メール即時通知と未読バッジ表示
  • 添付ファイルの安全な受信とCabinetへのワンクリック保存

Why the Market Needs It

  • Modern email apps (Electron-based web wrappers) consume hundreds of megabytes of RAM just to show plain text messages.
  • Users need a fast, deterministic C99 system email client that starts instantly and handles high-volume mailboxes with zero lag.
  • Mail provides clean separation between formal asynchronous email (System plane) and real-time interactive TAD messaging (Chat).

Typical Workflow

  1. Launch Mail or receive an automatic Deskbar notification of incoming messages.
  2. Browse threaded conversations with full search across headers and message bodies.
  3. Compose new messages with standard formatting and attach documents directly from Cabinet.
  4. Send via SMTP; copies are automatically synchronized to your IMAP Sent folder.
