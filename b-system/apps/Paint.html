Paint

作図・スケッチ
Fast Bitmap & Vector Sketching Tool
← Back to B-System Applications
"Sketch once, embed everywhere — native TAD vector output that is resolution-independent in any document"

Overview

Fast bitmap and vector sketching tool powered directly by the BTRON Display Primitives graphics engine in src/graphics/dp_core.c and src/graphics/dp_sdl.c. Output is native TAD graphics segments or PNG/GIF, ready for immediate embedding and annotation in T-Editor or MediaPulse.

ペイント： BTRON Display Primitives描画コア（src/graphics/dp_core.c, src/graphics/dp_sdl.c）に直結した軽快なビットマップおよびベクター図形スケッチツール。出力はネイティブなTADグラフィックスセグメント、または汎用PNG/GIFに対応。描いた瞬間にT-EditorやMediaPulseへ埋め込み可能。

Key Features & Implementation

  • 実体コード実装：src/graphics/dp_core.c ＆ src/graphics/dp_sdl.c（ベクター/ラスタ描画コア）
  • TRON Display Primitives（DP）直結のベクター/ラスター作図
  • ネイティブTAD図形セグメント出力で解像度無依存
  • 直感的なパレット操作とクイック注釈機能
  • Layer-based composition with per-layer Virtual Body export
  • One-click embed into T-Editor at the current cursor position
  • Annotation overlay mode: draw on top of any open TAD document as a transparent layer

Typical Workflow

  1. Open Paint; sketch a diagram using vector tools.
  2. Press Embed → T-Editor — the graphic appears at the cursor as a native TAD graphics segment.
  3. Scale the embedded diagram freely; being vector it remains crisp at any size.
  4. Alternatively export as PNG/GIF for use in Browser or Living Book illustrations.
