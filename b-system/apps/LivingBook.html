Living Book

科学PDFリーダー
High-Performance Scientific PDF Reader & TAD Annotation Lab (For Scientists)
← Back to B-System Applications
"Distraction-free scientific paper reading — instant PDF rendering with live TAD Real Body margin notes, formula linking, and reproducible citations."

Overview

High-performance scientific PDF reader and interactive annotation laboratory engineered specifically for scientists, researchers, and academic laboratories. Powered by the document viewing core in src/apps/tad_browser.c and validated by src/apps/test_tad_browser.c, Living Book renders dense multi-column academic preprints (arXiv, PubMed, IEEE, Nature, Springer) with crisp vector typography and high-speed page flipping. Instead of locking margin notes into proprietary PDF annotation layers, Living Book converts highlights, hypotheses, formula clippings, and voice notes into permanent, first-class TAD Real Bodies (実身) and citation Virtual Bodies (仮身付箋) via the TAD API. Figures and citations link directly to laboratory datasets in Matrix or experimental code, enabling true reproducible research.

リビングブック： 科学者・学術研究者・研究開発チームのために特化設計された、超高速科学PDFリーダー＆TAD注釈ラボ。実体コードはドキュメント表示基盤（src/apps/tad_browser.c）およびテスト検証スイート（src/apps/test_tad_browser.c）で構成。arXiv、PubMed、IEEE、Nature等の2段組論文プレプリントをベクター品質で瞬時にレンダリング。従来のPDF閲覧ソフトのように注釈を孤立させず、マージンノート、数式スニペット、仮説メモ、音声記録をすべてBTRONネイティブなTAD実身（Real Body）および引用仮身（Virtual Body）として恒久保存。論文中のグラフや表をMatrixの実測データやコード実身に直接リンクさせ、真の再現可能研究（Reproducible Research）を実現します。

Key Features & Implementation

  • 実体コード実装：src/apps/tad_browser.c（PDF/TADドキュメントビューア、ページキャッシュ）
  • テスト検証基盤：src/apps/test_tad_browser.c（描画整合性・注釈リンクテストスイート）
  • 科学論文専用の高速PDFリーダー（TeX/LaTeXフォント、数式、多段組論文を高速展開）
  • TAD API直結のマージン注釈：ハイライトやメモを独立したTAD実身（Real Body）として自動生成
  • 数式・図版スニッピング：PDF内の数式やグラフを切り取り、T-EditorやMatrixへ即座に仮身として埋め込み
  • 再現可能研究リンク：論文中の数値や図をMatrix実験データセットやPython/C99解析コードに双方向リンク
  • 音声ラボノート：研究室での実験中、音声メモをPDFの段落や図版に直接ピン留め保存
  • BibTeX / DOI自動解決とTAD仮身（Virtual Body Fusen）による文献引用ネットワークの自動形成

Why the Market Needs It

  • Scientists read hundreds of PDF papers, but their notes and thoughts remain trapped in fragile PDF annotation layers or fragmented reference managers (Mendeley, Zotero).
  • Figures and claims in static scientific PDFs cannot be interactively cross-checked against original datasets or code repositories.
  • Living Book unites PDF reading with the BTRON TAD hypermedia plane: an annotated scientific paper becomes an active node in the researcher's knowledge cabinet.

Typical Workflow

  1. Open an arXiv or IEEE PDF preprint in Living Book; dual-column pages render instantly with crisp vector equations.
  2. Select a paragraph and type a hypothesis → Living Book creates an annotation Real Body pinned to that text block.
  3. Snip an equation or plot from the PDF → drag it directly into a T-Editor manuscript or Matrix analysis sheet.
  4. Link the paper's dataset to a Matrix spreadsheet so recalculations verify the authors' published findings.
  5. Organize reading libraries in the TAD Cabinet with automatic citation tracking.
