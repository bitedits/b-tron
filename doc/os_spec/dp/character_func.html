縦書き 場合 , こ 関数 単 文字幅 戻すこ та なり, pos すべて同一 値 設定されるこ та なる.

こ 関数 より文字描画位置, 言語指定 変化しない.

Get String Rectangle
文字列描画領域 取り出し
