T-Editor

汎用ワードプロセッサ
General Word Processor with Native TAD Hypermedia Abilities
← Back to B-System Applications
"The universal Word replacement for daily documents — intuitive formatting, styles, and margins with the unmatched power of native TAD Real Bodies and Fusen links."

Overview

Universal rich-text word processor designed as a clean, responsive replacement for Microsoft Word and LibreOffice Writer, enriched with the full power of the BTRON TAD hypermedia architecture. Implemented in src/apps/t_editor.c and validated by src/apps/test_editor_ui.c, T-Editor gives everyday authors, business professionals, and students familiar word processing tools: paragraph styles (Heading 1–4, Body, Blockquote), visual rulers, margins, headers and footers, bulleted/numbered lists, footnotes, and page numbering. Unlike traditional word processors that treat documents as static monolithic text files, T-Editor operates directly on BTRON3 binary TAD segments: any image, audio clip, or sub-document can be embedded as a live Real Body (実身) directly inside the text flow, and non-linear ideas link seamlessly through Virtual Body fusen links (仮身付箋).

Tエディタ： Microsoft WordやLibreOffice Writerを置き換える、直感的で軽快な日常業務・執筆用ワードプロセッサ。BTRON TADハイパーメディア能力を標準装備。実体コードは src/apps/t_editor.c（文書エディタUI・セグメント操作）および src/apps/test_editor_ui.c（描画検証テスト）で構成。見出しスタイル（Heading 1〜4）、ルーラー、余白設定、ヘッダー/フッター、箇条書き、脚注、ページ番号など、一般的なワープロの標準機能を網羅。さらにTAD独自の強力なハイパーメディア性能により、テキスト行内に画像・音声・表計算（Matrix）を「実身（Real Body）」として埋め込み、関連文書や参考資料を「仮身付箋（Virtual Body Fusen）」として自在にリンク。DOCXやPDFへの入出力にも対応した新世代の汎用文書作成環境です。

Key Features & Implementation

  • 実体コード実装：src/apps/t_editor.c（TAD文書エディタ open_t_editor_window、セグメント操作）
  • テスト検証基盤：src/apps/test_editor_ui.c（UIレンダリング・セグメント編集検証）
  • Microsoft Word完全置換：段落スタイル（見出し・本文・引用）、インデント、行間、マージンルーラー
  • ヘッダー、フッター、ページ番号、脚注（Footnotes）、目次（TOC）の自動生成
  • Mozc TIP連携による快適な漢字変換・多言語TRONコード文字入力（和文・欧文・記号）
  • 実身インライン埋め込み：画像、Paint図版、音声、Matrix表計算を文書フロー内に直接埋め込み
  • 仮身付箋（Virtual Body Fusen）：文書内に別文書や参考資料へのリンクを付箋として配置
  • DOCX、RTF、PDF、プレーンテキスト、およびBTRON3規格準拠バイナリTADへの双方向保存・エクスポート

Typical Workflow

  1. Create a new document in T-Editor; set margins, orientation, and heading styles using the ruler and ribbon.
  2. Type reports or correspondence using Mozc TIP for fast Japanese kanji and TRON Code multilingual text.
  3. Drag a financial table from Matrix or a vector sketch from Paint directly into the document flow as a live Real Body.
  4. Insert Virtual Body fusen links to attach reference manuals or cabinet records without bloating file size.
  5. Save natively as a BTRON3 TAD binary record, or export as clean PDF or DOCX for outside distribution.
