Mail & Chat

統合通信
Unified XMPP Mail & Real-Time Chat
← Back to B-System Applications
"Every message and thread is a first-class Virtual Body — drop conversations straight into your TAD documents"

Overview

Unified XMPP-based mail and real-time chat. Conversations and messages are first-class Virtual Bodies that can be dropped into research memos, TAD reports, or the Workbench canvas.

メール＆チャット： XMPPプロトコルを基盤とするメールとリアルタイム対話の統合環境。個々のメッセージや会話スレッド全体が第一級の仮想オブジェクトとして扱われ、そのまま研究メモやTAD報告書にドロップ可能。

Key Features

  • 標準XMPP / Erlang Pub-Sub基盤による堅牢な暗号化通信（OMEMO）
  • 対話メッセージの実身・仮身化とTAD文書貼付
  • 連絡先ごとのリアルタイムプレゼンス＆ステータス表示
  • Attachment Real Bodies auto-linked to the originating thread
  • Conversation threads searchable from Clarity's global instant-search
  • Quote any message as a Virtual Body directly inside a T-Editor document

Typical Workflow

  1. Send or receive a message in Mail & Chat.
  2. Select any message or thread → drag it onto the Workbench canvas — it becomes a Virtual Body.
  3. Drop the Virtual Body into a T-Editor memo or Living Book annotation to cite the conversation inline.
  4. Search for any message content instantly from Clarity's global search bar.
