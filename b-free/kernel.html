Мікроядро µITRON 3.0 та його реалізація

Найнижчим рівнем B-Free OS є мікроядро, побудоване відповідно до промислового японського стандарту вбудованих систем µITRON 3.0. Ядро розташоване в директорії b-free/Program/btron-pc/kernel/ITRON/ та адаптовано для процесорів архітектури x86 (i386).

1. Основні функції мікроядра

Ядро µITRON відповідає за виконання низькорівневих системних операцій у реальному часі, керування пам'яттю та перемикання завдань (tasks). Воно не містить графічної оболонки або файлових систем; ці елементи реалізуються як користувацькі процеси (сервери) на вищих рівнях.

Диспетчеризація завдань (Task Management)

Кожне завдання в системі представляє собою окремий потік виконання з власним контекстом та стеком. Ядро підтримує витісняючу багатозадачність на основі пріоритетів. Основні системні виклики керування завданнями:

  • cre_tsk (Create Task) — Створення нового завдання.
  • sta_tsk (Start Task) — Запуск виконання створеного завдання.
  • ext_tsk (Exit Task) — Завершення поточного завдання.
  • slp_tsk (Sleep Task) — Переведення завдання у стан сну.
  • wup_tsk (Wakeup Task) — Пробудження завдання зі стану сну.

Синхронізація та зв'язок (IPC)

Для обміну даними та синхронізації завдань реалізовано механізми семафорів, поштових скриньок та прапорців подій:

  • Семафори (Semaphores): виклики cre_sem, sig_sem, wai_sem для захисту критичних секцій.
  • Прапорці подій (Event Flags): виклики cre_flg, set_flg, wai_flg для синхронізації за подіями.
  • Поштові скриньки (Mailboxes): виклики cre_mbx, snd_msg, rcv_msg для передачі повідомлень між завданнями.

2. Апаратна адаптація та перемикання контексту

Апаратно-залежний код для архітектури i386 міститься в директорії ITRON/i386/.

Ядро ініціалізує таблицю глобальних дескрипторів (GDT), таблицю дескрипторів переривань (IDT) таTask State Segment (TSS). При виникненні апаратних переривань або системних викликів процесор переходить у захищений режим ядра, де виконується збереження регістрів поточного завдання у його стек і завантаження контексту іншого завдання, призначеного планувальником ядра.

Низькорівневий асемблерний код перемикання контексту реалізовано у файлі entry.S або аналогічних апаратно-залежних модулях для IBM PC та архітектури PC9801.
