3.5 Елементи інтерфейсу та віджети (GUI Control Parts)

3.5.1 Огляд підсистеми відображення віджетів

Підсистема віджетів (GUI Control Parts) надає набір стандартних елементів управління інтерфейсу користувача: полоси прокрутки (Scrollbars), кнопочні елементи (Pushbuttons), прапорці (Checkboxes), радіокнопки (Radio Buttons), поля текстового введення та списки.

gcre_prt
Create GUI Part
Створення елемента інтерфейсу / віджета

【Синтаксис / Прототип】

PARTID  gcre_prt(WID wid, RECT *rect, UH type, VP par)

【Параметри】

WID     wid     Ідентифікатор вікна власника
RECT   *rect    Координати та розмір віджета
UH      type    Тип елемента інтерфейсу (Button, Scrollbar, Checkbox)
VP      par     Специфічні параметри віджета

【Значення, що повертається】

> 0      Успішне виконання (Дескриптор віджета PARTID)
< 0      Помилка (Код помилки)

【Детальний опис】

Створює новий елемент інтерфейсу type у вікні wid за координатами rect.

【Коди помилок】

EW_ADR     : Неприпустима адреса вказівника rect або par.
EW_WID     : Недійсний ідентифікатор вікна wid.
