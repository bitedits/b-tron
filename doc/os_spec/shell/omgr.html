3.4 Менеджер Реальних та Віртуальних об'єктів (Real/Virtual Object Manager)

3.4.1 Огляд Реально-Віртуальної об'єктної моделі

3.4.1.1 Призначення та архітектура Менеджера об'єктів

Менеджер Реальних та Віртуальних об'єктів (Real/Virtual Object Manager) реалізує фундаментальну концепцію операційного середовища BTRON — **Реально-Віртуальну об'єктну модель (Real/Virtual Object Model)**.

У цій моделі інформаційні ресурси розглядаються як мережа пов'язаних об'єктів без традиційних файлових каталожних структур:

  • Реальний об'єкт (Real Object / Jisshin): Контейнер збереження даних (файловий об'єкт на носії).
  • Віртуальний об meбель / Посилання (Virtual Object / Koshin): Візуальне графічне представлення посилання на Реальний об'єкт у вікні або документах.
  • Опосередковане посилання (Indirect Link / Koshin Link): Посилання на об'єкт, розташований на іншому томі чи носії.
  • Відключений об'єкт / Кьошін (Disconnected Object / Kyoshin): Віртуальний об'єкт, цільовий носій якого в даний момент відключений від системи (Unmounted).

3.4.1.2 Графічні стани та відображення Віртуальних об'єктів

Віртуальний об'єкт відображається у двох основних формах:

1. Закритий Віртуальний об'єкт (Closed VObject) :

Відображається у вигляді прямокутної плашки з піктограмою, назвою об'єкта, типом та часовою міткою останньої модифікації.

2. Відкритий Віртуальний об'єкт (Open VObject) :

Розгортається у вікно прикладного додатка, який зчитує та редагує вміст Реального об'єкта.
Мал. 114: Архітектура Реальних, Віртуальних та Відключених об'єктів (Кьошін)

3.4.2 Системні виклики Менеджера об'єктів

opn_obj
Open Real Object
Відкриття Реального об'єкта у новому вікні

【Синтаксис / Прототип】

WID     opn_obj(LINK *lnk, W mode, TC *pwd)

【Параметри】

LINK   *lnk     Посилання на Реальний об'єкт
W       mode    Режим відкриття (F_READ, F_WRITE, F_UPDATE)
TC     *pwd     Пароль доступу (NULL — без пароля)

【Значення, що повертається】

> 0      Успішне виконання (Дескриптор вікна відкритого об'єкта WID)
< 0      Помилка (Код помилки)

【Детальний опис】

Запускає відповідний прикладний додаток та відкриває Реальний об'єкт lnk у новому документальному вікні WID.

【Коди помилок】

ER_ACCES   : Відсутні права доступу до Реального об'єкта.
ER_ADR     : Неприпустима адреса вказівника lnk або pwd.
ER_NOEXS   : Цільовий Реальний об'єкт відсутній.
ER_NOFS    : Носій об'єкта відключений від системи.
cre_lnk
Create Virtual Object Link
Створення Віртуального об'єкта (Посилання)

【Синтаксис / Прототип】

ERR     cre_lnk(LINK *org, LINK *ref, TC *name)

【Параметри】

LINK   *org     Батьківський файл, куди додається посилання
LINK   *ref     Буфер для збереження нового посилання (Вихід)
TC     *name    Назва Віртуального об'єкта (до 20 символів TRON Code)

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Створює новий запис Віртуального об'єкта ref у батьківському об'єкті org з вказаним ім'ям name.

【Коди помилок】

ER_ACCES   : Відсутні права запису у батьківський об'єкт org.
ER_ADR     : Неприпустима адреса вказівника org або ref.
