2.4 Функції малювання геометричних фігур (Geometric Drawing Functions)

Функції малювання геометричних фігур, що приймають у якості аргументів візерунок заповнення PAT *pat та режим малювання DCM mode, підтримують розширені режими растрового перетворення G_CVFORM та G_CVCOLOR.

G_CVFORM — Перетворення растрового формату (BitMap Format Conversion) :
  • Якщо формат растрового візерунка (kind = 1, mpat) відрізняється від формату цільового графічного порту за кількістю площин чи глибиною кольору, виконується автоматична адаптація.
  • Якщо даний прапор не встановлено, при відмінності форматів джерела і призначення повертається помилка EG_PAR.
  • Перетворення виконується шляхом збереження значень $N$ молодших бітів пікселів (де $N$ — мінімальна глибина кольору depth).
G_CVCOLOR — Абсолютне колірне перетворення (Color Space Mapping) :
  • Виконується перетворення кольорів у випадку, коли колірний простір растрового масиву (mpat) відрізняється від колірного простору цільового пристрою.
  • Кольори джерела конвертуються у сумісну колірну модель за допомогою найближчого абсолютного колірного збігу.

2.4.1 Малювання ліній та точок (Line & Point Drawing)

Малювання ліній здійснюється шляхом проведення відрізка між двома заданими точками з урахуванням товщини пера (LATTR), стилю лінії, растрового шаблону PAT та режиму DCM mode.

При товщині лінії понад 1 піксель квадратний растровий штамп пера переміщується вздовж траєкторії відрізка. Для малювання точок надаються виклики зчитування колірного значення пікселя (gtst_pnt) та встановлення пікселя (gset_pnt).

gdra_lin
Draw Line
Малювання відрізка прямої лінії

【Синтаксис / Прототип】

ERR     gdra_lin(GID gid, PNT p1, PNT p2, LATTR attr, PAT *pat, DCM mode)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
PNT     p1      Початкова точка відрізка (X1, Y1)
PNT     p2      Кінцева точка відрізка (X2, Y2)
LATTR   attr    Атрибути лінії (товщина пера, стиль штриховки)
PAT    *pat     Візерунок заповнення або маска лінії
DCM     mode    Режим змішування растрових пікселів

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Малює пряму лінію між точками p1 та p2 у графічному контексті gid з урахуванням атрибутів attr, растрового патерну pat та режиму накладення mode.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника pat.
EG_GID     : Недійсний ідентифікатор графічного контексту gid.
EG_PAR     : Некоректні значення параметрів attr або mode.
gdra_rec
Draw Rectangle
Малювання прямокутника

【Синтаксис / Прототип】

ERR     gdra_rec(GID gid, RECT *rect, PAT *pat, DCM mode)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
RECT   *rect    Прямокутні межі фігури (left, top, right, bottom)
PAT    *pat     Візерунок заповнення
DCM     mode    Режим змішування пікселів

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Малює заповнений прямокутник rect у графічному контексті gid за допомогою візерунка pat та режиму mode.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника rect або pat.
EG_GID     : Недійсний ідентифікатор контексту gid.
EG_PAR     : Некоректні прямокутні координати rect.
gdra_ell
Draw Ellipse
Малювання еліпса / кола

【Синтаксис / Прототип】

ERR     gdra_ell(GID gid, RECT *rect, PAT *pat, DCM mode)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
RECT   *rect    Прямокутні межі еліпса
PAT    *pat     Візерунок заповнення
DCM     mode    Режим растрового змішування

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Малює заповнений еліпс у прямокутних межах rect. Якщо rect прямокутника є квадратом, малюється коло.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника rect або pat.
EG_GID     : Недійсний графічний контекст gid.
gbit_blt
BitBlt Copy
Растрове бітове копіювання BitBlt

【Синтаксис / Прототип】

ERR     gbit_blt(GID dgid, PNT dpnt, GID sgid, RECT *srect, DCM mode)

【Параметри】

GID     dgid    Цільовий графічний контекст
PNT     dpnt    Початкова точка цільової області (X, Y)
GID     sgid    Джерельний графічний контекст
RECT   *srect   Прямокутна область джерела
DCM     mode    Операція побітового суміщення ROP

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Виконує швидке апаратне або програмне копіювання прямокутного растрового масиву пікселів із контексту sgid у контекст dgid.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника srect.
EG_GID     : Недійсний ідентифікатор контексту sgid або dgid.
