Notebook

科学計算ノートブック
Interactive Mathematica & Jupyter-Style Scientific Notebook (TAD + Language VMs)

"The interactive computational laboratory for scientists — live executable cells, Matrix TAD data sources, and multi-language VMs (APL, Scheme, Python/Wasm, Micro-VMs)."

Overview

Interactive scientific notebook environment engineered for researchers, physicists, data scientists, and quantitative analysts, inspired by Mathematica and Jupyter. Implemented in src/apps/notebook.c and powered by the multi-language execution dispatcher src/apps/notebook_vm.c, Notebook structures scientific exploration into live, reactive computational cells. Unlike conventional browser-based notebooks that suffer from heavy Python runtimes and fragile state, Notebook runs natively on BTRON3, directly connecting to Matrix TAD sources and executing code across multiple embedded language VMs: Iverson APL vector math, Scheme/Lisp symbolic computing, Python/Wasm, and embedded C micro-VMs.

Notebook also seamlessly consumes peer-reviewed annotations and formula callouts generated by Review (src/apps/pdf_tad_anno.c), allowing scientists to verify published formulas against live datasets in one click.

ノートブック： MathematicaやJupyter Notebookの先進的計算環境をBTRON3ネイティブ環境で再構築した、科学者・研究者向け双方向計算ノートブック。実体コードはノートブック基盤（src/apps/notebook.c）およびマルチ言語VMディスパッチャー（src/apps/notebook_vm.c）で構成。セル単位の対話型コード実行、リアクティブ自動再計算、インライン作図を提供。

最大の強みは「Matrix TADソース直結」と「多言語VM実行能力」です。Matrixで集計した生データ（NYSE/Nasdaq金融時系列、実験計測値）を直接セルの入力として接続し、APL（ベクトル配列演算）、Scheme/Lisp（記号処理・数式処理）、Python/Wasm、CマイクロVMから自在に呼び出して解析。さらにReviewで論文から抽出した査読注釈・数式実身（pdf_tad_anno.c）をセル内へ引用し、再現性のある科学検証実験を即座に構築できます。

Key Features & Implementation

  • 実体コード実装：src/apps/notebook.c（双方向セル管理・TADリアクティブ計算エンジン）
  • 言語VMディスパッチャー：src/apps/notebook_vm.c（APL、Scheme/Lisp、Python/Wasm、C Micro-VM）
  • Matrix TADデータソース直結：スプレッドシートの数理モデルや時系列データをリアルタイムに入力
  • Review注釈エンジン（pdf_tad_anno.c）からの論文引用・数式呼び出しの直接実行
  • セル単位の逐次・一括実行および依存関係グラフに基づく自動リアクティブ更新
  • インライン・ベクトルチャート描画（2D/3Dサーフェス、散布図、ヒストグラム）
  • 完全な再現性（Reproducible Research）：実行環境VMとTADバイナリデータの一体保存
  • Clarityへの計算結果・図表のリアルタイム出版エクスポート

Why the Market Needs It

  • Traditional Jupyter notebooks depend on fragile web browsers and massive external conda environments that break over time.
  • Mathematica is a heavy proprietary monolith with zero integration into operating system hypermedia databases.
  • B-System Notebook provides instant, crash-proof native execution with permanent TAD Real Body reproducibility and direct OS-level array acceleration.

Typical Workflow

  1. Open Notebook and create a new scientific project notebook.
  2. Link a raw experiment dataset or financial tick stream from Matrix via matrix_source_robj.
  3. Write an APL cell for high-dimensional matrix reduction and a Scheme cell for symbolic simplification.
  4. Import an equation citation from a recent paper via Review (pdf_tad_anno.c) to benchmark theoretical formulas against live data.
  5. Execute cells interactively; visual graphs render instantly as vector TAD segments.
  6. Export the final verified computational report into Clarity for peer-reviewed journal publication.
