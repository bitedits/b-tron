Cassette

リアルタイム音響
SONY TC-K777ES Precision Stereo Cassette Deck & Media Environment
← Back to B-System Applications
"SONY Precision Audio Engineering — 3-Head Dual Capstan, Dolby B-C NR, Type I-IV Selector & Real-Time BTRON Audio Stream"

Overview

Precision Hi-Fi stereo cassette deck and media playback environment implemented in src/apps/audio_player.c (open_audio_player_window). Designed in authentic SONY workstation industrial aesthetics (deep titanium slate, brushed graphite, gold/cyan indicators), featuring mechanical rotating tape spools with real-time tape transfer physics, digital tape counter, 4-way cassette type selector (Type I Normal, Type II CrO2, Type III FeCr, Type IV Metal), Dolby B-C NR & HX Pro headroom extension, and 16-segment dual-channel L/R digital peak VU meters.

カセット（Cassette Deck）： SONY TC-K777ESの設計思想を継承したBTRONネイティブの高精度ステレオカセットデッキ・音響プレイヤー（src/apps/audio_player.c）。チタンスレートとグラファイトのSONYワークステーション意匠、磁気テープ巻取りアニメーション、デジタルカウンター、4種カセットテープセレクター（Type I ノーマル、Type II ハイポジション/CrO2、Type III フェリクローム、Type IV メタル）、ドルビーB-C NR / HX Proヘッドルーム拡張、および16セグメント高精度デジタルピークVUメーターを完全装備。

Key Features & Implementation

  • 実体コード実装：src/apps/audio_player.c（カセットデッキ・オーディオプレイヤー open_audio_player_window）
  • SONY Precision Industrial Palette（チタンスレート、ブラッシュドグラファイト、ゴールド・シアン・グリーンLED）
  • 4種カセットテープ対応セレクター：TYPE I (NORM), TYPE II (CrO2), TYPE III (FeCr), TYPE IV (METAL)
  • Dolby B-C NR（ノイズリダクション）＆ HX Proヘッドルーム拡張、MPXフィルター連動
  • 16セグメント L/R デジタルピークホールドVUメーター（-30dB〜+8dB、グリーン→シアン→ゴールド→レッド遷移）
  • 磁気テープ巻取り物理シミュレーション（再生・早送り・巻戻しに伴うテープハブの動的回転とテープパック厚み変化）
  • タクタイル・トランスポートキー群（REW, REV PLAY, PLAY, FF, STOP, PAUSE, REC）
  • μITRON高精度タイマーに基づくジッターフリー低遅延ストリーミングパイプライン
  • TADハイパーメディア文書へのシームレスな音声・仮想オブジェクト（Virtual Body）直接埋め込み

Typical Workflow

  1. Launch Cassette from the BTRON Deskbar Tracker menu or Desktop audio icon.
  2. Select cassette tape formulation (Normal, CrO2, FeCr, or Metal) and configure Dolby B/C NR.
  3. Engage transport controls (Play, Fast Forward, Rewind) with real-time rotating tape hub telemetry.
  4. Monitor dual-channel stereo peak levels on the graduated 16-segment digital VU meters.
  5. Drag recorded audio Virtual Bodies into T-Editor or TAD documents for instant hypermedia linkage.
