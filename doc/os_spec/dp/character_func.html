2.5 Функції виведення тексту та шрифтів (Text & Font Functions)

2.5.1 Доступ до системних атрибутів символів у контексті

gset_chp
Set Character Position
Налаштування початкової позиції друку символу

【Синтаксис / Прототип】

ERR     gset_chp(GID gid, W x, W y, Bool abs)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
W       x       Горизонтальне зміщення чи координата X
W       y       Вертикальне зміщення чи координата Y
Bool    abs     Прапорець режиму: 0 — відносне зміщення, 1 — абсолютні координати

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Встановлює поточну позицію друку текстового пера в графічному контексті gid. Якщо abs = 0, координати додаються до поточного положення пера. Якщо abs != 0, встановлюються абсолютні координати (x, y).

【Коди помилок】

EG_GID     : Недійсний ідентифікатор контексту gid.
EG_PAR     : Переповнення координат при відносному позиціонуванні.
gget_chp
Get Character Position
Зчитання поточної позиції текстового пера

【Синтаксис / Прототип】

ERR     gget_chp(GID gid, W *x, W *y)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
W      *x       Буфер для збереження координати X (Вихід)
W      *y       Буфер для збереження координати Y (Вихід)

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Повертає поточні координати (x, y) текстового пера у графічному контексті gid.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника x або y.
EG_GID     : Недійсний графічний контекст gid.
gset_chc
Set Character Color
Налаштування кольорів символу та фону

【Синтаксис / Прототип】

ERR     gset_chc(GID gid, COLOR fgc, COLOR bgc)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
COLOR   fgc     Колір переднього плану (символу)
COLOR   bgc     Колір заднього плану (фону)

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Змінює передній колір символів fgc та колір фонного прямокутника bgc для текстового друку у контексті gid.

【Коди помилок】

EG_GID     : Недійсний графічний контекст gid.
gget_chc
Get Character Color
Зчитання кольорів символу та фону

【Синтаксис / Прототип】

ERR     gget_chc(GID gid, COLOR *fgc, COLOR *bgc)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
COLOR  *fgc     Буфер для збереження кольору символів (Вихід)
COLOR  *bgc     Буфер для збереження кольору фону (Вихід)

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Зчитує поточні налаштування кольорів тексту та фону з контексту gid.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника fgc або bgc.
EG_GID     : Недійсний графічний контекст gid.
gset_chd
Set Character Direction
Налаштування напрямку та інтервалів тексту

【Синтаксис / Прототип】

ERR     gset_chd(GID gid, W dir, CGAP *gap)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
W       dir     Напрямок друку (TORIGHT=0, TOLEFT=1, TODOWN=2, TOUP=3)
CGAP   *gap     Структура додаткових інтервалів між символами та рядками

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Встановлює напрямок друку dir (горизонтальний зліва направо, справа наліво, вертикальний зверху вниз чи знизу вгору) та додаткові міжсимвольні інтервали gap.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника gap.
EG_GID     : Недійсний графічний контекст gid.
EG_PAR     : Некоректний напрямок dir.
gdra_chr
Draw Character
Виведення одного символу TRON Code

【Синтаксис / Прототип】

ERR     gdra_chr(GID gid, TC ch, PAT *pat, DCM mode)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
TC      ch      Код символу в системному кодуванні TRON Code
PAT    *pat     Візерунок малювання (NULL — поточний колір fgc)
DCM     mode    Режим змішування пікселів

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Малює один символ ch у поточному положенні пера контексту gid та зміщує перо на ширину даного символу.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника pat.
EG_GID     : Недійсний графічний контекст gid.
gdra_str
Draw Text String
Виведення текстового рядка TRON Code

【Синтаксис / Прототип】

ERR     gdra_str(GID gid, TC *str, W len, PAT *pat, DCM mode)

【Параметри】

GID     gid     Ідентифікатор графічного контексту
TC     *str     Масив символів TRON Code
W       len     Кількість символів (або -1 для нуль-термінованого рядка)
PAT    *pat     Візерунок заповнення або колір тексту
DCM     mode    Режим змішування растрових пікселів

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Послідовно виводить текстовий рядок str у графічному контексті gid з автоматичним оновленням позиції пера.

【Коди помилок】

EG_ADR     : Неприпустима адреса вказівника str або pat.
EG_GID     : Недійсний ідентифікатор контексту gid.
