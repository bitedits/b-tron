Central System Settings & Hardware Control Panel

"Centralized system control and hardware tuning — pure C99 settings manager applying kernel, display, and network parameters live without rebooting."

Overview

Unified system settings and hardware configuration manager engineered in pure C99, backed by the kernel management and device subsystems (src/kernel/sys_mgmt.c, src/kernel/dev_mgr.c, src/drivers/virtio/virtio.c). Directly interacts with the BTRON system management interfaces (sys_mgmt.h), hardware device configurations (btron/device.h, btron/core.h), Mozc TIP input method settings (src/tip/tip_task.c), display resolution/scaling, VirtIO network parameters, and audio routing. All configuration changes apply live in kernel memory and persist to system records without requiring an OS restart.

環境設定パネル： BTRONシステム管理（src/kernel/sys_mgmt.c）、デバイス管理（src/kernel/dev_mgr.c）、VirtIOドライバー（src/drivers/virtio/virtio.c）、Mozc TIP設定（src/tip/tip_task.c）に直結した純粋C99製システム環境設定ツール。設定変更はカーネルメモリへ即時反映され、システム構成ファイルへ永続保存（OS再起動不要）。堅牢なシステムプレーン・コントロールパネル。

Key Features & Implementation

  • システム管理基盤：src/kernel/sys_mgmt.c ＆ src/kernel/dev_mgr.c（デバイス制御）
  • VirtIO設定管理：src/drivers/virtio/virtio.c（ネットワーク・GPU・ストレージ）
  • ワンクリックで主要カーネルパラメータおよびハードウェア設定へアクセス
  • 純粋C99システム設計（設定の即時適用・OS再起動不要）
  • ディスプレイ解像度・リフレッシュレート・色深度の動的切り替え
  • Mozc TIP日本語入力メソッドのキーバインドおよび辞書構成管理
  • VirtIOデバイス設定（ネットワークIP/DNS、VirtIO-Block、VirtIO-GPU）
  • システムオーディオ音量・サンプルレートおよび省電力プロファイル制御

Typical Workflow

  1. Open Preferences from Workbench, Deskbar, or via system hotkey.
  2. Select any category (Display, Input, Network, Sound, System) to adjust parameters.
  3. Sliders and toggles apply changes immediately to hardware and kernel drivers.
  4. Preferences persists current values into system configuration storage (sysinit.h, fs_record.h).
