1.8 Менеджер пристроїв та драйверів (Device Management)

1.8.1 Огляд підсистеми управління пристроями (Overview)

Підсистема управління пристроями забезпечує уніфікований системний інтерфейс для прикладних програм та системних модулів ядра, дозволяючи прозоро взаємодіяти з будь-якими периферійними пристроями через драйвери пристроїв (Device Drivers).

Файловий менеджер та Менеджер подій ядра внутрішньо використовують Менеджер пристроїв для виконання низькорівневих операцій читання/запису даних на фізичних носіях та контролерах.

Мал. 14: Ієрархія та позиціонування Менеджера пристроїв у BTRON3

Підтримувані класи периферійних пристроїв:

  1. Растрові дисплеї (CRT, LCD)
  2. Клавіатури (KB)
  3. Поінтинг-пристрої та миші (PD)
  4. Дискові накопичувачі (FD, HD, Flash, CD-ROM)
  5. Друкуючі пристрої (Принтери)
  6. Комунікаційні інтерфейси (RS-232C, модеми, мережеві адаптери)
  7. Звукові синтезатори та динаміки
  8. Сканери та пристрої обробки зображень

1.8.2 Архітектура пристроїв та логічні імена (Device Architecture)

Класифікація пристроїв

Пристрої поділяються на 2 основні типи:

1. Символьні пристрої (Character Devices) :

Послідовне введення/виведення потоку байтів (наприклад, RS-232C, принтери, клавіатура).

2. Блочні пристрої (Block Devices) :

Введення/виведення даних неперервними блоками фіксованого розміру (наприклад, жорсткі диски HD, дискети FD, флеш-пам'ять) із підтримкою довільного позиціонування (Seek).

Формат логічних імен пристроїв (Logical Device Names)

Кожен пристрій реєструється у системі за унікальним логічним ім'ям довжиною до 8 символів (16 байтів). Логічне ім'я будується за схемою: «Тип» + «Літера юніта» + «Номер сабюніта».

Тип (Device Type) :
Символьний код класу пристрою (наприклад, "hd" — жорсткий диск, "fd" — дискета, "prn" — принтер).
Юніт (Unit Letter) :
Латинська літера для ідентифікації конкретного пристрою одного типу (наприклад, "hda", "hdb").
Сабюніт / Розділ (Subunit Number) :
Номер розділу на фізичному носії (від 0 до 254, наприклад "hda0", "hda1").

1.8.3 Визначення типів даних та констант (Data Types & Constants)

□ Режими відкриття пристроїв opn_dev()

#define TD_READ     0x0001      /* Відкриття лише для читання */
#define TD_WRITE    0x0002      /* Відкриття лише для запису */
#define TD_UPDATE   0x0003      /* Відкриття для читання та запису */
#define TD_EXCL     0x0100      /* Монопольний режим відкриття */

1.8.4 Системні виклики підсистеми пристроїв (Device System Calls)

opn_dev
 
Відкриття пристрою (Open Device)

【Синтаксис / Прототип】

WERR    opn_dev(TC *devnm, W mode)

【Параметри】

TC  *devnm  Логічне ім'я пристрою (наприклад, "hda0", "fd0")
W    mode   Режим відкриття: TD_READ, TD_WRITE, TD_UPDATE | [TD_EXCL]

【Значення, що повертається】

> 0      Успішне виконання (Дескриптор відкритого пристрою dd)
< 0      Помилка (Код помилки)

【Детальний опис】

Відкриває вказаний логічний пристрій devnm у заданому режимі mode та повертає системний дескриптор пристрою dd.

【Коди помилок】

ER_ACCES   : Відсутні права доступу до пристрою.
ER_ADR     : Неприпустима адреса вказівника devnm.
ER_BUSY    : Пристрій заблокований у монопольному режимі іншим процесом.
ER_NOEXS   : Логічний пристрій devnm відсутній у системі.
ER_NOSPC   : Недостатньо пам'яті ядра.
ER_PAR     : Некоректний режим mode.
cls_dev
 
Закриття пристрою (Close Device)

【Синтаксис / Прототип】

ERR     cls_dev(W dd)

【Параметри】

W   dd  Дескриптор відкритого пристрою

【Значення, що повертається】

= 0      Успішне виконання
< 0      Помилка (Код помилки)

【Детальний опис】

Закриває відкритий дескриптор пристрою dd та вивільняє системні ресурси.

【Коди помилок】

ER_ID      : Недійсний або закритий дескриптор пристрою dd.
ER_IO      : Помилка введення/виведення пристрою.
rea_dev
 
Зчитання даних з пристрою (Read Device)

【Синтаксис / Прототип】

WERR    rea_dev(W dd, VP buf, W start, W size)

【Параметри】

W   dd      Дескриптор відкритого пристрою
VP  buf     Буфер для збереження зчитаних даних (Вихід)
W   start   Початковий номер блоку або зміщення (для блочних пристроїв)
W   size    Розмір зчитуваних даних у байтах/блоках

【Значення, що повертається】

>= 0     Успішне виконання (Кількість фактично зчитаних байтів/блоків)
< 0      Помилка (Код помилки)

【Детальний опис】

Зчитує size байтів або блоків із пристрою dd у буфер buf починаючи із позиції start.

【Коди помилок】

ER_ADR     : Неприпустима адреса буфера buf.
ER_ID      : Недійсний дескриптор пристрою dd.
ER_IO      : Апаратна помилка зчитання даного пристрою.
ER_PAR     : Некоректні параметри start або size.
wri_dev
 
Запис даних на пристрій (Write Device)

【Синтаксис / Прототип】

WERR    wri_dev(W dd, VP buf, W start, W size)

【Параметри】

W   dd      Дескриптор відкритого пристрою
VP  buf     Буфер із даними для запису
W   start   Початковий номер блоку або зміщення
W   size    Розмір даних для запису у байтах/блоках

【Значення, що повертається】

>= 0     Успішне виконання (Кількість фактично записаних байтів/блоків)
< 0      Помилка (Код помилки)

【Детальний опис】

Записує size байтів або блоків із буфера buf на пристрій dd починаючи з позиції start.

【Коди помилок】

ER_ADR     : Неприпустима адреса буфера buf.
ER_ID      : Недійсний дескриптор пристрою dd.
ER_IO      : Апаратна помилка запису на пристрій.
ER_RONLY   : Пристрій перебуває у режимі захисту від запису.
