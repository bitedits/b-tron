Cabinet Explorer

実身・仮身キャビネット
Real Body Cabinet & Virtual Body Explorer (TAD API)
← Back to B-System Applications
"The heart of BTRON hypermedia — explore, link, and organize Real Bodies and Virtual Bodies through the native TAD API."

Overview

Official hypermedia object navigator implemented in src/apps/vobj_manager.c and backed by the core BTRON object manager (src/vobject/vobj.c, src/vobject/omgr.c) and TAD API (tad_browser.h, vobj.h, omgr.h). Unlike traditional hierarchical file managers, Cabinet Explorer manages the network of Real Bodies (実身) and Virtual Bodies (仮身) that forms the foundation of BTRON hypermedia. Users can inspect object IDs, resolve fusen link pointers, organize nested cabinet containers, and seamlessly launch documents into T-Editor or TAD Browser.

キャビネット・エクスプローラー： BTRON TAD API（tad_browser.h、vobj.h、omgr.h）およびオブジェクト管理基盤（src/vobject/vobj.c, src/vobject/omgr.c）に直結した公式ハイパーメディア・オブジェクトマネージャ実装（src/apps/vobj_manager.c）。階層的ディレクトリスキームを超越した、BTRONの中核概念である「実身（Real Body）」と「仮身（Virtual Body）」のネットワーク構造を可視化・管理。実身ID（robj_id）の追跡、付箋（Fusen）リンクの解決、キャビネット構造の整理、およびT-EditorやTAD Browserへの即座展開を実現。

Key Features & Implementation

  • 実体コード実装：src/apps/vobj_manager.c（UI・グリッド/リスト表示・コンテナ管理）
  • 実身・仮身バックエンド：src/vobject/vobj.c ＆ src/vobject/omgr.c（TADオブジェクト層）
  • TAD API（vobj.h, omgr.h）直結による実身・仮身リレーションの双方向ブラウジング
  • グリッド表示（Grid View）および詳細リスト表示（List View）の瞬時切り替え（CAB_VIEW_MODE）
  • TADバイナリ形式で永続化された実身レコード（R-Object Record）の属性・サイズ・カテゴリ管理
  • 仮身（Virtual Body Fusen）のドラッグ＆ドロップによるリンク網形成と複数文書への同一実身埋め込み
  • ダブルクリックによるT-EditorおよびTAD Browserへのシームレスなハンドオフ（open_tad_browser_window）
  • NASA JPL仕様およびBTRON3 SPEC 3.20に完全準拠したクリーンルーム実装

Why the Market Needs It

  • Traditional filesystems force users into rigid single-parent directory trees where a file can only live in one folder without brittle symlinks.
  • BTRON's Real Body / Virtual Body model enables one document to appear simultaneously in multiple contexts without data duplication.
  • Cabinet Explorer provides the dedicated Knowledge-plane interface to navigate and maintain these hypermedia networks via the standard TAD API.

Replaces / Normalises

Ordinary hierarchical file trees True non-hierarchical hypermedia network of Real Bodies and Virtual Body pointers

Typical Workflow

  1. Launch Cabinet Explorer from the Workbench Deskbar or Knowledge menu.
  2. Browse available cabinets containing research papers, technical specs, and project records.
  3. Inspect Real Body IDs, sizes, and MIME categories in List or Grid view.
  4. Drag a Virtual Body fusen from Cabinet Explorer directly into an open T-Editor document.
  5. Double-click any TAD Real Body to open it instantly in the native TAD Browser or T-Editor.
