1.9 時計管理

1.9.1 時計管理機能 Загальний огляд

時計管理機能 , Система (System)内部 保持している基準時間 あるСистема (System)時間 取出し / 設定, およびカレンダー日付時刻 та 変換機能 提供している.

Система (System)時間 グリニッチ標準時 GMT (Greenwich Mean Time) 1985年1月1日 00:00 から 秒数 Табл. わされた32ビット 値 あり, Файл (File) 生成 / 更新 / アクセス日時等 Система (System)内部 時間Табл. 現 та して使用される.

Система (System)時間 対して, マシン 実際 存在する地域 時間 ローカル時間 та 呼ぶ. 時計管理機能 Система (System)時間 та ローカル時間 та 時差 保持し, ローカル時間 日付時刻 取出し / 設定機能 також 提供している.

Система (System)時間 та ローカル時間 関係 , 以下 示す時間補正データ та して定義される. 

	typedef struct {
		W	adjust;		/* Система (System)時間 та  時差(秒) */
		W	dst_flg;	/* DST  適用Тип (Type) */
		W	dst_adj;	/* DST 調整時間(分) */
	} TIMEZONE;

adjust ローカル時間 та Система (System)時間 ( GMT ) та 時差 あり, グリニッチから西方向へ 秒単位 Табл. 現される, - (12 × 60 × 60) 〜 + (12 × 60 × 60) 範囲 値 ある.

dst_flg サマータイム ( Daylight Saving Time, DST ) 適用Тип (Type) 示し 0 適用しないこ та 示す. 0 以外 値 適用するこ та 示す , そ 意味 時計管理機能 関知せず, 単 0 か 0 ないか 判断 み 行なっている.

dst_adj DST よる時間 調整時間 ( 分 ) 示す - (12×60) 〜 + (12×60) 値 ある. 時計管理機能 DST 適用されるか否か 判断 行なわず, Система (System)プログラム DST 実際 適用される期間 開始時 , dst_adj 適当な値 設定し, DST 適用される期間 終了時 , dst_adj 0 設定するこ та 想定している.

時間補正データ より, ローカル時間 以下 式 定義されるこ та なる. 

    ローカル時間(秒)
        = Система (System)時間(秒) - adjust + (dst_flg ? (dst_adj×60): 0)

なお, 時間 設定 ユーザレベル0 Процес (Process)以外から行なうこ та 禁止されている.

また, 時計管理機能 , 以下 示す構造体 定義されるカレンダー日付時刻 サポートしており, Система (System)時間 та 変換機能 提供されている. 

	typedef struct {
		W	d_year;	  /* 1990年から オフセット(85〜) */
		W	d_month;  /* 月 ( 1 〜 12, 0) */
		W	d_day;	  /* 日 ( 1 〜 31 ) */
		W	d_hour;	  /* 時 ( 0 〜 23 ) */
		W	d_min;	  /* 分 ( 0 〜 59 ) */
		W	d_sec;	  /* 秒 ( 0 〜 59 ) */
		W	d_week;	  /* 週 ( 1 〜 54 ) */
		W	d_wday;	  /* 曜日 ( 0 〜 6, 0 日曜) */
		W	d_days;	  /* 日 ( 1 〜 366 ) */
	} DATE_TIM;

d_week , そ 年 1月1日 週 1 та した場合 週 数 意味し, d_days , そ 年 1月1日 1 та した場合 日数 意味する. また, d_month = 0 , 特殊な意味 та して使用される.

1.9.3 Системні виклики

get_tim
 
Система (System)時間 取得

【Формат / Синтаксис】

ERR get_tim(STIME* time, TIMEZONE* tz)

【Параметри】

STIME*  time    Система (System)時間 格納領域
                NULL  格納しない

TIMEZONE*  tz   時間補正データ 格納領域
                NULL  格納しない

【Значення, що повертається】

＝0  正常
＜0  エラー(Коди помилок)

【Опис та функціонал】

現在 Система (System)時間, および時間補正データ 取り出す.

【Коди помилок】

ER_ADR      : アドレス(time,tz) アクセス 許されていない.
set_tim
 
Система (System)時間 設定

【Формат / Синтаксис】

ERR set_tim(STIME time, TIMEZONE* tz)

【Параметри】

STIME   time    設定するСистема (System)時間
                ≦0   設定しない

TIMEZONE*  tz   設定する時間補正データ
                NULL  設定しない

【Значення, що повертається】

＝ 0  正常
＜ 0  エラー(Коди помилок)

【Опис та функціонал】

現在 Система (System)時間, および時間補正データ設定する.

本Системні виклики 実行 ユーザレベル 0 Процес (Process) み許可される.

【Коди помилок】

ER_ACCES    : レベル 0  ユーザ ない. 
ER_ADR      : アドレス(tz) アクセス 許されていない. 
ER_PAR      : Параметри 不正 ある(tz  内容 範囲外).
get_tod
 
日時 取得／変換

【Формат / Синтаксис】

ERR get_tod(DATE_TIM* dt, STIME time, Bool local)

【Параметри】

DATE_TIM*  dt      変換した日時 格納領域

STIME      time    変換するСистема (System)時間
                   ≦ 0  現在 Система (System)時間 変換

Bool       local   ローカル時間指定
                   ＝ 0  GMT 時間
                         dt   時間補正 行わない結果 戻す. 
                   ≠ 0  ローカル時間
                         dt   時間補正 行った結果 戻す.

【Значення, що повертається】

＝0  正常
＜0  エラー(Коди помилок)

【Опис та функціонал】

指定したСистема (System)時間また 現在 Система (System)時間 カレンダー日付時刻 変換する.

【Коди помилок】

ER_ADR  : アドレス(data_tim) アクセス 許されていない.
set_tod
 
日時 設定／変換

【Формат / Синтаксис】

ERR set_tod(DATE_TIM* dt, STIME* time, Bool local)

【Параметри】

DATE_TIM*  dt     設定 / 変換する日時

STIME*     time   変換したСистема (System)時間 格納領域
                  NULL  現在 Система (System)時間 та して設定する
                        (ユーザレベル 0  Процес (Process) み許可)

Bool      local   ローカル時間指定
                  ＝ 0  GMT 時間
                        dt  時間補正 行わない日時 та みなす. 
                  ≠ 0  ローカル時間
                        dt  時間補正 行った日時 та みなす.

【Значення, що повертається】

＝0    正常
＜0    エラー(Коди помилок)

【Опис та функціонал】

指定したカレンダー日付時刻 Система (System)時間 変換する.

指定した日時 内容 うち, d_week ( 週 ), d_wday ( 曜日 ) 無視される. d_days ( 日数 ) 値 d_month = 0 та き み有効 あり, d_month ≠0 та き 無視される.

【Коди помилок】

ER_ACCES    : レベル 0  ユーザ ない(time=NULL 時). 
ER_ADR      : アドレス(tz) アクセス 許されていない. 
ER_PAR      : Параметри 不正 ある(dat_tim  内容 範囲外).
