Commander

2画面ファイラー
Dual-Pane Orthodox File Manager (OFM)
← Back to B-System Applications
"High-speed keyboard-driven dual-pane file management — pure C99 filesystem operations, directory synchronization, and inspection."

Overview

Keyboard-driven dual-pane orthodox file manager (OFM) engineered in pure C99, backed by the BTRON filesystem and record manager (src/kernel/fs_record.c, src/kernel/proc_mgr.c). Designed for rapid navigation, batch file operations, archive browsing, and directory synchronization across BTRON FS partitions, mounted POSIX filesystems, and VirtIO block volumes. Features built-in raw hex/binary and text viewers, directory comparisons, and rapid hotkeys (F3 View, F4 Edit, F5 Copy, F6 Move, F7 Mkdir, F8 Delete).

コマンダー： BTRONファイルシステム基盤（src/kernel/fs_record.c）およびプロセス管理（src/kernel/proc_mgr.c）に直結した、キーボード主導の超高速操作を実現する純粋C99製左右2画面（OFM: Orthodox File Manager）ファイルマネージャ。BTRON FSパーティション、マウント済みPOSIXファイルツリー、VirtIOブロックデバイス間での一括ファイル転送、ディレクトリ同期、属性変更を瞬時に実行。内蔵バイナリ/HEXビューア、テキストプレビュー、ファンクションキー（F3〜F8）ショートカットを備え、軽量・堅牢に動作。

Key Features & Implementation

  • ファイルシステム基盤：src/kernel/fs_record.c（BTRON FSレコードI/O・同期）
  • 熟練エンジニアのための高速キーボード主導2画面レイアウト（左右ペイン独立）
  • 純粋C99システム設計（高速ファイルI/O・低メモリ消費）
  • ファンクションキー標準操作（F3: 閲覧, F4: 編集, F5: 複製, F6: 移動, F7: 作成, F8: 削除）
  • 内蔵RAWバイナリ/HEXダンパおよびプレーンテキストビューア
  • ディレクトリ差分比較（Diff）とタイムスタンプ/パーミッション同期
  • Terminal (gterm) 連携による現在ディレクトリへの即時シェル起動

Typical Workflow

  1. Launch Commander; left pane displays source directory or storage partition, right pane shows destination.
  2. Navigate effortlessly using cursor keys; select multiple files with Insert or Space.
  3. Press F3 to inspect raw file contents in the built-in hex/binary viewer.
  4. Press F5 or F6 to execute high-speed atomic copy or move operations between partitions.
  5. Press Ctrl+O or Enter to jump directly into a Terminal shell at the active pane's directory.
