POSIX-сумісність та Файлові системи

Для забезпечення роботи стандартного ПЗ та полегшення портування системних утиліт B-Free містить повноцінний сервер сумісності з POSIX. Системні компоненти та вихідні файли POSIX-сервера завантажені в директорії b-free/Program/btron-pc/kernel/POSIX/.

1. POSIX-менеджер (POSIX Server)

POSIX-менеджер (kernel/POSIX/manager/) працює як окремий фоновий процес в середовищі µITRON. Він перехоплює програмні пастки (traps/syscalls) від користувацьких POSIX-процесів і виконує їх.

Сервер реалізує такі системні сервіси:

  • Менеджер процесів: обробка викликів fork, exec, exit, waitpid, надсилання сигналів (kill).
  • Завантажувач ELF: парсинг та завантаження виконуваних файлів формату ELF у віртуальну пам'ять.
  • Планувальник: додаткове планування POSIX-процесів поверх завдань ядра µITRON.

2. Клієнтська бібліотека (lowlib) та libc

Користувацькі програми лінкуються з низькорівневою бібліотекою lowlib (kernel/POSIX/lowlib/) та полегшеною версією libc. Бібліотека lowlib здійснює зв'язок між процесом користувача та POSIX-сервером через системне міжзадачне сполучення ядра µITRON, пакуючи аргументи функцій у повідомлення і надсилаючи їх серверу.

3. Підтримка файлових систем

Файловий менеджер сервера підтримує дві файлові системи:

  • Simple File System (SFS): власна проста файлова система для B-Free. Реалізація знаходиться в POSIX/manager/sfs/. Вона розбиває дисковий простір на блоки, використовує бітову карту для відстеження вільних блоків та іноди (inodes) для представлення файлів.
  • DOS File System (FAT): підсистема для читання дискет та розділів дисків у форматі MS-DOS FAT. Знаходиться в POSIX/manager/dosfs/.

4. Командна оболонка (Shell) та Init

Після запуску системи POSIX-сервер запускає процес ініціалізації init (POSIX/init/init.c), який зчитує конфігураційний файл конфігурації rc, монтує розділи та запускає командний інтерпретатор shell (POSIX/shell/shell.c) для інтерактивної роботи користувача.
