1.3 Процес (Process)/Задача (Task)間同期通信管理

Процес (Process) / Задача (Task)間 同期 та 通信 行うため 機構 та して, 下記 同期通信機能 提供する.

  • セマフォ
  • Подія (Event)フラグ
  • Повідомлення (Message)バッファ
  • ランデブ

これら 同期・通信オブジェクト 動的 生成され, 生成時 割り当てられたID ( > 0 ) より識別される.

Повідомлення (Message) よる通信 та 一番大きく異なる点 , Повідомлення (Message) Процес (Process)間 通信 ある 対し, Задача (Task)間 通信 あるこ та ある. した って, 主な用途 Процес (Process)内 Задача (Task)間 同期・通信 ある. 生成したオブジェクト すべて Процес (Process)から使用可能 та なる , Процес (Process)間 同期・通信 також 使用 きる.

1.3.1 データ / 定数 定義

□ タイムアウト定義

typedef W   TMOUT;          /* タイムアウト指定 (ミリ秒) */

#define T_NOWAIT    ( 0)    /* 待たない */
#define T_FOREVER   (-1)    /* 永久待ち */

□ セマフォ定数定義

#define SEM_SYNC    0x0000  /* 同期用セマフォ */
#define SEM_EXCL    0x4000  /* 排他制御用セマフォ */

□ Подія (Event)フラグ定数定義

#define WF_AND      0x0000  /* Подія (Event)フラグ AND 待ち */
#define WF_OR       0x0002  /* Подія (Event)フラグ OR  待ち */

1.3.2 Системні виклики

cre_sem
 
セマフォ 生成

【Формат / Синтаксис】

WERR    cre_sem(W cnt, UW opt)

【Параметри】

W   cnt セマフォ初期値
        同期用セマフォ 場合   cnt ≧ 0  なければならない. 
        排他制御用セマフォ 場合   cnt = 1  なければならない. 

UW  opt セマフォ属性
        ( SEM_SYNC ‖ SEM_EXCL ) | [ DELEXIT ]
        SEM_SYNC    同期用セマフォ
        SEM_EXCL    排他制御用セマフォ
        DELEXIT     生成Процес (Process)終了時 自動削除

【Значення, що повертається】

＞0   正常(生成したセマフォID)
＜0   エラー(Коди помилок)

【Опис та функціонал】

セマフォ 生成する. 生成したセマフォ , すべて Процес (Process)から使用可能 ある.

SEM_EXCL -- 排他制御用セマフォ
  • 必ず, 獲得 ( wai_sem ) 〜 開放 ( sig_sem ) 順 使用しなくて ならない.
  • セマフォ 獲得したまま解放せず Задача (Task) 終了した場合 , 自動的 解放される.
  • 初期値 1 なければならない.
SEM_SYNC -- 同期用セマフォ
  • セマフォ 獲得 ( wai_sem ), 開放 ( sig_sem ) 順序 対する制限 ない.
  • Задача (Task) 終了した場合 自動解放 行われない.
  • 生成時 初期値 制限 ない.

【Коди помилок】

ER_NOSPC    : Система (System) Пам'ять (Memory)領域 不足した. 
ER_LIMIT    : セマフォ 数 Система (System) 制限 超えた. 
ER_PAR      : Параметри 不正 ある.

wai_flg
 
Подія (Event)フラグ待ち

【Формат / Синтаксис】

WERR    wai_flg(ID id, W ptn, UW mode, TMOUT tmo)

【Параметри】

ID  id  Подія (Event)フラグID

W   ptn 待ちパターン (>0)

UW  mode    待ち解除条件
        ( WF_AND ‖ WF_OR ) | [ NOCLR ]
        WF_AND  0x0000  ptn  1 ビット すべてセットされるま 待つ
        WF_OR   0x0002  ptn  1 ビット いずれか セットされるま 待つ
        NOCLR   0x0008  待ち解除条件 満たされた時, Подія (Event)フラグ 値 
                        クリアしない

TMOUT   tmo タイムアウト指定 (ミリ秒)
        T_NOWAIT    待ち解除条件 満たされなくて також 待たない
        T_FOREVER   待ち解除条件 満たされるま 待つ
        >0          待ち解除条件 満たされるま 最長 tmo ミリ秒待つ

【Значення, що повертається】

＞0   正常(待ち状態 解除された та き Подія (Event)フラグ 値)
＜0   エラー(Коди помилок)

【Опис та функціонал】

mode 指定された条件 した って, Подія (Event)フラグ セットされる 待つ.

次 条件 満たされた та き待ち解除 та なる. 

WF_AND  時 ( flg & ptn ) == ptn
WF_OR  時  ( flg & ptn ) != 0
        ∵ flg  Подія (Event)フラグ 値

NOCLR 指定された時 , 待ち解除条件 満たされた та きПодія (Event)フラグ 値 変化しない. NOCLR 指定 ない場合 , 待ち解除条件 満たされた та きПодія (Event)フラグ 値 ( 全ビット ) 0 クリアされる.

指定された待ち時間 経過して також 待ち解除条件 満たされない場合 , ER_NONE 返される.

【Коди помилок】

ER_DLT      : Подія (Event)フラグ 待ち 間 削除された. 
ER_ID       : Подія (Event)フラグID 不正 ある. 
ER_MINTR    : Повідомлення (Message)ハンドラ 起動されたため待ち処理 中断された. 
ER_NOEXS    : Подія (Event)フラグ 存在していない. 
ER_NONE     : Подія (Event)フラグ 条件 満たされず タイムアウトした. 
ER_PAR      : Параметри 不正 ある.
