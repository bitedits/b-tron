T-Editor

TADエディタ
Native Hypermedia Document Editor
← Back to B-System Applications
"The native TAD authoring environment — mix text, graphics, Virtual Bodies and media in one document"

Overview

Native hypermedia editor. Mix text, graphics, Virtual Bodies and media in a single TAD document. Excellent multilingual input via Mozc TIP and smooth collaborative editing support.

Tエディタ： ネイティブ・ハイパーメディア文書編集環境。テキスト、ベクター図形、仮想オブジェクト、各種メディアを単一のTAD文書内で自在に融合。強力な多言語入力（TRONコード・多言語プレーン）とスムーズな共同編集をサポート。

Key Features

  • TAD標準準拠の真のハイパーメディア編集
  • Mozc TIP連携による高度な漢字・多言語文字入力
  • 実身と仮身の自由な埋め込み・展開・リンク網形成
  • Inline embedding of Paint graphics, MediaPulse clips, and Calculator results as Virtual Bodies
  • Collaborative real-time editing with conflict-free merge via CRDT
  • Export to TAD Cabinet, PDF, or plain-text without losing the hypermedia structure

Typical Workflow

  1. Open a new TAD document in T-Editor.
  2. Type multilingual text using Mozc TIP for kanji and TRON Code for extended characters.
  3. Drag a graphic from Paint — it embeds as a native TAD vector segment (resolution-independent).
  4. Drop a MediaPulse clip — it becomes an inline scrubbable Virtual Body within the text flow.
  5. Share the document; collaborators see live cursors and edits merge automatically.
