3.8 Реальний об'єкт (Real Object)／Менеджер віртуальних об'єктів (VObject Manager)

3.8.1 Реальний об'єкт (Real Object)／Менеджер віртуальних об'єктів (VObject Manager)のфункціонал / підсистема

3.8.1.1 概要

Реальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)は, 外殻の 1 つとして«Реальний об'єкт (Real Object) / Віртуальний об'єкт (Virtual Object)モデル»を実現する上での各種の高レベルのфункціонал / підсистемаを提供しており, прикладний додаток / програмаプログラムはРеальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)で提供される拡張системний виклик (System Call)を使用して容易にРеальний об'єкт (Real Object) / Віртуальний об'єкт (Virtual Object)を表示 / 操作することが可能となる.

また, Реальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)は, прикладний додаток / програмаプログラムの登録 / 削除функціонал / підсистемаを提供しており, 基本的に全てのприкладний додаток / програмаプログラムはРеальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)を通して起動されることになる.

Реальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)のфункціонал / підсистемаとしては, 以下のものがあげられる.

  1. Віртуальний об'єкт (Virtual Object)の各種表示 / 操作функціонал / підсистема
  2. 付箋の各種表示 / 操作функціонал / підсистема
  3. прикладний додаток / програмаプログラムの管理 ( 登録 / 削除 / 実行 ) функціонал / підсистема
  4. メニュー設定функціонал / підсистема
  5. Файл (File)システムの接続管理функціонал / підсистема
  6. その他のприкладний додаток / програмафункціонал / підсистема

以下, この章ではHMI外部仕様としてのРеальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)を用いたприкладний додаток / програмаによる, Реальний об'єкт (Real Object) / Віртуальний об'єкт (Virtual Object)の取扱いを記述しているが, 具体的な表示項目や表示のデザインなどの詳細についてはインプリメントに依存する.

3.8.1.2 Віртуальний об'єкт (Virtual Object) / Реальний об'єкт (Real Object) / 虚身

«Реальний об'єкт (Real Object)»とは意味のあるデータの集まりそれ自体のことであり, 実際のФайл (File)に一対一に対応するものである. Реальний об'єкт (Real Object)をユーザが操作するための手掛かりが«Віртуальний об'єкт (Virtual Object)»であり, Реальний об'єкт (Real Object)は常にВіртуальний об'єкт (Virtual Object)を通して参照される. Віртуальний об'єкт (Virtual Object)はРеальний об'єкт (Real Object)を参照するための一種のタグであり, 一つのРеальний об'єкт (Real Object)を一つ以上のВіртуальний об'єкт (Virtual Object)が参照することができる.

図 114 : Віртуальний об'єкт (Virtual Object) / Реальний об'єкт (Real Object) / 虚身

Реальний об'єкт (Real Object)自体は目で見える形で直接的に表示されることはなく, そのРеальний об'єкт (Real Object)を参照するВіртуальний об'єкт (Virtual Object)として表示される. Віртуальний об'єкт (Virtual Object)は 1 つのデータ単位として, 文字や図形等と同様にРеальний об'єкт (Real Object)内の任意の位置に埋め込まれて表示される.

Віртуальний об'єкт (Virtual Object)にはРеальний об'єкт (Real Object)の管理情報のみを表示している«閉じたВіртуальний об'єкт (Virtual Object)»と, 管理情報と共にРеальний об'єкт (Real Object)の内容も表示している«開いたВіртуальний об'єкт (Virtual Object)»がある.

Віртуальний об'єкт (Virtual Object)を«ウィンドウに開く»ことにより, そのВіртуальний об'єкт (Virtual Object)が指すРеальний об'єкт (Real Object)に適用されるприкладний додаток / програмаが実行されて, Реальний об'єкт (Real Object)の内容が表示される. どのприкладний додаток / програмаを実行するかを指定せずにВіртуальний об'єкт (Virtual Object)からウィンドウを開いた場合には, そのВіртуальний об'єкт (Virtual Object)に保持されているデフォールトприкладний додаток / програмаが起動される.

Віртуальний об'єкт (Virtual Object)が格納されていたРеальний об'єкт (Real Object)が存在するПристрій (Device)を, Віртуальний об'єкт (Virtual Object)の«所属元Пристрій (Device)»と呼び, Віртуальний об'єкт (Virtual Object)が格納されるРеальний об'єкт (Real Object)が存在するПристрій (Device), 即ち, Віртуальний об'єкт (Virtual Object)が表示されているウィンドウの元となったРеальний об'єкт (Real Object)が存在するПристрій (Device)をВіртуальний об'єкт (Virtual Object)の«所属Пристрій (Device)»と呼ぶ. Віртуальний об'єкт (Virtual Object)の所属Пристрій (Device)は, Віртуальний об'єкт (Virtual Object)を, 異なるПристрій (Device)に存在するРеальний об'єкт (Real Object)を元にして開かれたウィンドウ間で移動することにより動的に変化する.

Віртуальний об'єкт (Virtual Object)の所属元Пристрій (Device)と異なるПристрій (Device)もしくはその中のРеальний об'єкт (Real Object)を参照するВіртуальний об'єкт (Virtual Object), 即ちПосилання (Link)Файл (File)を参照しているВіртуальний об'єкт (Virtual Object)を«間接参照Віртуальний об'єкт (Virtual Object)»と呼ぶ. 間接参照Віртуальний об'єкт (Virtual Object)とРеальний об'єкт (Real Object)は疎な結合であるため, その参照は保証されない.

また, Віртуальний об'єкт (Virtual Object)の所属Пристрій (Device)と異なるПристрій (Device)もしくはその中のРеальний об'єкт (Real Object)を参照するВіртуальний об'єкт (Virtual Object)を«一時間接参照Віртуальний об'єкт (Virtual Object)»と呼ぶ. 一時間接参照Віртуальний об'єкт (Virtual Object)は格納することによりПосилання (Link)Файл (File)を参照する間接参照Віртуальний об'єкт (Virtual Object)となる.

Пристрій (Device)には, そのПристрій (Device)が物理的または論理的に接続されておらず直接アクセスできない«切断状態»と接続されておりアクセス可能な«接続状態»の 2 つの状態があり, 初期状態は切断状態となる.

«切断状態»のПристрій (Device)もしくはその中のРеальний об'єкт (Real Object)を参照する間接参照Віртуальний об'єкт (Virtual Object)を«虚身»と呼ぶ. 虚身を通常のВіртуальний об'єкт (Virtual Object)のようにウィンドウに開こうとした場合は, «Пристрій (Device)接続パネル»が現われ, その虚身の参照するРеальний об'єкт (Real Object)が最後に«接続状態»だった時点での所在等の管理情報を表示して, 接続状態にするか否かの判断を求める. 接続状態にすることにより虚身は通常のВіртуальний об'єкт (Virtual Object)と同様に操作できる.

一般の虚身は«閉じた虚身»であり開くことはできないが, すでに開いているВіртуальний об'єкт (Virtual Object)が切断状態にされた場合は«開いた虚身»となる.

3.8.1.3 Віртуальний об'єкт (Virtual Object)の表示

Віртуальний об'єкт (Virtual Object)の表示

«閉じたВіртуальний об'єкт (Virtual Object)»は, 横長の矩形枠で囲まれた図形として表示され, 参照するРеальний об'єкт (Real Object)に関する情報が内部に表示される.

«開いたВіртуальний об'єкт (Virtual Object)»は, 閉じたВіртуальний об'єкт (Virtual Object)の境界線が下に拡がり, Реальний об'єкт (Real Object)の内容自体を表示する表示エリアが追加されたものであり, 表示エリアはРеальний об'єкт (Real Object)の内容が対応するприкладний додаток / програмаにより表示される.

«選択状態»の場合, Віртуальний об'єкт (Virtual Object)の周囲に点線の枠をチラツキ表示させる.

Віртуальний об'єкт (Virtual Object)から開かれたウィンドウが存在している状態を«処理中状態»と呼び, 元のВіртуальний об'єкт (Virtual Object)の表示全体に灰色パターンが重ねられる. «間接参照Віртуальний об'єкт (Virtual Object)»および«一時間接参照Віртуальний об'єкт (Virtual Object)»の場合, Віртуальний об'єкт (Virtual Object)の枠の左上角が境界線色で塗りつぶされる. この間接参照を示す表示は, Віртуальний об'єкт (Virtual Object)を格納した場合間接参照Віртуальний об'єкт (Virtual Object)となることを示すものである. よって«間接参照Віртуальний об'єкт (Virtual Object)»をそのВіртуальний об'єкт (Virtual Object)が参照するРеальний об'єкт (Real Object)のПристрій (Device)のウィンドウへ戻した場合は, 間接参照表示が解除される.

Віртуальний об'єкт (Virtual Object)の表示の大きさ, デザイン等の詳細はРеальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)のインプリメントに依存する.

Віртуальний об'єкт (Virtual Object)の選択

  • Віртуальний об'єкт (Virtual Object)の領域内をВказівний пристрій (Pointing Device)でプレスするか, または選択フレームで囲むことによりВіртуальний об'єкт (Virtual Object)を«選択状態»とし, 周囲に adsp_slt() または adsp_sel() を用いて, チラツキ枠を表示する. «選択状態»は, そのВіртуальний об'єкт (Virtual Object)を表示しているприкладний додаток / програмаのコマンド ( メニュー ) の対象であることを示すものであり, 複数のВіртуальний об'єкт (Virtual Object)を同時に«選択状態»としてもよい.

  • 選択状態のВіртуальний об'єкт (Virtual Object)では, вказівник (Pointer)の形状を以下のように変化させる.

    ピクトグラム部分 -- «選択指»
    ハンドルの部分 -- «変形手»
    その他の部分 -- «移動手»

  • 選択状態でないВіртуальний об'єкт (Virtual Object)を, プレスしてドラッグした場合は, プレスの時点で選択状態とし, «移動手»または«変形手»を一瞬表示した後, «握り»または«つまみ»に変化させ, ドラッグを行なう.

3.8.2 Віртуальний об'єкт (Virtual Object)の移動 / 複写

  • Віртуальний об'єкт (Virtual Object)のハンドル部以外 ( 表示エリアを含む ) をポイントし ( この時点でВіртуальний об'єкт (Virtual Object)が選択状態ならば, вказівник (Pointer)形状を«移動手»にする. ただし, ピクトグラム上では«選択指»にする), ドラッグすることによって移動を行なう. リリース時にメニューボタンが押下されていれば複写を行なう.

Віртуальний об'єкт (Virtual Object)の分類

Віртуальний об'єкт (Virtual Object)は, 内部的にはФайл (File)管理で定義されている«Посилання (Link)»により表現され, その取り扱い上, 以下のように分類される.

今後, 単にВіртуальний об'єкт (Virtual Object)という場合は通常Віртуальний об'єкт (Virtual Object)を示すものとする.

Реальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)ではВіртуальний об'єкт (Virtual Object)を, 指定したウィンドウ / パネル上に存在する一種のパーツとして登録し, 登録したВіртуальний об'єкт (Virtual Object)に対してВіртуальний об'єкт (Virtual Object)ID ( vid > 0 ) を割り当てて管理する. прикладний додаток / програмаは登録時に得られるВіртуальний об'єкт (Virtual Object)IDを使用して, Віртуальний об'єкт (Virtual Object)の表示 / 操作を行なうことになる. ただし, 内部Віртуальний об'єкт (Virtual Object)のサポートのため, Віртуальний об'єкт (Virtual Object)を登録せずに直接表示するфункціонал / підсистемаも提供している.

3.8.3.3 прикладний додаток / програмаプログラム管理

ユーザの処理の実行環境となっているФайл (File)を«実行環境Файл (File)»と呼ぶ.

прикладний додаток / програмаプログラムは対応する付箋を元に実行される. 付箋にはприкладний додаток / програма ID が入っており, これを元に登録済みのприкладний додаток / програмаプログラムが検索されて実行される.

3.8.3.4 прикладний додаток / програмаプログラムの起動

起動方法

登録されたприкладний додаток / програмаプログラムに対しては, 以下の 4 種類の起動が行なわれる.

(1) Віртуальний об'єкт (Virtual Object)のオープン起動 :

指定されたВіртуальний об'єкт (Virtual Object)に対してウィンドウを開いてприкладний додаток / програма本来のфункціонал / підсистемаを実行する. 実行メニュー, 小物メニューまたはピクトグラム ( または, Віртуальний об'єкт (Virtual Object)の任意の箇所 ) のダブルクリックにより起動される.

(2) 開いたВіртуальний об'єкт (Virtual Object)の表示起動 :

(3) データ貼り込み起動 :

指定されたВіртуальний об'єкт (Virtual Object)の参照するРеальний об'єкт (Real Object)にトレーに格納されているデータを貼り込み, 貼り込み完了後に終了する. Віртуальний об'єкт (Virtual Object)への貼り込み操作で起動される.

(4) 付箋のオープン起動 :

指定された付箋に対して対応するприкладний додаток / програмаを起動する. 付箋のピクトグラム ( または, 付箋の任意の箇所 ) のダブルクリック, 付箋操作メニューにより起動される.

(5) 開いたВіртуальний об'єкт (Virtual Object)のTADデータ作成起動 :

指定された開いたВіртуальний об'єкт (Virtual Object)の表示エリア内の表示に相当する TAD データを作成し, データ作成完了後に終了する.

以下に, 付箋のオープン起動で起動されたприкладний додаток / програмаの典型的な動作例 (例えば, 印刷прикладний додаток / програмаプログラム)を示す.

  2. параметриの設定が行なわれた場合は, oend_prc() により, 付箋固有データの更新を行なう.

  3. «実行»を要求された場合は, oreq_prc() により, 起動元のПроцес (Process)に対して, 現在の編集結果を一時Файл (File)とすることを要求する. この応答により得られた一時Файл (File)を対象として«実行»としてのфункціонал / підсистемаを実施する. 通常は, 応答が得られた時点でパネルをクローズするが, Процес (Process)はまだ終了しない.

  4. «実行»が要求されなかった場合は, パネルをクローズしПроцес (Process)を終了する.

3.8.5 Реальний об'єкт (Real Object)／Менеджер віртуальних об'єктів (VObject Manager)の関数

ここでは, Реальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)がサポートしている各関数の詳細を説明する. これらの関数群は外殻の拡張системний виклик (System Call)として提供される.

関数値は, 何らかのПомилкаがあった場合は«負»のкод помилкиが戻る. Успішне виконання終了時には«0»または«正»の値が戻る.

各関数のкод помилкиとしては, ここで示した以外にも, 核や他の外殻でПомилкаが検出された場合は, そのкод помилкиが直接戻る場合がある.

また, 各関数のпараметриの説明では, 以下に示す記述方法を使用している. 

    ( x ‖ y ‖ z ) -- x, y, z のいずれか1つを意味する. 
    |               -- OR で指定可能なことを意味する. 
    [ ]             -- 省略可能なことを意味する.

Реальний об'єкт (Real Object) / Менеджер віртуальних об'єктів (VObject Manager)の関数は他の外殻の関数と比較して, よりприкладний додаток / програмаレベルに近いため, 関数によってはパネルを利用したユーザとのインタラクションが含まれている点に注意が必要である.

ここで示している多くの関数は, 特に記述がない限り, Віртуальний об'єкт (Virtual Object)だけでなく付箋に対しても適用される. したがって, 単に«Віртуальний об'єкт (Virtual Object)»と記述してある場合は«付箋»も含まれるものとする.

【Синтаксис / Прототип】

【Параметри】

VLINK   *vlnk   Віртуальний об'єкт (Virtual Object)(Посилання (Link))

V_DISP

*evt はパネルの動作実行で得られたメニューПодія (Event)でなくてはいけない.

*evt が EV_KEYDWN のときは, キーメニューとしての処理を行ない, そうでないときは, 以下の内容のメニューを画面に表示して, 選択された項目に応じた処理を行なう. 

    編集    トレーへ複写    Ｃ
            トレーから複写  Ｚ
            トレーへ移動    Ｖ
            トレーから移動  Ｘ
            削除

メニュー処理の結果として, トレーや対象のテキストボックスの内容が更新される.

achg_bgc
 
ウィンドウ背景色変更処理

【Синтаксис / Прототип】

W   achg_bgc(W *mask, COLOR *color, COLOR bgc)

【Параметри】

W       *mask   マスク(0, FILL0 (1) 〜 FILL100 (7)) 0 はВіртуальний об'єкт (Virtual Object)背景色と同じ
COLOR   *color  背景色
COLOR   bgc Віртуальний об'єкт (Virtual Object)背景色

【Значення, що повертається】

= 0      Успішне виконання (取り消し, または変更なし)
＝1    Успішне виконання (変更された)
＜0    Помилка (код помилки)

【Детальний опис】

mask, color, bgc で指定された現在のウィンドウ背景色に対して, «ウィンドウ背景色変更パネル»を表示して, ウィンドウ背景色の変更を行い, 変更した結果を, mask, color に格納する.

bgc < 0 のときは, «Віртуальний об'єкт (Virtual Object)背景色と同じ»という選択はないようになる.

【Коди помилок】

EX_ADR      : адреса пам'яті(mask, color)のアクセスは許されていない.
